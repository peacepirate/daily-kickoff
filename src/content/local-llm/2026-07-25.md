# Local LLM Weekly — Week of Jul 20–25, 2026
*Coverage window: Mon Jul 20 – Sat Jul 25*

## TL;DR

llama.cpp landed the MCP integration that's been in the works for months — stdio MCP servers now work end-to-end, and the built-in WebUI is now a full agentic chat client without needing Open WebUI or a wrapper. Ollama shipped v0.32.4 with Laguna MLX support on Apple GPUs and a 4–9% Qwen3 MoE decode improvement on M5 Max, plus a decoding fix for differently-quantized experts. llama.cpp b10121 slashes streaming render cost per token by roughly two orders of magnitude in the worst case. Prince Canuma dropped Nativ, a new MLX-native macOS app aimed squarely at the LM Studio slot.

## Releases & Updates

- **[Ollama v0.32.4](https://github.com/ollama/ollama/releases/tag/v0.32.4)** — Adds Laguna support on Apple GPUs via the MLX engine (XS 2, XS 2.1, S 2.1 dense + MoE). Fixes Qwen3 MoE decoding for differently-quantized experts and ships a faster packed gate/up projection worth ~4–9% on M5 Max. Also quantizes draft-model output heads at the requested type for speculative decoding. Direct win for your 96GB Mac if you run Qwen3 MoE variants. `[UPGRADE]`

- **[Ollama v0.32.3](https://github.com/ollama/ollama/releases/tag/v0.32.3)** — Fixes downloads that stall before sending data. Adds chat/thinking/tool-calling support for Laguna 2.1 models including a Metal inference fix. Fixes GLM tool calls being silently dropped at end-of-generation. Restored Claude Code Channels integration, fixed Anthropic thinking streams. Updates both MLX and llama.cpp engines. `[UPGRADE]`

- **[llama.cpp now has full MCP support](https://www.reddit.com/r/LocalLLaMA/comments/1v6n33i/llamacpp_now_has_full_mcp_support/)** — After a long push from ngxson, PR #26062 merged. HTTP MCP was already there client-side; stdio servers now work too because `llama-cli` was refactored to use the server rather than a separate model-serving route. The built-in WebUI is now a full-fledged agentic chat with tools — no wrapper needed. `[BUILD]`

- **[llama.cpp b10121](https://github.com/ggml-org/llama.cpp/releases/tag/b10121)** — WebUI perf: reduces per-token render cost while streaming. Empirical numbers from the harness are dramatic: 210.36ms→2.67ms, 11.58ms→0.62ms, 22.02ms→3.33ms, 3.07ms→1.36ms at 40 messages. If you use the built-in WebUI for long chats this is a huge UX upgrade. `[UPGRADE]`

- **[llama.cpp b10105](https://github.com/ggml-org/llama.cpp/releases/tag/b10105)** — CLI overhaul: refactors mlock, mmap, and direct IO into a single `load-mode` arg. Deprecated flags still work. Small quality-of-life change if you script llama.cpp invocations for benchmarking. `[UPGRADE]`

## Models to Try

- **Laguna XS 2 / XS 2.1 / S 2.1 (MLX)** — Now supported in Ollama v0.32.4 via the MLX engine with mixed-precision expert dispatch. Ollama config quantizes attention and expert projections while keeping the tied output head and router at source precision, and selectively promotes sensitive expert down-projections. No public benchmark numbers in the release notes; worth a spin if the sizes match your 96GB budget. `[BENCHMARK]`

## Ecosystem Signals

- **[Nativ: Run AI models locally on your Mac](https://simonwillison.net/2026/Jul/21/nativ/#atom-everything)** — Prince Canuma (author of MLX-VLM) shipped a native macOS app wrapping MLX with both a chat UI and a localhost API server. Auto-detected models in Simon's existing HuggingFace MLX cache. Positioned as an MLX-first LM Studio alternative from someone who actually built the underlying stack. `[BUILD]`

- **[Bringing Nunchaku 4-bit Diffusion Inference to Diffusers](https://huggingface.co/blog/nunchaku-diffusers)** — 4-bit quantized diffusion model inference now integrated into the HuggingFace `diffusers` library. Relevant if you want quantized image generation for mythology illustrations on your Mac without a dedicated GPU. `[BUILD]`
