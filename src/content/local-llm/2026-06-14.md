# Local LLM Weekly — Week of Jun 9–14, 2026
*Coverage window: Mon–Sat*

## TL;DR
Ollama 0.30.7–0.30.8 shipped with meaningful improvements: better KV cache reuse, more stable MLX inference on Apple Silicon, and Hermes Desktop via `ollama launch`. llama.cpp added cohere2-MoE architecture support across b9624–b9628. A quiet week for new model drops — no HuggingFace or LM Studio signal came through.

## Releases & Updates

- **[Ollama v0.30.8](https://github.com/ollama/ollama/releases/tag/v0.30.8)** — Three wins for your Mac: (1) prompt caching now decoupled from context shift for better KV cache reuse (faster multi-turn conversations), (2) MLX inference hardened with stabilized linear and embedding layers, (3) MLX runner snapshots during prompt processing and speculative decoding for improved reliability. Also improved recurrent model support. Upgrade immediately. `[UPGRADE]`

- **[Ollama v0.30.7](https://github.com/ollama/ollama/releases/tag/v0.30.7)** — Introduces `ollama launch hermes-desktop`, a native desktop interface for the Hermes agent (Windows config paths supported). OpenAI-compatible API model list now aligns with available model tags. If you're using Hermes for Gods content generation workflows, this is worth a look. `[BUILD]`

- **[llama.cpp b9628](https://github.com/ggml-org/llama.cpp/releases/tag/b9628)** — Adds SYCL to the release check matrix. Apple Silicon (arm64) build included as usual. Incremental maintenance release. `[UPGRADE]`

- **[llama.cpp b9626](https://github.com/ggml-org/llama.cpp/releases/tag/b9626)** — Adds architecture support for cohere2-MoE. This is the Cohere Command R+ style MoE architecture — if GGUF conversions appear on HuggingFace for cohere2-MoE models, llama.cpp can now run them. Watch for quantized uploads. `[BENCHMARK]`
