# Local LLM Weekly — Week of Jun 16–21, 2026
*Coverage window: Mon–Sat*

## TL;DR
Ollama v0.30.9/v0.30.10 landed two notable fixes: Command A and North family models now run on Apple Silicon via MLX, and a one-token output bug in coding agent workflows is patched. llama.cpp is churning through grammar/structured-output refactors this week. Georgi Gerganov (llama.cpp author) publicly endorses Qwen3-27B as his daily coding model on M2 Ultra — that's a meaningful signal for your 96GB Mac.

## Releases & Updates

- **[Ollama v0.30.10](https://github.com/ollama/ollama/releases/tag/v0.30.10)** — Command A and North family models now run on Apple Silicon with the MLX engine (previously CPU-only). llama.cpp engine bumped to b9672. If you've tried Command A before and it was slow, re-pull and re-test. `[UPGRADE]`

- **[Ollama v0.30.9](https://github.com/ollama/ollama/releases/tag/v0.30.9)** — Critical fix: coding agent / Claude Code-style workflows were only outputting one token. If you use Ollama-backed agents for any Gods project automation, this is a must-upgrade. Also adds Cohere2Moe architecture support and proper error when a message exceeds context window. `[UPGRADE]`

- **[llama.cpp b9744](https://github.com/ggml-org/llama.cpp/releases/tag/b9744)** — PEG grammar refactor: GBNF grammar generation now goes through an AC automaton. Plumbing work that will improve structured output reliability (JSON schema, constrained decoding). Pre-built Apple Silicon arm64 binaries available. `[UPGRADE]`

- **[llama.cpp b9741](https://github.com/ggml-org/llama.cpp/releases/tag/b9741)** — Uses LLM_KV for quantization_version and file_type metadata. Internal housekeeping from HuggingFace contributor; no user-facing behavior change but keeps GGUF metadata standards aligned. `[SKIP]`

## Models to Try

- **[Qwen3-27B](https://huggingface.co/Qwen/Qwen3-27B-GGUF)** — Georgi Gerganov (llama.cpp author) has been using this daily on M2 Ultra for coding tasks via his `pi` agent harness. At Q4_K_M: ~18GB VRAM, fits easily in your 96GB unified memory with room for a long context window. Strong candidate for Gods of the Future Past story/lore generation. `[BENCHMARK]`

- **GLM-5.2** — Vercel CEO called it "almost shocked" good at coding. No GGUF link in this week's sources — check HuggingFace for `bartowski/GLM-5.2-GGUF` or similar before benchmarking. If weights land at Q4_K_M for the 32B or smaller variant, it's worth a test against Qwen3-27B on your mythology prompts. `[BENCHMARK]`
