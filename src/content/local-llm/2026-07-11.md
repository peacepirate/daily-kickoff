# Local LLM Weekly — Week of Jul 7–11, 2026
*Coverage window: Mon Jul 7 – Sat Jul 11*

## TL;DR

Ollama shipped v0.31.2 with a meaningful Apple Silicon fix: iGPU vision models (multimodal projectors) now offload correctly instead of falling back to CPU on GB10 and Strix Halo. v0.32.0-rc0 previews a Qwen3.5 parser/renderer and an in-terminal agent UI. llama.cpp reached b9968 with incremental fixes; the standout is a tensor-split regex that was recompiled on every decode call — now static. Quiet week on model releases and community signal — r/LocalLLaMA, HuggingFace Blog, Simon Willison, and GitHub Trending all returned no data.

## Releases & Updates

- **[Ollama v0.31.2](https://github.com/ollama/ollama/releases/tag/v0.31.2)** — Flash attention enabled on older NVIDIA GPUs (6.x compute), iGPU multimodal projector offload fixed (no more forced CPU fallback for vision models on Metal iGPUs), structured output fixed for thinking models when thinking is disabled, GGUF create hardened, MLX + llama.cpp engines updated. The iGPU projector fix is directly useful if you're running any vision/multimodal model on your Mac. `[UPGRADE]`

- **[Ollama v0.32.0-rc0](https://github.com/ollama/ollama/releases/tag/v0.32.0-rc0)** — Preview release. Adds a Qwen3.5/Next-specific parser and renderer, a new agent UI accessible via `ollama launch`, and a warning when launching older agent-incompatible models. Worth testing now if you're evaluating Qwen3.5 for story-generation tasks in Gods of the Future Past. `[BUILD]`

- **[llama.cpp b9966](https://github.com/ggml-org/llama.cpp/releases/tag/b9966)** — Fixes a performance regression in tensor-split mode: `llama_meta_device_get_split_state()` was recompiling 29 regex patterns on every decode callback. Now static. In `-sm tensor` mode this was dominating the decode thread. If you ever split models across memory regions this matters. `[UPGRADE]`

- **[llama.cpp b9967](https://github.com/ggml-org/llama.cpp/releases/tag/b9967)** — Server now accepts `null` sampling params (temperature, top_p, etc.) per OpenAI spec, treating them as absent rather than erroring. Cleaner API compatibility if you're hitting the llama.cpp server from custom tooling. `[UPGRADE]`

- **[llama.cpp b9964](https://github.com/ggml-org/llama.cpp/releases/tag/b9964)** — Prevents duplicate model downloads when the same spec model is referenced multiple times in `--model` args. Minor QoL fix. `[UPGRADE]`
