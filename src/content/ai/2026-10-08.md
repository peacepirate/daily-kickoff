## TL;DR
Anthropic shipped Claude Haiku 5.5 on Bedrock and published a containment-architecture write-up worth reading before your next agentic-adoption conversation. Two solid Bedrock multi-agent RAG case studies (Qlik, Cornerstone OnDemand) are good reference material for your team. LangChain's Deep Agents picked up a context-efficient skills pattern, and Docling shipped a batch of OCR/table fixes.

## What's New

- **[Introducing Claude Haiku 5.5 on AWS](https://aws.amazon.com/blogs/machine-learning/introducing-claude-haiku-5-5-on-aws/)** — Now live on Bedrock. Fastest, cheapest model in the Claude 5.5 family, built for subagents and high-volume work, roughly 75% cheaper than Haiku 4.5 for most tasks. If you're running Claude Code subagents or document classification on Bedrock, this is the tier to route cheap work to. [TRY]

- **[How we contain Claude](https://www.anthropic.com/engineering/how-we-contain-claude)** — Anthropic's own write-up on capping agent blast radius across claude.ai, Claude Code, and Cowork as capability grows. Directly useful for the governance conversation you'll have leading agentic adoption at a regulated company. [READ DEEPER]

- **[Rethinking access control for RAG with Amazon Quick and Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/rethinking-access-control-for-rag-with-amazon-quick-and-amazon-bedrock/)** — Enforces document-level permissions in real time against the authoritative source at query time, instead of baking ACLs into the index. Worth checking against your underwriting document RAG build for the same permission gap. [READ DEEPER]

- **[How Qlik built grounded, enterprise-scale AI with Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/how-qlik-built-grounded-enterprise-scale-ai-with-amazon-bedrock/)** — Layered multi-agent architecture with cross-Region inference and Bedrock Guardrails, grounding answers across structured and unstructured data for 40,000+ customers. A clean reference architecture for layered RAG at scale. [SHARE w/ engineering team]

- **[How Cornerstone OnDemand cut database diagnosis by 78% with Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/how-cornerstone-ondemand-cut-database-diagnosis-by-78-with-amazon-bedrock/)** — A 3-person team built a multi-agent system on Strands Agents + Bedrock that cut DB diagnosis from 45 to 10 minutes in six months. Reproducible numbers, small team — good talking point for what's achievable. [SHARE w/ engineering team]

- **[Revamping Skills in Deep Agents](https://www.langchain.com/blog/revamping-skills-in-deep-agents)** — Deep Agents now lets you bind tools to skills, pin skills at runtime, and reload mid-thread, so agents with large skill libraries stay context-efficient. Applicable if you're designing skill-heavy Claude Code agents for your teams. [TRY]

- **[Docling v2.135.0](https://github.com/docling-project/docling/releases/tag/v2.135.0)** — Routine release with OCR, table, and PDF-parsing fixes (tesseract word preservation, table cell placement, failed-page handling). Worth a skim if you're on Docling for document ingestion, nothing urgent. [SKIP]

- **Quick hits** — **[GPT-6 and Intelligent UI for everyone](https://openai.com/index/gpt-6-for-everyone/)** (OpenAI's GA push, trending hard on HN) and **[Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** (new flagship, no benchmark detail published yet). Neither touches your Bedrock/Claude stack directly. [SKIP]
