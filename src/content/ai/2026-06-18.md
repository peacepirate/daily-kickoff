# AI Digest — Wednesday, June 18, 2026

*Coverage window: previous 24 hours*

## TL;DR

Big day: AWS Bedrock AgentCore harness goes GA — two API calls to spin up a production-grade agent with memory, MCP tool access, and multi-model switching. MCP gets zero-touch OAuth for enterprise, and DeepSeek drops V4 preview with top-tier reasoning. Several smaller signals worth noting for your agentic teams.

## What's New

- **[Amazon Bedrock AgentCore harness is now generally available](https://aws.amazon.com/blogs/machine-learning/amazon-bedrock-agentcore-harness-is-now-generally-available-go-from-idea-to-production-grade-agent-in-minutes/)** — `CreateHarness` + `InvokeHarness` and you have an isolated agent running in seconds: sandboxed shell/filesystem, persistent memory across sessions, web browsing, MCP tool gateway, and the ability to switch model providers mid-session without losing context. This is the fastest on-ramp to production agents on your existing Bedrock infrastructure — your teams should prototype against it this sprint. `[TRY]` `[SHARE w/ engineering team]`

- **[Zero-Touch OAuth for MCP](https://blog.modelcontextprotocol.io/posts/enterprise-managed-auth/)** — MCP's new enterprise-managed auth spec lets organizations centrally manage OAuth authorization for MCP connectors rather than requiring per-user credential setup. Directly relevant as your teams add more MCP servers — eliminates the credential-sprawl problem before it starts. Anthropic's platform already shipped a matching feature ([Centrally manage authorization for MCP connectors](https://releasebot.io/updates/anthropic#Centrally-manage-authorization-for-MCP-connectors)). `[READ DEEPER]` `[SHARE w/ engineering team]`

- **[DeepSeek-V4 Preview](https://mp.weixin.qq.com/s/8bxXqS2R8Fx5-1TLDBiEDg)** — DeepSeek announces V4 with "world-class reasoning" and significantly improved agent capabilities, live on web, app, and API. No English-language technical write-up yet but worth tracking as a model alternative — especially if you're evaluating non-AWS options for document understanding or RAG eval. `[SHARE w/ leadership]`

- **[Monitor and debug generative AI inference with SageMaker detailed metrics and Insights dashboard](https://aws.amazon.com/blogs/machine-learning/monitor-and-debug-generative-ai-inference-with-sagemaker-detailed-metrics-and-insights-dashboard-on-cloudwatch/)** — SageMaker now surfaces detailed per-request inference metrics and an Insights dashboard in CloudWatch for both single-model and inference-component endpoints. If your OCR/RAG pipeline runs on SageMaker endpoints, this closes a visibility gap that's been painful for debugging latency spikes. `[SHARE w/ engineering team]`

- **[Introducing Gemini Omni](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)** — Google releases Gemini Omni, a new multimodal model. No detailed benchmarks in the source data; worth a look if you're evaluating document AI alternatives to Azure AI, given its multimodal strengths. `[SKIP]` *(Note for later: revisit when technical evals appear)*

- **[codebase-memory-mcp](https://github.com/DeusData/codebase-memory-mcp)** — MCP server that indexes a codebase into a persistent knowledge graph (158 languages, sub-ms queries, 99% fewer tokens, single static binary). If your teams are context-window-constrained on large repos in Claude Code, this is worth a quick test. 7k stars and growing fast. `[TRY]`

- **[TesterArmy — Agents that test web and mobile apps (YC P26)](https://tester.army)** — Agentic E2E testing platform: write tests in natural language, agent executes and maintains them. Coding agents can manage the whole platform via API. Early but directionally interesting for teams that maintain manual test suites. `[SHARE w/ engineering team]`
