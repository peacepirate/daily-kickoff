# AI Digest — Friday, July 11, 2026
*Coverage window: previous 24 hours*

## TL;DR
Quiet end to one of the busiest model-release weeks on record — Claude Fable 5, Grok 4.5, Gemini Omni, and GPT-5.6 (Luna/Terra/Sol) all shipped Mon–Thu, and today Latent Space literally titled their recap "not much happened today." The most actionable item for your work: AWS published the setup guide for the Claude apps gateway, a self-hosted control plane that gives you central auth, cost caps, and policy enforcement for Claude Code across your teams via Bedrock.

## What's New

- **[Introducing Claude apps gateway for AWS](https://aws.amazon.com/blogs/machine-learning/introducing-claude-apps-gateway-for-aws/)** — Self-hosted control plane that gives orgs a single point of control over access, cost, and policy for Claude Code and Claude Desktop, wired to Amazon Bedrock and Claude Platform. This is the governance layer that's been missing for multi-team Claude Code rollouts — central auth, spend visibility, and policy enforcement without routing traffic through a third party. [READ DEEPER] [TRY]

- **[The new GPT-5.6 family: Luna, Terra, Sol](https://simonwillison.net/2026/Jul/9/gpt-5-6/#atom-everything)** — OpenAI's new flagship hits GA in three sizes: Luna ($1/$6 per 1M in/out), Terra ($2.50/$15), Sol ($5/$30). For context, Claude Opus is $5/$25 and Claude Fable 5 is $10/$50. All three have a 1M token context and 128K max output. Grok 4.5 and Gemini Omni also launched this week, making it the densest multi-lab model drop of the year. [SKIP] unless you're actively benchmarking for multi-model strategy.

- **[Expanding Managed Agents in Gemini API: background tasks, remote MCP and more](https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api/)** — Google added background task execution and remote MCP server support to the Gemini API's managed agents feature bundle. The remote MCP angle matters: your teams can now target the same MCP servers from Gemini-based agents as from Claude Code. Competitive parity with Anthropic's agent infrastructure is accelerating. [SHARE w/ engineering team]

- **[MCP tool design: Practical approaches and tradeoffs](https://aws.amazon.com/blogs/machine-learning/mcp-tool-design-practical-approaches-and-tradeoffs/)** — AWS post on where MCP tool schemas go wrong and how to fix them with practical context engineering. Covers naming, parameter design, and schema patterns that improve model tool-selection accuracy. Send this to any team that has already shipped or is about to ship MCP tools. [SHARE w/ engineering team]

- **[Introducing Mistral OCR 4](https://mistral.ai/news/ocr-4/)** — Mistral's new document intelligence model, claimed state of the art. The release note is light on benchmarks, but Mistral has been competitive on document tasks. Given your OCR/Azure AI Search pipeline for small-business card underwriting, worth pulling a sample doc set and running a head-to-head. [READ DEEPER]

- **[Quoting Kenton Varda](https://simonwillison.net/2026/Jul/8/kenton-varda/#atom-everything)** — Cloudflare's infrastructure lead declared a moratorium on AI-written PR and commit descriptions on his team. The failure mode: models summarize what the code does (visible in the diff) but omit the higher-level framing a reviewer needs to understand why. As your teams ramp up agentic coding, this is the norm to set early. [SHARE w/ engineering team]

- **[Mesh LLM: distributed AI computing on iroh](https://www.iroh.computer/blog/mesh-llm)** — Peer-to-peer distributed LLM inference across multiple machines using the iroh network library. Early-stage but the underlying transport layer is production-grade. Worth a quick test if you're exploring local inference options beyond single-node setups. [TRY]

## Personal / Side-Project Watch

- **[Fixed three bugs that made Qwen3.5-122B a daily driver on Mac Studio](https://mrzk.io/posts/qmlx-maximising-ai-psychosis-minmaxing-mac-studio/)** — Practical mlx fixes for running a 122B local model reliably on Apple Silicon. If local inference quality has felt inconsistent, the bug fixes here (quantization and context window handling) may be the root cause.
