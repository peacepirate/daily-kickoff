## TL;DR

Anthropic pushed two enterprise moves — a Financial Advisors product and pooled-budget/reporting admin tools — both relevant to running Claude Code across a regulated-industry org. AWS published a strong AgentCore Gateway case study on turning 400 internal APIs into agent tools, plus a reusable Kiro-based legacy migration pattern. Mistral shipped Large 4 and an open coding/cybersecurity model; LangChain's Deep Agents gained browser use.

## What's New

- **[Claude for Financial Advisors](https://releasebot.io/updates/anthropic#Claude-for-Financial-Advisors)** — Anthropic's first named vertical product for regulated finance. Same compliance terrain you work in on the underwriting side — worth knowing what Anthropic considers "safe enough" to ship for this industry. [SHARE w/ leadership]
- **[Smart reports, surveys, and pooled group budgets for Claude Enterprise](https://releasebot.io/updates/anthropic#Smart-reports,-surveys,-and-pooled-group-budgets-for-Claude-Enterprise)** — admin-side features for tracking usage and sharing budget across groups. Relevant once Claude Code spend spans more than a couple of teams. [SHARE w/ leadership]
- **[Docling v2.145.0](https://github.com/docling-project/docling/releases/tag/v2.145.0)** — adds page-orientation detection for RapidOCR, among other fixes. Directly on-target for document ingestion where scans arrive rotated. [TRY]
- **[How MoEngage turned over 400 APIs into agent tools with AgentCore Gateway](https://aws.amazon.com/blogs/machine-learning/how-moengage-turned-over-400-apis-into-agent-tools-with-agentcore-gateway/)** — OpenAPI specs + Cedar policies + VPC Lattice egress, no per-service MCP server and no 400-tool context bloat. A concrete pattern for agent-tool sprawl at scale. [SHARE w/ engineering team]
- **[Build a repeatable PHP-to-Java migration engine with Kiro](https://aws.amazon.com/blogs/machine-learning/build-a-repeatable-php-to-java-migration-engine-with-kiro/)** — treats the legacy app as the spec, verifies the port with a parity harness. A reproducible agentic-coding pattern beyond one-off "vibe migrate." [READ DEEPER]
- **[Managed Deep Agents v0.10: Browser Use and Async Subagents](https://www.langchain.com/blog/managed-deep-agents-browser-use-and-asynchronous-subagents)** — agents can now drive a real browser (with a handoff for sign-in) and run subagents in the background. [TRY]
- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — new flagship, alongside an open-weight release ("Le Chonk") targeting agentic coding and cybersecurity. Baseline-worth-knowing, not an action item. [READ DEEPER]

## Personal / Side-Project Watch

**[llama.cpp b12002](https://github.com/ggml-org/llama.cpp/releases/tag/b12002)** adds a generic batched tensor copy API, cutting context-io overhead — a small but real local-inference speedup if you're still running models on the Mac Studio.
