## What's New

- **[Optimizing cost and latency with Amazon Bedrock prompt caching](https://aws.amazon.com/blogs/machine-learning/optimizing-cost-and-latency-with-amazon-bedrock-prompt-caching/)** — Walks through six prompt-caching scenarios on the Converse API: message content, system prompt, tool definitions, mixed TTL, tenant isolation, and LangChain integration. Claims up to 90% input token cost reduction when context repeats. Directly testable against your Bedrock-backed ingestion prompts. [TRY]
- **[Introducing Gemini 3.8 Live and 3.8 Live Extended Thinking](https://deepmind.google/blog/introducing-gemini-3-8-live-and-3-8-live-extended-thinking/)** — Google's new speech-to-speech model family, positioned against OpenAI's GPT-Live line. No enterprise/Bedrock angle yet, but a new model release from a major lab is worth knowing about. [SHARE w/ product team]
- **[Scaling Agents in Healthcare & Life Sciences](https://www.langchain.com/blog/scaling-agents-in-healthcare-life-sciences-lessons-from-madrigal-pharmaceuticals-abridge-and-vizient)** — Lessons from three companies building agents where data is fragmented across systems and a wrong answer carries real cost. Same shape of constraint as regulated underwriting workflows. [READ DEEPER]
- **[Modernizing complex legacy code with AI agents](https://mistral.ai/news/legacy-code-modernization/)** — Mistral's writeup on using agents for legacy code modernization. A reproducible pattern, not just a benchmark claim. [SHARE w/ engineering team]
- **[addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)** — A curated, open-source set of "production-grade" skills for AI coding agents. Worth a skim against what your teams already maintain for Claude Code. [TRY]
- **[alibaba/open-code-review](https://github.com/alibaba/open-code-review)** — Hybrid deterministic-pipeline + LLM-agent code review tool, line-level comments, built-in ruleset for NPE/thread-safety/XSS/SQL injection, OpenAI and Anthropic compatible. [SHARE w/ engineering team]
- **[Cognee v1.5.4rc1 — Hybrid Retrieval, Structured Evidence, and Safer MCP Packaging](https://github.com/topoteretes/cognee/releases/tag/v1.5.4rc1)** — Adds a context-primed query decomposition retriever and tightens MCP server/telemetry hardening. Relevant to RAG/memory-layer evaluation. [READ DEEPER]
