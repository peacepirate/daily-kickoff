## TL;DR

OpenAI shipped GPT-6 Astra, its biggest launch to date, priced level with Claude Fable. The more useful thread for your day job: two document-review benchmarks (Legora, Mistral Agentic Search) land squarely on your underwriting-doc-ingestion turf, and Anthropic/AWS both published fresh Claude Code + Bedrock AgentCore material worth routing to your teams.

## What's New

- **[GPT-6 Astra](https://openai.com/index/gpt-6-astra/)** — OpenAI's biggest LLM launch to date: SOTA computer-use and coding scores, rolling out to ChatGPT Plus/Pro/Business/Enterprise, the API, and AWS. API pricing ($10/M in, $50/M out) matches Claude Fable. Worth a look now that it's on AWS and price-competitive with what you're already running on Bedrock. [READ DEEPER]

- **[How we built Claude Code auto mode: a safer way to skip permissions](https://www.anthropic.com/engineering/claude-code-auto-mode)** — Anthropic's engineering writeup on the design behind auto mode. Permission-prompt friction is a real adoption blocker for your teams; this explains what's actually being relaxed and what stays gated. [TRY]

- **[Which tools do Claude, Codex and Cursor choose? We measured 17k runs to find out](https://armature.tech/blog/which-tools-coding-agents-install)** — Empirical data on which tools coding agents reach for across 17k runs. Useful input for standardizing the tool/skill set your 6–10 teams give their agents, rather than guessing. [SHARE w/ engineering team]

- **[Legora reviewed 41 documents in minutes with GPT-6 Astra](https://openai.com/index/legora-financial-statement-review-with-astra)** — Legora used Astra to review 41 financial documents, catch all four planted errors, and improve accuracy ~40% over the prior model. Same problem shape as your underwriting document review — worth benchmarking against your current OCR/RAG pipeline. [SHARE w/ product team]

- **[AI-driven development lifecycle using Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/ai-driven-development-lifecycle-using-amazon-bedrock-agentcore/)** — Two reference implementations (SQL-to-ER-diagram generator, multi-agent code security analyzer) built on Bedrock AgentCore, Kiro, and Claude Code. A concrete pattern you can borrow directly since you're already on Bedrock. [SHARE w/ engineering team]

- **[An update on recent Claude Code quality reports](https://www.anthropic.com/engineering/april-23-postmortem)** — Anthropic's postmortem on recent Claude Code quality issues. Good to have on hand if leadership raises questions about the reliability of the tool your teams depend on. [SHARE w/ leadership]

- **[Agentic Search](https://mistral.ai/news/agentic-search/)** — Mistral's new retrieval layer for helping AI systems navigate, read, and verify information inside complex documents. Directly adjacent to your RAG work — worth comparing against your current retrieval approach. [READ DEEPER]

- **[Docling v2.125.0](https://github.com/docling-project/docling/releases/tag/v2.125.0)** — OCR/VLM parsing fixes: better table-vs-form handling, a min-version check for VLM engines, CUDA support for RapidOCR. Relevant maintenance if Docling sits anywhere in your ingestion stack. [SHARE w/ engineering team]

## Personal / Side-Project Watch

- **[Ollama v0.33.3](https://github.com/ollama/ollama/releases/tag/v0.33.3)** — gemma4 now supports images and audio on the MLX engine, plus cached prompt token reporting. Minor, but worth knowing if you're running local models for experimentation.
