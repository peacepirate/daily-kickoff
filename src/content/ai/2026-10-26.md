## TL;DR

Mistral shipped Large 4, a new frontier model. Anthropic published engineering guidance on when to keep subagents folded into your main loop instead of spinning up new ones — relevant to how your teams structure Claude Code workflows. Ollama added small on-device classification models and local speech generation. A few new open-source Claude Code skills (security audits, anti-slop design) hit GitHub Trending, worth a look for your engineering teams.

## What's New

- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — New flagship model from Mistral. Mistral models run on Bedrock, so this is a candidate if you ever want a second model behind your underwriting pipeline for comparison or cost reasons. [READ DEEPER]

- **[Building agents: When to fold subagents into your main agent loop](https://releasebot.io/updates/anthropic#Building-agents:-When-to-fold-subagents-into-your-main-agent-loop)** — Anthropic engineering guidance on when subagent architectures add overhead instead of value. Directly applicable to how you're structuring Claude Code workflows across your 6–10 teams. [SHARE w/ engineering team]

- **[Claude Cowork and chat come together for Enterprise](https://releasebot.io/updates/anthropic#Claude-Cowork-and-chat-come-together-for-Enterprise)** — Claude's Cowork workspace features are merging with chat at the Enterprise tier. You're on Bedrock, not Claude Enterprise, but this signals where Anthropic is pointing the product. [SHARE w/ leadership]

- **[Ollama v0.40.11](https://github.com/ollama/ollama/releases/tag/v0.40.11)** — Adds on-device speech generation on macOS and ships "d3," a family of small decision/classification models (2B–27B) for scoring and routing text, structured state, or images. The classification angle is worth testing as a cheap pre-filter ahead of your OCR/RAG stack. [TRY]

- **[The five components of building a "company harness"](https://www.langchain.com/blog/components-building-company-harness)** — LangChain's writeup on scaling internal agents across marketing, sales, and engineering teams. Same org-wide rollout problem you're working on. [READ DEEPER]

- **[PaperPilot – Zero-Cloud, Pure-Rust PDF Engine with WASM and MCP](https://github.com/KrushnaVardhanReddy/PaperPilot)** — Open-source, fully local PDF engine with MCP support. Worth a look for document-ingestion work where on-prem/offline processing is a hard requirement. [READ DEEPER]

- **[cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)** — New Claude Code skill for multi-phase security audits with independently verified, machine-readable findings. Could slot into a code-review gate for Claude Code-generated changes. [TRY]

- **[Nutlope/hallmark](https://github.com/Nutlope/hallmark)** — "Anti-AI-slop" design skill for Claude Code, Cursor, and Codex, meant to push agentic coding tools away from generic UI output. [SHARE w/ engineering team]
