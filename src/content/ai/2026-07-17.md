## TL;DR
Moderate day. Mistral shipped OCR 4, its next-gen document intelligence model — worth testing against your underwriting doc corpus. AWS published a detailed architecture writeup on how Smartsheet built a remote MCP server on AWS, directly useful if a team wants to expose internal tools via MCP. Google also pushed several Gemini updates (Omni, Flash/Lite variants, and computer use in 3.5 Flash); Claude Code, Anthropic, and OpenAI each shipped a string of patch releases with no changelog detail surfaced in the feed.

## What's New

- **[Introducing Mistral OCR 4](https://mistral.ai/news/ocr-4/)** — Mistral's next-gen document intelligence model. If it holds up on messy underwriting scans, it's a candidate to simplify or replace parts of your OCR pipeline. [TRY]

- **[How Smartsheet built a remote MCP server on AWS](https://aws.amazon.com/blogs/machine-learning/how-smartsheet-built-a-remote-mcp-server-on-aws/)** — Walks through the actual AWS infrastructure behind a production remote MCP server: security, governance, scaling, and AI-specific optimizations. A concrete blueprint if any of your teams want to expose internal tools to Claude Code or Bedrock agents via MCP. [READ DEEPER]

- **[Introducing Gemini Omni](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)** — Google's new flagship model, alongside cheaper [Nano Banana 2 Lite / Gemini Omni Flash](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni-flash-nano-banana-2-lite/) variants for production use. Not Bedrock-native, but shifts the competitive landscape you're weighing model choices against. [SHARE w/ leadership]

- **[Introducing computer use in Gemini 3.5 Flash](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-computer-use-gemini-3-5-flash/)** — Google extends browser/OS agent control to its fast, cheap tier — the same pattern Anthropic pioneered with Claude computer use, now at a lower price point. Worth tracking for future automation pilots. [READ DEEPER]

- **[Your Prompts and Skills need a system of record](https://mistral.ai/news/manage-prompts-and-skills-in-studio/)** — Mistral Studio adds versioned, owned, traceable storage for prompts and skills. Relevant if your teams' Claude Code skills and prompts are scattered across repos with no governance. [SHARE w/ engineering team]

- **[Nutlope/hallmark](https://github.com/Nutlope/hallmark)** — An anti-AI-slop design skill for Claude Code, Cursor, and Codex, trending on GitHub. Worth a quick install to see if it catches generic-looking output before it hits review. [TRY]

- **[tirth8205/code-review-graph](https://github.com/tirth8205/code-review-graph)** — Local-first code intelligence graph for MCP and CLI; builds a persistent map of a codebase so agents read only what matters, with benchmarked context reductions on reviews and large-repo workflows. Directly relevant to scaling agentic coding across 6-10 teams without blowing context budgets. [TRY]

- **[RyanCodrai/turbovec](https://github.com/RyanCodrai/turbovec)** — A vector index built on TurboQuant, in Rust with Python bindings, trending on GitHub. Worth a look if you're evaluating alternatives to your current Azure AI Search vector layer for the underwriting RAG pipeline. [READ DEEPER]

## Personal / Side-Project Watch
- **[Open Interpreter](https://github.com/openinterpreter/openinterpreter)** now bills itself as a coding agent for open models like Kimi K3 — an option if you want to experiment with local/open-weight coding agents for Gods of the Future Past content generation without routing through paid APIs.
