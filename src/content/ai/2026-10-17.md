## TL;DR

Gemini 4 Argon went GA this week, matching the frontier pace from Anthropic and Mistral — Gemini, Mistral Large 4, and Meta's new Muse Wonder all shipped flagship-tier models within days of each other, so expect another round of price/performance comparisons before your next Bedrock model pick. Anthropic's Code Review hit general availability, and a quote making the rounds this week describes exactly what GA code review looks like in practice: continuous AI review before a human ever opens the PR — worth testing against your own teams' review gates. AWS kept building out the Bedrock AgentCore stack, with a new nine-stage evaluation framework for catching silent agent-quality regressions as the most directly useful post of the week for your doc-ingestion evals, alongside a self-improving document-processing pattern already flagged Thursday. Compliance stayed on the agenda: Arize published both a piece on why agents can't verify their own permissions and an EU AI Act engineering guide, both worth a leadership conversation given your regulated environment. The document-AI stack saw steady, incremental news — two Docling releases and a Weaviate security patch worth applying if you're running vector search.

## Tier 2 — Curator Picks

- **[Quoting Addy Osmani, Morgan Westlee Lunt, and Qing Wang](https://simonwillison.net/2026/Oct/16/code-review/)** — "Most changes have been reviewed and fixed by Claude at least once before a human is asked to look." Describes the practice Code Review GA (above) is built for — review running continuously, like spellcheck, rather than as an end-of-road gate. [SHARE w/ engineering team]
- **[Quoting Geoffrey Huntley](https://simonwillison.net/2026/Oct/13/geoffrey-huntley/)** — Huntley's fix for agents bypassing a required module: a pre-commit hook that greps the diff, fails the commit, and injects a prompt telling the agent to use the right module instead. A concrete enforcement mechanism for the AGENTS.md-drift problem, worth testing on one convention your teams keep breaking. [TRY]
- **[Context Engineering with Deep Agents: How To Remember Without Keeping Everything In Context](https://www.langchain.com/blog/context-engineering-deep-agents-remember)** — Offloading, summarization, skills, subagents, and memory as the five techniques for long-running agents that don't degrade. Already covered Thursday. [SKIP]
- **[The Most Common Questions About Agent Evals, Answered](https://www.langchain.com/blog/common-questions-about-agent-evals)** — Where to start with agent evals, offline vs. online, LLM judges. Already covered Thursday. [SKIP]
- **[Four evaluation engineering lessons learned from building agent plugins](https://cloud.google.com/blog/topics/developers-practitioners/four-eval-engineering-lessons/)** — A second independent eval-engineering writeup this week, from building the Google Cloud Developer plugin. Worth reading alongside AWS's framework (above) for what both agree matters: measurement, not construction, is the hard part. [READ DEEPER]
- **[AI agent permissions: Why agents don't know what you're allowed to do](https://arize.com/blog/ai-agent-permissions/)** — A model can't reliably verify a claimed permission just from conversation. Direct relevance as you expand agent autonomy in a regulated environment — this is the gap between "the agent refused" and "the agent overstepped." [SHARE w/ engineering team]
- **[EU AI Act compliance for AI agents: a practical engineering guide](https://arize.com/blog/eu-ai-act-compliance-ai-agents/)** — Agent traces, human oversight, production evals, and log retention mapped to a credit-assistant example, close to your underwriting domain. Already covered Wednesday. [SHARE w/ leadership]
- **[Weaviate security release - nearObject vector disclosure](https://weaviate.io/blog/weaviate-security-release-nearobject-2026)** — v1.39.3 fixes a medium-severity authorization issue letting nearObject queries leak vectors across collections. Patch now if any RAG work runs on Weaviate. [SHARE w/ engineering team]
- **[PathSeer: Adaptive Filtered Vector Search](https://weaviate.io/blog/pathseer-filtered-vector-search)** — A third HNSW filter strategy for Weaviate 1.40, from a SIGMOD 2026 paper. Worth comparing against ACORN/sweeping on a real filtered-RAG query. [TRY]
- **[Everything we shipped in the Zep Context API](https://www.getzep.com/blog/what-shipped-in-the-context-api/)** — Entity hierarchies, a graph assistant, and hyperedges (facts spanning three or more entities). Not in your stack, but the hyperedge concept is worth knowing if your RAG graph work ever needs multi-entity facts. [SKIP]
- **[DSPy 3.4.1](https://github.com/stanfordnlp/dspy/releases/tag/3.4.1)** — Makes GEPA's structured instruction proposer the default, adds Python 3.15 support. Routine point release. [SKIP]
- **[Ollama v0.40.6](https://github.com/ollama/ollama/releases/tag/v0.40.6)** — Fixes an orphaned-runner bug and adds q2_0 tensor support. Relevant if your local-LLM side project runs Ollama. [TRY]
- **[Anthropic tells investors quarterly revenue up nearly 50% to $16.8bn ahead of IPO](https://simonwillison.net/2026/Oct/15/anthropic-tells-investors/)** — Q3 revenue $16.8bn, $1.70 earned per $1 spent on compute. Financial, not capability — noted for completeness given you run Claude via Bedrock. [SKIP]
- **[[AINews] Meta Muse Wonder & Wonder Full: MSL's Claude 5.5-tier Frontier Model](https://www.latent.space/p/ainews-meta-muse-wonder-and-wonder)** — MSL's (Meta Superintelligence Labs) new frontier-class model, benchmarked near GPT-6.1 Sol tier. A fourth major-lab model release this week, after Gemini 4 Argon and Mistral Large 4. [SHARE w/ engineering team]
