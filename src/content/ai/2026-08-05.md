# AI Digest — Wednesday, August 5, 2026
*Coverage window: previous 24 hours*

## TL;DR
Most of today's Tier 1 feed is the same unchanged repeat from last week — Opus 5, the MCP 2026-07-28 update, and all four Anthropic engineering posts haven't moved since before 07-31. The real news is two fresh AWS Bedrock posts (native web-search grounding, and an AgentCore recipe for turning scraped web content into searchable insights), plus a major LLM CLI release from Simon Willison with visible reasoning traces and confirmed support for the claude-opus-5/sonnet-5/fable-5 lineup. Latent Space also has a solid technical teardown of OpenAI's new ChatGPT Work agent, worth a competitive-reference read.

## What's New

- **[Introducing Web Search on Amazon Bedrock for foundation model grounding](https://aws.amazon.com/blogs/machine-learning/introducing-web-search-on-amazon-bedrock-for-foundation-model-grounding/)** — Native, server-side web grounding for Bedrock models: no third-party vendor to onboard, no external API to orchestrate, no extra security review. Directly usable in your document-ingestion stack anywhere a model needs current external context. [TRY]

- **[Automated web insight extraction with Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/automated-web-insight-extraction-with-amazon-bedrock-agentcore/)** — A reference pipeline using AgentCore Browser, Bedrock, OpenSearch Serverless, and Lambda to monitor RSS feeds, render pages reliably, and make AI-extracted insights searchable. A reusable pattern for any "watch these sources and surface what matters" job. [SHARE w/ engineering team]

- **[New release of LLM adds support for reasoning traces, OpenAI Responses, server-side tools, and smarter logging](https://simonwillison.net/2026/Aug/4/new-release-of-llm/#atom-everything)** — LLM 0.32 now shows reasoning-model "thinking" traces to stderr, and the companion llm-anthropic 0.26 adds the new claude-opus-5, claude-sonnet-5, and claude-fable-5 model IDs plus server-side WebSearch/WebFetch/CodeExecution/AnthropicMCP tools via a `-T` interface. Confirms the Opus 5 lineup is now live in the tooling, even though Anthropic's own announcement is a repeat. [TRY]

- **[Unpacking ChatGPT Work: the Agent for a Billion Users](https://www.latent.space/p/unpacking-chatgpt-work)** — An outside reconstruction of how OpenAI's new agent handles Memory, Proactivity, Scheduling, Browser Use, Plugins, Skills, and Tools. Good competitive read against how Claude Code's own agentic surface is evolving. [READ DEEPER]

- **[uber/ADR](https://github.com/uber/ADR)** — Open-source framework for observability, security benchmarking, and threat detection on enterprise AI agents, running in production at Uber. Worth a look as your teams push further into autonomous Claude Code workflows. [SHARE w/ engineering team]

## Personal / Side-Project Watch

- **[Show HN: Maple-Preview](https://deepgrove.ai/maple-preview)** — A ternary 20B MoE model running at 120 tok/s on an iPhone. A strong on-device inference data point if you pick local-LLM experiments back up.
- **[PipeNetwork/minimax-h3-mlx](https://simonwillison.net/2026/Aug/4/minimax-h3-mlx/#atom-everything)** — MLX port of MiniMax's omni-modal H3 model for Apple Silicon (text/image/audio/video in, short video clips with audio out). Confirmed running on an M5 Max MacBook Pro — relevant if you're testing local models for Gods of the Future Past.
