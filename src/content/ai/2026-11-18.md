## TL;DR

OpenAI shipped GPT-6.2 Astra and Sol, its next frontier pair, cheaper than the last generation but with mixed early reviews on real coding quality. Mistral released Large 4 as open weights, aimed at agentic coding and cybersecurity defense. The more useful story today is infrastructure: AWS and the agent-sandboxing community both published concrete, testable patterns for running coding agents safely and cheaply.

## What's New

- **[Introducing GPT-6.2 Astra and Sol](https://openai.com/index/introducing-gpt-6-2-astra-sol)** — OpenAI's new pair: Astra for hard tasks, Sol as the everyday workhorse, both priced below their predecessors (Astra at 80% of the prior price). Early testers disagree on whether Astra's actual coding feel matches its benchmark gains. Worth a quick eval if your teams benchmark models for agentic coding, but don't switch on benchmark numbers alone. [SHARE w/ engineering team]

- **[External sandboxes for coding agents](https://simonwillison.net/2026/Nov/17/external-sandboxes-for-coding-agents/)** — A pattern where code the agent executes runs inside a dedicated sandbox while the agent itself lives outside it, so a mistake or a prompt-injection attack can't reach the host machine. Directly applicable to how you scope Claude Code's file and shell access across teams in a regulated shop. [READ DEEPER] — worth 20 min: this shapes how you'd architect agent sandboxing before your next security review.

- **[How to Choose the Right Sandbox for AI Agents](https://www.langchain.com/blog/how-to-choose-the-right-sandbox-for-your-agent)** — A practical checklist: filesystem isolation, network access, resource limits, containers vs microVMs. Pairs with the item above — gives your teams a decision framework instead of ad hoc permission rules. [SHARE w/ engineering team]

- **[Reducing token costs and latency in Amazon Bedrock AgentCore JSON workloads](https://aws.amazon.com/blogs/machine-learning/reducing-token-costs-and-latency-in-amazon-bedrock-agentcore-json-workloads/)** — Three composable techniques — offload large artifacts to S3, page results on demand, compact dictionaries — cut token use up to 71% and latency up to 80% for agents handling big JSON payloads. Directly testable against any Bedrock agent in your document-ingestion pipeline that's passing large OCR or extraction output through context. [TRY] — pick one agent with large JSON payloads and test the S3-offload step this week.

- **[Cut generative AI costs: Code for rules, models for judgment](https://aws.amazon.com/blogs/machine-learning/cut-generative-ai-costs-code-for-rules-models-for-judgment/)** — A framework for deciding, step by step, whether a workflow stage needs a model call at all, versus deterministic code or a constrained decision call. Useful lens for auditing your underwriting document pipeline — some steps dressed up as "AI" may just be rules. [SHARE w/ engineering team]

- **[Govern and discover records with common metadata in AWS Agent Registry](https://aws.amazon.com/blogs/machine-learning/govern-and-discover-records-with-common-metadata-in-aws-agent-registry/)** — Typed, validated metadata schemas so every agent, MCP server, and skill in an org carries the same governance fields, trackable from registration through approval. Relevant as MCP and agent adoption scales past a handful of teams — this is the kind of governance layer a regulated company eventually has to ask for. [READ DEEPER] — why: governance will become a live question as MCP servers multiply across your 6–10 teams.

- **[Le Chonk: Built for Coders, Trusted by Defenders](https://mistral.ai/news/mistral-large-4-oss/)** — Mistral released Large 4's weights, pitched squarely at agentic coding and cybersecurity defense work. An open-weight option worth knowing about if any team wants an on-prem or local alternative to Bedrock-hosted models. [SHARE w/ engineering team]

- **[Put Gemini to work for you](https://blog.google/innovation-and-ai/products/gemini-app/tasks-in-gemini-free-new-features/)** — Google added a "what can I get done for you" task-delegation UI to the consumer Gemini app. Signal that agentic task UX is becoming table stakes for consumer assistants; no action needed.
