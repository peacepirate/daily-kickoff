## What's New

- **[Four layers of context engineering for production AI agents: How Deep Insight applies them in working code](https://aws.amazon.com/blogs/machine-learning/four-layers-of-context-engineering-for-production-ai-agents-how-deep-insight-applies-them-in-working-code/)** — AWS lays out a four-layer framework (architecture, prompts, file-based tools, verification agents) for the real bottleneck in production agents: context management. Implemented in working code on Strands Agents SDK and Bedrock AgentCore. [TRY]

- **[Use decision models with Amazon Bedrock AgentCore Evaluations](https://aws.amazon.com/blogs/machine-learning/use-decision-models-with-amazon-bedrock-agentcore-evaluations/)** — Shows how to wire narrow, repeatable evaluation questions into code-based evaluators (Jev, Strands Decider) and validate a check before gating a release on it. A pattern for making agent evals a hard gate rather than a vibe check. [TRY]

- **[Smart Approvals in Amazon Quick: Human oversight where it matters](https://aws.amazon.com/blogs/machine-learning/smart-approvals-in-amazon-quick-human-oversight-where-it-matters/)** — A policy set defines the boundary, a classifier reviews each agent action against it, and only consequential actions still need a human sign-off. CloudTrail and CloudWatch Logs carry the audit trail. Directly relevant to how much human-in-the-loop governance an underwriting agent needs to keep. [SHARE w/ leadership]

- **[Le Chonk: Built for Coders, Trusted by Defenders](https://mistral.ai/news/mistral-large-4-oss/)** — Mistral open-sourced the weights behind Mistral Large 4, aimed at agentic coding and cybersecurity work. Worth knowing as an open alternative when a Bedrock-hosted model isn't the right fit for a given workload. [SHARE w/ engineering team]

- **[Web Scraping for RAG: Build a Reliable Pipeline with Zyte API, Qdrant and LangChain](https://www.zyte.com/blog/uninterrupted-web-data-for-rag-pipelines/)** — Reproducible walkthrough of a RAG pipeline that fetches LLM-ready Markdown through bot blocks and JS-rendered pages, gates bad pages, and tests before deploy. [READ DEEPER]

- **[garrytan/gstack](https://github.com/garrytan/gstack)** — Trending repo packaging 23 opinionated Claude Code tools covering CEO, designer, eng manager, release manager, doc engineer, and QA roles. Worth a look as a reference setup when standardizing Claude Code usage across your teams. [TRY]

- **[max-sixty/worktrunk](https://github.com/max-sixty/worktrunk)** — A CLI for git worktree management built specifically for parallel AI agent workflows — several agents working the same repo without colliding. Solves a real friction point as agentic coding scales past one dev at a time. [SHARE w/ engineering team]
