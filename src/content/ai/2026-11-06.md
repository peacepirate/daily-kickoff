## What's New

- **[Getting started with Web Answer on Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/getting-started-with-web-answer-on-amazon-bedrock-agentcore/)** — New AgentCore tool returns a synthesized, source-cited answer to a natural-language question in one call, no separate search/retrieve/synthesize/cite pipeline needed. Worth testing against your current RAG retrieval path for underwriting Q&A. [TRY]

- **[How Amazon Marketplace evaluates content quality with Amazon SageMaker AI](https://aws.amazon.com/blogs/machine-learning/how-amazon-marketplace-evaluates-content-quality-with-amazon-sagemaker-ai/)** — Amazon renders product pages as single snapshots, scores them with a vision-language model fused with OCR readability signals in a CatBoost classifier, then uses SHAP to turn each decision into a prioritized fix-it recommendation. The scoring and explainability pattern maps directly onto confidence-scoring OCR-extracted fields in your underwriting documents. [READ DEEPER]

- **[Docling v2.148.0](https://github.com/docling-project/docling/releases/tag/v2.148.0)** — Adds surya v2.5 OCR support and detects superscript/subscript text from glyph size and baseline, plus several PDF/table parsing fixes. Relevant if your document pipeline touches footnoted or annotated financial docs. [SHARE w/ engineering team]

- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — Mistral's new flagship ("Le Chonk"), open-weighted and tuned for agentic coding and cybersecurity use cases. Another open-weight frontier option alongside what you're already evaluating on Bedrock. [READ DEEPER]

- **[Anthropic: More visibility and control over Claude Enterprise for security teams](https://releasebot.io/updates/anthropic#More-visibility-and-control-over-Claude-Enterprise-for-security-teams)** — Expanded admin visibility and access controls for Claude Enterprise. Relevant to a regulated shop's security review of any Claude Enterprise usage outside Bedrock. [SHARE w/ leadership]

- **[How We Optimized Browser Use for Deep Agents](https://www.langchain.com/blog/how-we-optimized-browser-use-for-deep-agents)** — LangChain compared seven browser toolsets, picked Stagehand (Browserbase), then tuned it using LangSmith traces and evals — a concrete, reproducible agent-eval workflow, not just a tool pick. [READ DEEPER]

- **[Announcing Zep Agent Skills](https://www.getzep.com/blog/introducing-zep-agent-skills/)** — Turns repeated agent runs into verified procedures; Zep claims smaller models then perform at or near Opus 5.5 on business-task benchmarks. If it holds up, that's a cost lever for any agent you're running at volume. [TRY]

- **[Is the cheap model good enough? How to test a new model in your agent](https://arize.com/blog/how-to-test-a-new-model-in-your-agent/)** — Step-by-step: traces → eval dataset built from those traces → pass rate, cost-per-solved-problem, and latency comparison against a frontier model. A reusable template for any "can we downgrade this agent's model" decision. [TRY]

## Personal / Side-Project Watch

- **[Ollama v0.40.15](https://github.com/ollama/ollama/releases/tag/v0.40.15)** — Adds support for MiMo V2.6, a 9B code/agent model, plus new "AutoTrust" decision models (9B/35B/27B-VL) that read text or images and return yes/no probabilities for classification-style questions. Worth a look if local inference ever fits into a Gods of the Future Past content-moderation or classification step.
