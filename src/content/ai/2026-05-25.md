## TL;DR

DeepSeek V4, Gemini Omni, Gemini 3.5, and Mistral Medium 3.5 all landed over the weekend — a rare four-model day across three labs. Claude Code shipped 10 rapid-fire point releases (2.1.140–2.1.150). A widely-discussed piece arguing AI helps you write code "more slowly" is a useful reframe for teams you're coaching on agentic adoption.

## What's New

- **[DeepSeek V4 Preview](https://mp.weixin.qq.com/s/8bxXqS2R8Fx5-1TLDBiEDg)** — DeepSeek drops V4 with claimed world-class reasoning and a major jump in agent capabilities, now live on web, app, and API. Given the V3 disruption in early 2025, V4 is worth a benchmark run — especially if your teams are evaluating open-weight alternatives to Claude on Bedrock. [TRY]

- **[Introducing Gemini Omni](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)** — Google's new flagship multimodal model. No technical depth in the announcement yet, but the Omni naming convention signals full audio/video/text native capability, not bolted-on. Watch for Bedrock availability. [READ DEEPER]

- **[Gemini 3.5: frontier intelligence with action](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-5/)** — Gemini 3.5 positions explicitly around agentic tool use. Google dropped two significant models in one weekend; their agentic story is accelerating. Relevant if your org is evaluating non-Anthropic paths on Bedrock. [READ DEEPER]

- **[Mistral Medium 3.5 + remote coding agents in Vibe](https://mistral.ai/)** — Mistral ships a new mid-tier model alongside remote coding agents in their Vibe product, plus a "Work mode" in Le Chat for complex tasks. Mistral is now building full agent infrastructure, not just releasing weights. Worth tracking as a potential lighter-weight Claude Code alternative for constrained environments. [READ DEEPER]

- **[Claude Code 2.1.140–2.1.150](https://releasebot.io/updates/anthropic/claude-code#2.1.150)** — Ten point releases over the weekend. The releasebot source doesn't include changelogs, but the velocity signals active iteration. Check the in-app changelog (`/release-notes`) for specifics on what shipped. [SHARE w/ engineering team]

- **[Anthropic Project Glasswing: An initial update](https://releasebot.io/updates/anthropic#Project-Glasswing:-An-initial-update)** — New named Anthropic initiative surfaced in release notes. No public detail yet — worth monitoring. The project name and "initial update" framing suggest something that will matter soon. [READ DEEPER]

- **[Using AI to write better code more slowly](https://nolanlawson.com/2026/05/25/using-ai-to-write-better-code-more-slowly/)** — 188 HN points. The author argues AI's actual value isn't velocity — it's helping you understand code more deeply before committing. Direct counter to how agentic coding is often pitched internally. Useful for setting realistic expectations with the teams you lead. [SHARE w/ engineering team]

- **[CVE-2026-28952: Apple macOS kernel vuln found by Claude](https://support.apple.com/en-us/127115)** — Claude independently identified a macOS 26.5 kernel vulnerability. First signal of AI doing meaningful, novel security research (not just assisted). Relevant for your security posture awareness and for conversations with leadership about AI capability ceilings. [SHARE w/ leadership]
