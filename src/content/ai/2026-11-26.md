## TL;DR
Anthropic widened MCP servers to ship skills and run background tasks, not just expose tools — worth a look for your internal MCP work. Mistral dropped a new flagship model plus an open-weight coding/security variant, and Docling shipped a doc-AI patch relevant to your OCR pipeline. Everything else today is plumbing: 10 unexplained Claude Code patch bumps and a Rust rewrite of Anthropic's Messages API.

## What's New

- **[MCP servers can now ship skills, run tasks, and more with Claude](https://releasebot.io/updates/anthropic#MCP-servers-can-now-ship-skills,-run-tasks,-and-more-with-Claude)** — Anthropic extended the MCP server spec so a server can package skills and kick off long-running tasks, not just expose callable tools. Changes the shape of what an internal MCP server for your doc-ingestion stack could do. [SHARE w/ engineering team]

- **[Migrating our Messages API to Rust](https://www.anthropic.com/research/migrating-api-to-rust)** — Anthropic rewrote the Messages API backend in Rust for latency and reliability at scale. No action needed, but a clean real-world case study if your team ever debates rewriting a hot-path service away from Python. [READ DEEPER]

- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — New flagship model, alongside an open-weight sibling ("Le Chonk") Mistral is positioning for agentic coding and cybersecurity work. Another open-weight option to have on the radar if a regulated workload ever needs an on-prem or non-Bedrock alternative. [SHARE w/ engineering team]

- **[Docling v2.153.0](https://github.com/docling-project/docling/releases/tag/v2.153.0)** — Fixes missing-page detection on the native PDF pipeline, adds a character-normalization control, and cleans up table/email parsing edge cases. Relevant if Docling or a comparable layout-aware parser sits anywhere in your OCR/RAG ingestion stack. [TRY]

- **[The Agent Lake](https://www.langchain.com/blog/the-agent-lake)** — LangChain's pitch for storing every agent trace and mining it for fixes and fine-tuning data. The same problem your underwriting agents will eventually hit: traces pile up, signal gets buried. [READ DEEPER]

- **[Claude Code 2.1.332](https://releasebot.io/updates/anthropic/claude-code#2.1.332)** — 10 patch releases landed since yesterday (2.1.322 → 2.1.332) with no changelog text surfaced by the feed. Not actionable until you check release notes directly. [SKIP] *(completeness only)*

One line also worth knowing: Claude.ai can now turn artifacts into installable Mac/Windows apps — consumer UX, no action for you.
