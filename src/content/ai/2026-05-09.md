## TL;DR

Heaviest week of 2026 for your stack. Two things land directly on your work: **OpenAI ended Microsoft exclusivity and its models are now on Bedrock** (Capital One can finally A/B Claude vs. GPT-5.5 inside the same account-bound tenant), and **AWS MCP Server hit GA with IAM guardrails** (your agentic coding rollout just got an enterprise-grade story for AWS-touching agents). Code w/ Claude on Tuesday was a feature-only show — multi-agent orchestration, "Dreaming," doubled Claude Code rate limits. Plus a security incident worth circulating: Anthropic disclosed Claude was used in an attempted compromise of a Mexican water utility — useful priming for your team on agent abuse patterns.

## What's New

### Tier 1 — Primary

- **OpenAI ↔ Microsoft exclusivity ended; GPT-5.5 family now on AWS Bedrock** (May 8). OpenAI also launched GPT-5.5 Instant (default in ChatGPT, claims >50% hallucination reduction in high-stakes scenarios), a GPT-5.5-Cyber variant for security work, and three new realtime voice models. The Bedrock availability is the headline for you — it's the first time Capital One could realistically pilot GPT-5.5 against your underwriting RAG without leaving the approved environment. **[TRY]** Pilot GPT-5.5 Instant against your current Claude prompt for one underwriting document type, hold prompt + retrieval constant, compare extraction accuracy + token economics. **[SHARE → Dave Perra]** — this changes your "Claude on Bedrock is the only path" framing.

- **Code w/ Claude 2026 keynote** (May 6, SF). No new model. Three things matter: (1) **Claude Code rate limits doubled** on Pro/Max/Team/Enterprise and peak-hour reductions removed — directly affects how aggressively your 6–10 teams can lean in; (2) **Multi-agent orchestration** in Claude managed agents — fleets of coordinated agents with explicit "outcomes" you set; (3) **"Dreaming"** — Claude inspecting its own past sessions to self-improve. Anthropic also said API volume is up 17× YoY. **[SHARE → Pratik, Vinay]** for the rate-limit change (kills a real adoption blocker). **[READ DEEPER]** Simon Willison's live blog for the keynote details.

- **AWS MCP Server hit GA** (May 6). Managed server giving coding agents secure, auditable access to AWS via MCP, with IAM guardrails, CloudWatch metrics, and CloudTrail logging. This is the "yes you can run agents against our AWS account" answer your security partners have been waiting for. **[TRY]** Stand it up in a sandbox account against one Claude Code workflow and bring CloudTrail traces to the next architecture review. **[SHARE → Naveen, Graham]**.

- **Bedrock AgentCore: GovCloud (US-West) GA, plus AgentCore Payments preview** (Coinbase + Stripe), plus AWS for SAP MCP Server GA. The AgentCore optimization loop (recommendations, batch evals, A/B tests) also went live. Payments is a preview novelty for now; GovCloud + the optimization loop are the substantive items for regulated enterprise. **[WATCH]** AgentCore evals — likely the path of least resistance for shipping agent quality measurement at Capital One.

- **Anthropic-Akamai $1.8B compute deal + Colossus 1 (Memphis) capacity rental from xAI**. Annualized revenue cited at ~$30B (3× YoY). The compute is what's enabling the rate-limit increases. **[SKIP]** context only — no action.

- **Anthropic disclosed Claude was used in attempted compromise of a Mexican water utility**. First high-profile public example of an agent being weaponized for ICS reconnaissance. Anthropic blocked it; the details on TTPs are useful for anyone building agentic systems with elevated permissions. **[SHARE → all teams]** as a 2-min read in your next staff meeting — useful priming on why you're being conservative with agent permissions in the underwriting flow.

### Tier 1 — Financial services toolchain

- **10 ready-to-run agent templates for financial services** (May 5). Each ships as a plugin in Cowork/Code *and* a Managed Agents cookbook. KYC screener + statement auditor map directly to your underwriting workflows. **[TRY]** Pull KYC screener cookbook, benchmark vs current pipeline. **[SHARE → Dave]**

- **Claude for Microsoft 365 add-ins went GA** (Excel/PowerPoint/Word; Outlook beta). Single agent carries context across all four.

- **Eight new connectors + Moody's MCP app**. Verisk + Moody's are the standouts for card underwriting.

- **Anthropic JV with Blackstone, H&F, Goldman** for mid-sized custom AI delivery. **[WATCH]**

### Tier 2 — Curators

- **Mistral OCR for RAG over multimodal docs** continues to land well: cited at up to 2,000 pages/min on a single node, strong on tables + math + complex layouts. If your underwriting RAG still leans on Azure AI Search's OCR, this is a credible challenger to benchmark on a representative sample of card application packets. **[TRY]** One-day spike: Mistral OCR vs. current pipeline on 50 representative docs, measure extraction F1 and latency.

- **Frontier open-source roundup**: Mistral Medium 3.5 (Apr 29), Qwen 3.6 27B with 77.2% SWE-bench (notable for a dense 27B), Qwen3.6-35B-A3B MoE focused on agentic coding, DeepSeek V4 Pro (1.6T/49B active) and V4 Flash (284B/13B active). **[WATCH]** Qwen 3.6 27B is the one to watch for personal projects — a dense model under 30B hitting >75% SWE-bench means a credible local coding agent at the 96GB-RAM tier.

### Tier 3 — Discovery

- **r/LocalLLaMA: high-end consumer hardware is now actively positioned as a Claude Code replacement**. Top stack: Llama 4 Scout 17B (general), Qwen3 (coding), Gemma 3 12B (16GB tier). Relevant to your Gods of the Future Past tinkering — a 96GB+ Mac would let you run a real coding agent locally without depending on cloud quotas.
