## What's New

- **[How Duco transforms financial data automation with Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/how-duco-transforms-financial-data-automation-with-amazon-bedrock-agentcore/)** — A tier-one-bank data-automation vendor rebuilt on Bedrock AgentCore with strict per-tenant isolation and an MCP skills architecture that cut context overhead 90%, taking reconciliation deployment time down 10x. Closest thing today to a regulated-finance reference architecture for your own stack. **[SHARE w/ leadership]**

Same shape as document ingestion for underwriting, just a different regulated domain. **[SHARE w/ product team]**

- **[Taxonomy of multi-agent design patterns, anti-patterns, and lessons from manufacturing](https://aws.amazon.com/blogs/machine-learning/taxonomy-of-multi-agent-design-patterns-anti-patterns-and-lessons-from-manufacturing/)** — Treats multi-agent coordination as a distributed-systems problem, with a framework for deciding when multiple agents are actually warranted versus one agent with better tools. Useful checklist for agentic coding adoption calls across your teams. **[SHARE w/ engineering team]** **[TRY]**

- **[Get answers from tables with tabular search in Amazon Bedrock Managed Knowledge Base](https://aws.amazon.com/blogs/machine-learning/get-answers-from-tables-with-tabular-search-in-amazon-bedrock-managed-knowledge-base/)** — Agentic retrieval now runs calculations across CSV/XLSX rows and combines results with document facts for multi-step analytical questions. Directly testable against your OCR/RAG pipeline. **[TRY]**

- **[Use prompt caching with open-weight models on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/use-prompt-caching-with-open-weight-models-on-amazon-bedrock/)** — Implicit and explicit caching through the Chat Completions API, demonstrated on an OpenCode coding-agent session. Worth a cost/latency comparison against your current setup. **[TRY]**

- **[Best practices for writing Denied Topics in Amazon Bedrock Guardrails](https://aws.amazon.com/blogs/machine-learning/best-practices-for-writing-denied-topics-in-amazon-bedrock-guardrails/)** — Denied Topics match by meaning, not keyword, so an imprecise description can block more than intended. Eight concrete practices for tightening this. **[READ DEEPER]**

- **[Anthropic: Operate Claude Managed Agents inside your security perimeter](https://releasebot.io/updates/anthropic#Operate-Claude-Managed-Agents-inside-your-security-perimeter)** — A self-hosted managed-agents option from Anthropic.
