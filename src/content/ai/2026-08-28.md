## TL;DR

One day after Anthropic published how Claude Code's auto mode is supposed to contain risk, prompt-injection researcher Johann Rehberger published a bypass that works roughly 80% of the time — read it alongside yesterday's post, not in isolation. Two more Anthropic engineering posts cover agent architecture patterns (managed agents, long-running harnesses) relevant to how your teams structure agentic coding. AWS extended Bedrock's in-country inferencing to India, and Arize shipped an MCP server for querying agent traces with SQL.

## What's New

- **[Breaking Claude Code Opus 5 Auto Mode](https://simonwillison.net/2026/Aug/27/breaking-claude-code-opus-5-auto-mode/)** — Johann Rehberger found an attack against Claude Code's auto mode that works about 80% of the time: it tricks the agent into downloading and unzipping an archive, then running code that imports `base64` in a way that slips past the containment checks. Auto mode is default-on and marketed as safe against exactly this kind of prompt injection — this is a working counterexample, not a theoretical one. [SHARE w/ engineering team]

- **[Scaling Managed Agents: Decoupling the brain from the hands](https://www.anthropic.com/engineering/managed-agents)** — Anthropic's architecture for splitting an agent's decision-making from its execution environment, aimed at running many agents reliably at scale. Relevant once agentic coding moves past one engineer, one session. [READ DEEPER]

- **[Harness design for long-running application development](https://www.anthropic.com/engineering/harness-design-long-running-apps)** — How to structure a coding agent's harness for work that spans well beyond a single sitting. Directly applicable to longer agentic coding tasks your teams are likely already attempting. [READ DEEPER]

- **[Introducing OpenAI models on Amazon Bedrock for in-country inferencing in India](https://aws.amazon.com/blogs/machine-learning/introducing-openai-models-on-amazon-bedrock-for-in-country-inferencing-in-india/)** — Bedrock now offers OpenAI's GPT-5.6 models with inference and data kept inside India via cross-Region routing. The mechanism (not the region) is the interesting part for a regulated shop watching data-residency requirements. [SHARE w/ leadership]

- **[Arize Phoenix has a built-in MCP server that lets your agents query traces with SQL](https://arize.com/blog/phoenix-mcp-sql-code-mode/)** — Read-only SQL and code mode let a coding agent answer questions across traces without paging thousands of spans into context. Useful pattern if you're building observability around your own agent deployments. [TRY]

- **[Gemini Omni 1.1 Flash lets you build with more control](https://deepmind.google/blog/gemini-omni-1-1-flash-lets-you-build-with-more-control/)** — Google's smaller Omni model gets more configurability for developers. [SKIP]
