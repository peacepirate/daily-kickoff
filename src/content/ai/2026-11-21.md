## TL;DR

Document AI and Bedrock governance were the real story this week, not new chat models. AWS shipped Textract Insights (grounded, confidence-scored extraction) and a Bedrock case study on automating AI risk assessment at a bank — both land squarely on your underwriting and compliance work. OpenAI and DeepMind both pushed new flagship models (GPT-6.2 Astra/Sol, Gemini 4 Neon), and Mistral released Large 4, but none of the three changed how you'd work day to day. The sharper thread is agent safety as adoption scales: sandboxing coding agents, a Bedrock tool-call governance gateway from LangChain, and a 15k-star Claude Code red-team skill bundle. Claude Code itself had a quiet week — ten patch releases, no feature write-ups.

## Tier 1 — Primary Sources

- **[Announcing Amazon Textract Insights: Verifiable generative AI for documents](https://aws.amazon.com/blogs/machine-learning/announcing-amazon-textract-insights-verifiable-generative-ai-for-documents/)** — Describe the fields you need in plain language, submit a document, get structured results back with a confidence score and page-level grounding per field, no model training needed. This is the closest thing this week to a direct upgrade path for your OCR/document-ingestion pipeline. [TRY]
- **[Cut self-hosted LLM cost and latency with the distributed KV caching agent skill](https://aws.amazon.com/blogs/machine-learning/cut-self-hosted-llm-cost-and-latency-with-the-distributed-kv-caching-agent-skill/)** — A coding-agent skill in the AWS Agent Toolkit that evaluates and sets up distributed KV caching via ElastiCache, claiming up to 40% lower inference cost and 80% faster time-to-first-token. Only relevant if you're self-hosting rather than calling Bedrock. [TRY]
- **[How Standard Bank Group automates AI risk assessment for generative AI](https://aws.amazon.com/blogs/machine-learning/how-standard-bank-group-automates-ai-risk-assessment-for-generative-ai/)** — A bank built an assessment inside its own AWS account that scores each gen-AI use case against international standards and internal policy using LLM-as-a-judge on Bedrock, giving risk committees consistent, traceable evidence. This is the governance shape a regulated financial-services shop needs for its own approval gates. [SHARE w/ leadership]
- **[Use Kimi Code CLI with models on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/use-kimi-code-cli-with-models-on-amazon-bedrock/)** — Kimi Code CLI v2.7.0 adds a native Bedrock provider, so the open-source coding agent uses your standard AWS credential chain instead of a separate API key. Confirms Bedrock is becoming the default entry point for third-party coding agents, not just first-party ones. [SHARE w/ engineering team]
- **[Explore the Codex Security Plugin](https://openai.com/business/learn/codex-security-plugin-demo)** — A demo of OpenAI's plugin for reviewing agent-written code for security issues as part of the workflow. Worth a look as a comparison point for whatever review gate you put around your own teams' agent output. [SHARE w/ engineering team]
- **[Hebbia sees improvements in financial research with GPT-6 Astra](https://openai.com/business/customer-stories/hebbia)** — Hebbia's prerelease evaluation of GPT-6 Astra found gains in source coverage, citation relevance, and presentation quality for financial research — a RAG-and-grounding use case adjacent to your underwriting document work. [READ DEEPER]
- **[Introducing Gemini 4 Neon](https://deepmind.google/blog/introducing-gemini-4-neon/)** — Google's new mid-tier model in the Gemini 4 line, positioned against Claude Opus and GPT Sol-class models. New model release, no action needed unless you're evaluating Gemini for a specific workload.
- **[Genie 4 is now available](https://deepmind.google/blog/genie-4-is-now-available/)** — DeepMind's world-model system, now generally available. Outside your current scope but worth knowing it exists.
- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — Mistral's new open-weights flagship ("Le Chonk"), with a companion release pitched at agentic coding and cybersecurity use cases. Notable mainly because it's open weights — a real alternative if you ever need an on-prem option.
- **[Ollama v0.40.17](https://github.com/ollama/ollama/releases/tag/v0.40.17)** — Ships Inkling 2 Mini (a 26B-parameter, 5.4B-active local model that fits on a Mac at ~20GB and scores 79.2% on SWE-bench Verified), plus Claude Code support for deferred MCP tool loading so tools load on demand instead of all at once. Relevant both to your local-LLM side interest and to how Claude Code's MCP integration behaves under your setup.

## Tier 2 — Curator Picks

- **[GPT‑6.2 Astra and GPT‑6.2 Sol](https://simonwillison.net/2026/Nov/17/gpt62-astra-and-sol/)** — OpenAI's newest frontier (Astra) and efficient (Sol) models, with Astra priced 20% lower than its predecessor. Early reviews are mixed on Astra specifically; Sol looks likely to be the default workhorse tier. Context for any model-routing decisions you make.
- **[External sandboxes for coding agents](https://simonwillison.net/2026/Nov/17/external-sandboxes-for-coding-agents/)** — Simon Willison and Prime Radiant on a pattern where code an agent executes runs inside a dedicated sandbox while the agent itself lives outside it — aimed at making it safe to try local models without risking a mistake or prompt-injection attack touching the host machine. Directly applicable as you scale agentic coding across more teams. [READ DEEPER]
- **[Quoting Daniel Stenberg](https://simonwillison.net/2026/Nov/18/daniel-stenberg/)** — The curl maintainer reports that during three weeks of AI-driven C-to-Rust rewrite attempts, curl's human-maintained project alone merged 300+ commits and 200 bugfixes — "none of those rust rewrites have" matched that. A grounded data point against hype about agentic code migration. [READ DEEPER]
- **[LangSmith Tool Gateway: Secure, governed tool use for agents](https://www.langchain.com/blog/langsmith-tool-gateway)** — Now in public beta: handles credentials, identity, and access for every agent tool call, with policies, approvals, and traces. Same governance shape as the Standard Bank Bedrock item above, from a different vendor. [SHARE w/ engineering team]
- **[Why agent governance starts with observability](https://www.langchain.com/blog/agent-governance-observability)** — LangChain's framing piece for the Tool Gateway launch above; useful as a one-page argument if you need to make the case for agent governance internally.
- **[How agents can learn skills from traces](https://www.getzep.com/blog/how-agents-learn-skills-from-traces/)** — Zep's "Agent Skills" turns verified execution traces into reusable procedural skills, reporting 4.5–18.8 point gains on three benchmarks for cheaper models. An agentic pattern with a reproducible write-up, relevant if you're thinking about how your teams' agents retain what works.
- **[The War Against Slop and an Emerging Weapon to Fight it: Formal Verification](https://latent.space/p/formal-verification/)** — AI plus the Lean proof assistant automating formal verification of code correctness, traditionally a specialist-only discipline. Early, but relevant to how much you can trust agent-written code without a human in the loop. [READ DEEPER]

## Tier 3 — Discovery

- **[Claude-BugHunter](https://github.com/elementalsouls/Claude-BugHunter)** — A Claude Code skill bundle for bug hunting and red-team work: 82 skills, 15 slash commands, 681 disclosed-report patterns across 24 vulnerability classes. 15k+ stars. Could be a scoped, sign-off'd tool for internal security testing of your own services. [TRY]
- **[ClawDOS – An AI coding agent for DOS](http://ricapar.net/ClawDOS/)** — A coding agent built to run under DOS. Novelty, not production-relevant, but a fun signal of how far agentic coding tooling has spread.
- **[Vibecoding an inference chip](https://ankitg.me/blog/vibecoding-inference-chip/)** — A write-up of using agentic coding to help design an inference chip. Discovery-tier curiosity on how far "vibecoding" extends outside software.
- Google's Gemini app now runs on lower-memory Android devices, widening access to Gemini Live and image generation. [SKIP]
- Cloudflare is branding itself a "Neolab," building its own models to make edge routing decisions in milliseconds — adjacent-ecosystem move worth knowing about if you ever evaluate Cloudflare's AI-adjacent products.
