## What's New

- **[Trust in Depth: Giving agents more autonomy without losing control](https://aws.amazon.com/blogs/machine-learning/trust-in-depth-giving-agents-more-autonomy-without-losing-control/)** — AWS lays out a layered framework (scope, know, bound, observe, prove) for deciding when an agent can act alone versus when a human needs to sign off. This is the governance vocabulary you'll want on hand as you push agentic coding adoption further into regulated workflows. [SHARE w/ leadership]

- **[AI agent permissions: Why agents don't know what you're allowed to do](https://arize.com/blog/ai-agent-permissions/)** — Agents can't reliably verify a claimed permission just from conversation context, and the failure runs both ways: agents over-trust claimed authority, and sometimes refuse things they're actually allowed to do. Relevant as you widen what your teams let agents touch in underwriting-adjacent systems. [SHARE w/ engineering team]

- **[Anthropic Code Review is now generally available](https://releasebot.io/updates/anthropic#Code-Review-is-now-generally-available)** — Automated code review moves out of preview. Worth checking whether it's reachable through your Bedrock-hosted Claude Code setup, and whether it changes your review gate for agent-authored PRs. [TRY]

- **[Meta's Muse Spark Open now available in Amazon SageMaker JumpStart](https://aws.amazon.com/blogs/machine-learning/metas-muse-spark-open-now-available-in-amazon-sagemaker-jumpstart/)** — Meta's coding-optimized open-weight model is deployable to a SageMaker endpoint in your own AWS account. One more option if you ever need an open-weight model inside your AWS boundary rather than going through Bedrock's managed models. [SHARE w/ engineering team]

- **[Modernizing complex legacy code with AI agents](https://mistral.ai/news/legacy-code-modernization/)** — Mistral's write-up on using agents for large-scale legacy modernization. A reproducible pattern worth reading against your own agentic coding rollout. [READ DEEPER]

- **[Docling v2.140.0](https://github.com/docling-project/docling/releases/tag/v2.140.0)** — This release adds a remote OpenAI-compatible ASR server option, hardens reading-order handling with page-separator bounds, and fixes an HTML-escaping bug in email body parsing. Direct relevance if Docling sits anywhere in your document ingestion pipeline. [TRY]

- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — New flagship release from Mistral. No benchmark details in the fetch; worth a glance if you evaluate non-Bedrock models for comparison. [SKIP]

- **[anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official)** — Anthropic's own curated directory of Claude Code plugins is live on GitHub. If any of your teams have been building one-off Claude Code extensions, check here first before they reinvent one. [SHARE w/ engineering team]

## Personal / Side-Project Watch

- **[Ollama v0.40.5](https://github.com/ollama/ollama/releases/tag/v0.40.5)** — Adds NVIDIA Nemotron 3.5 Super (120B MoE, vision-language, 1M context) and a smaller Nemotron 3.5 Bolt variant sized to fit a 24GB GPU for everyday agentic tasks. Worth a look for local-LLM experimentation.
