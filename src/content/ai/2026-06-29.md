# AI Digest — Monday, June 29, 2026
*Coverage window: previous 24 hours*

## TL;DR
Active Monday: OpenAI launched the GPT-5.6 family (Sol, Terra, Luna), Mistral dropped OCR 4, and AWS published a direct Nova 2 Lite + Claude document pipeline walkthrough on Bedrock that maps closely to your scanned-document work. Claude Code also rolled through several minor releases this weekend.

## What's New

- **[OpenAI GPT-5.6 Series: Sol, Terra and Luna](https://releasebot.io/updates/openai#Introducing-GPT-5.6-series:-Sol,-Terra-and-Luna)** — OpenAI introduced a three-variant model family: Sol, Terra, and Luna. No detailed capability breakdown yet in the source, but naming convention suggests differentiation by speed/cost tier similar to GPT-4o mini vs. full. Worth watching for API availability and how it competes with Claude Sonnet 4.6 on your team's use cases. [SHARE w/ all teams]

- **[Introducing Mistral OCR 4](https://mistral.ai/news/ocr-4/)** — Mistral's new document intelligence model targeting state-of-the-art OCR accuracy. Directly competes with Azure AI Document Intelligence in your stack. If it handles multi-column layouts and mixed-type documents better, it's worth a benchmark run before your next underwriting pipeline review. [READ DEEPER]

- **[Pair Nova 2 Lite with Claude for cost-optimized document processing](https://aws.amazon.com/blogs/machine-learning/pair-nova-2-lite-with-claude-for-cost-optimized-document-processing/)** — AWS published a two-model Bedrock pipeline: Nova 2 Lite handles native multimodal extraction (detect photos, extract names, get coordinates) in a single call, then Claude Sonnet 4.6 does spatial reasoning to match names to layout positions. The pattern — cheap model for extraction, expensive model for reasoning — is directly applicable to your OCR/RAG document ingestion work. [TRY]

- **[Debugging production agents with Amazon Bedrock AgentCore Observability](https://aws.amazon.com/blogs/machine-learning/debugging-production-agents-with-amazon-bedrock-agentcore-observability/)** — Part 1 of a two-part series covering how to analyze agent traces and metrics, resolve infinite loops, and diagnose tool invocation failures using built-in AgentCore tooling. As you scale agentic coding across your teams, this debugging infrastructure becomes load-bearing — send to your leads. [SHARE w/ engineering team]

- **[Introducing Gemini Omni](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)** — Google's new multimodal model release from DeepMind. Signals continued competition in the multimodal/agentic space. No detailed specs in source data — watch for benchmarks vs. Claude 4 and GPT-5.6. [SHARE w/ all teams]

- **[Introducing computer use in Gemini 3.5 Flash](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-computer-use-gemini-3-5-flash/)** — Gemini 3.5 Flash now supports computer use (browser/desktop control), joining Claude 3.5 Sonnet and GPT-4o in the agentic UI automation space. Flash tier means cost will be low — relevant for teams evaluating automated testing or UI agent workflows. [SHARE w/ engineering team]

- **[Ornith-1.0: Self-Scaffolding LLMs for Agentic Coding](https://simonwillison.net/2026/Jun/29/ornith/#atom-everything)** — New MIT-licensed open-weights model family from DeepReinforce (9B, 31B Dense; 35B, 397B MoE), built on Gemma 4 and Qwen 3.5. Claims SOTA on coding benchmarks at open-source scale. "Self-scaffolding" means the model generates its own agentic loop scaffolding rather than relying on external orchestration. Directly relevant to your teams evaluating local LLM alternatives for agentic coding. [READ DEEPER]

- **[Open Memory Protocol – One Memory Store for Claude, ChatGPT, Cursor](https://github.com/SMJAI/open-memory-protocol)** — Early-stage GitHub project proposing a shared memory layer across Claude Code, ChatGPT, and Cursor. Relevant to MCP ecosystem watch — persistent agent memory across tools is a real gap. Low stars (11) but the problem it solves matters as your teams run multi-session Claude Code workflows. [TRY]
