## TL;DR
Anthropic shipped Claude Fable 5.1 to Bedrock and published a run of engineering posts on containment, harness design, and auto-mode — all directly relevant to how you scope permissions for your teams. OpenAI's Astra crossed a frontier cybersecurity safety threshold, and Mistral's new agentic search layer is worth comparing against your RAG pipeline. A PDF-inspector project on GitHub Trending is a plausible upgrade for your scanned-vs-text doc routing.

## What's New

- **[Introducing Claude Fable 5.1 on AWS](https://aws.amazon.com/blogs/machine-learning/introducing-claude-fable-5-1-on-aws/)** — Anthropic's new flagship model is live on Bedrock, with Enterprise Frontier Safeguards for keeping data in a cloud environment you control. Worth checking whether your Bedrock endpoint needs an explicit model-ID change to pick it up. [TRY]

- **[How we built Claude Code auto mode: a safer way to skip permissions](https://www.anthropic.com/engineering/claude-code-auto-mode)** — Anthropic's own writeup on letting agents skip permission prompts without going fully unsupervised. This is the exact tradeoff you're navigating rolling agentic coding out across 6–10 teams. [READ DEEPER]

- **[Harness design for long-running application development](https://www.anthropic.com/engineering/harness-design-long-running-apps)** — Patterns for keeping agents on-task across long sessions: context management, checkpoints, task decomposition. [SHARE w/ engineering team]

- **[How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)** — Anthropic's containment model for capping agent blast radius across claude.ai, Claude Code, and Cowork. Useful vocabulary for a containment conversation with compliance/risk. [SHARE w/ leadership]

- **[Tokenomics at scale: How Jamf built real-time spend enforcement for Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/tokenomics-at-scale-how-jamf-built-real-time-spend-enforcement-for-amazon-bedrock/)** — Per-user Bedrock spend caps via IAM policies, an Athena cost view, and a Lambda loop that throttles tiered limits without killing active sessions. [SHARE w/ leadership]

- **[Agentic Search](https://mistral.ai/news/agentic-search/)** (Mistral) — A retrieval layer built to navigate, read, and verify information inside complex documents. Worth a direct comparison against the retrieval layer in your underwriting RAG pipeline. [READ DEEPER]

- **[firecrawl/pdf-inspector](https://github.com/firecrawl/pdf-inspector)** — Rust library for PDF inspection and classification that detects scanned vs. text-based PDFs to drive routing decisions. Directly applicable to your OCR intake routing. [TRY]

- **[Path to Astra: critical capabilities and frontier safeguards](https://openai.com/index/path-to-astra)** — Astra is the first OpenAI model to cross the "Critical" cybersecurity capability threshold under their Preparedness Framework, shipping with added safeguards. Signals frontier labs are now shipping under active safety gating — useful context if enterprise risk asks about frontier model exposure. [SHARE w/ leadership]
