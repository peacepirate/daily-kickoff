# AI Digest — Friday, July 24, 2026
*Coverage window: previous 24 hours*

## TL;DR
Anthropic shipped Claude Opus 5 today — new frontier-leaderboard leader, priced at Opus 4.8 levels, and per the system card, their most prompt-injection-resistant model yet. It's live on Bedrock alongside OpenAI's new GPT-5.6 family, giving you two fresh options to benchmark against your current Bedrock setup. On the document AI side, Mistral shipped OCR 4 and AWS published a reference architecture for explainable banking recommendations — both land close to your underwriting/RAG work.

## What's New

- **[Claude Opus 5](https://www.anthropic.com/news/claude-opus-5)** — Anthropic's new flagship, pitched as "frontier intelligence... at half the price" of Fable 5, now topping the Artificial Analysis leaderboard. Priced same as Opus 4.8, same 2x-cost fast mode. Worth checking whether it changes your Opus vs. Sonnet routing for agentic coding across teams. [READ DEEPER]

- **[Introducing Claude Opus 5 on AWS](https://aws.amazon.com/blogs/machine-learning/introducing-claude-opus-5-on-aws-anthropics-most-capable-opus-model/)** — Opus 5 is live on Bedrock with integration guidance for agentic systems and production inference. Since you're already on Claude Code via Bedrock, this is the fastest path to try it. [TRY]

- **[Get started with OpenAI GPT-5.6 Sol, Terra, and Luna on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/get-started-with-openai-gpt-5-6-sol-terra-and-luna-on-amazon-bedrock/)** — OpenAI's newest family is now GA on Bedrock via the Responses API, with prompt caching and Codex agent support. Same-platform benchmark against Opus 5 without leaving Bedrock. [SHARE w/ engineering team]

- **[Build an explainable next-best-product recommendation system for banking on AWS](https://aws.amazon.com/blogs/machine-learning/build-an-explainable-next-best-product-recommendation-system-for-banking-on-aws/)** — SageMaker reference architecture using a multi-tower network with learned attention, built to satisfy banking-regulator explainability requirements. Close enough to your underwriting domain to be worth a skim even outside document ingestion. [READ DEEPER]

- **[Introducing Mistral OCR 4](https://mistral.ai/news/ocr-4/)** — New "state of the art" document intelligence model. Direct competitor to whatever you're running through Azure AI Search today — worth a side-by-side on your card-underwriting document set. [TRY]

- **[Quoting Boris Cherny](https://simonwillison.net/2026/Jul/25/boris-cherny/#atom-everything)** — Per the Opus 5 system card (p.73), Anthropic says it's their most prompt-injection-resistant model yet, borne out across red-teaming and PI evals. Relevant as agentic Claude Code adoption expands across your teams and touches more untrusted input (docs, web content, tool outputs). [READ DEEPER]

- **[Your Prompts and Skills need a system of record](https://mistral.ai/news/manage-prompts-and-skills-in-studio/)** — Mistral's Studio now versions and tracks ownership of prompts and skills. Same problem you'll hit as skill libraries grow across teams doing agentic coding — worth comparing against however you're versioning Claude Code skills today. [SHARE w/ engineering team]

- **[Introducing Gemini 3.6 Flash, 3.5 Flash-Lite, and 3.5 Flash Cyber](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-6-flash-3-5-flash-lite-3-5-flash-cyber/)** — Google's Flash refresh adds a security-focused "Cyber" variant. [SKIP]
