## TL;DR

DeepMind and Mistral both shipped new frontier models this week (Gemini 4 Carbon, Mistral Large 4), and Anthropic kept building out verticals close to your world — financial advisors, legal, enterprise budget controls — rather than a new model. AWS's Bedrock news this week was all governance and cost tooling, not capability. The one item that needs action, not reading: a backdoored Claude Code VS Code extension was distributed through the Cursor Marketplace. Check your teams installed Claude Code from the official source, not that marketplace. Beyond that, a quiet, incremental week.

## Tier 1 — Primary Sources

- **[Gemini 4 Carbon](https://deepmind.google/blog/gemini-4-carbon-our-next-frontier-model/)** — DeepMind's new frontier model, leading independent evals, launched first for cyber defenders rather than general access. Worth knowing the shape of, not urgent to test since you can't get it yet. [READ DEEPER]
- **["Le Chonk" / Mistral Large 4 open weights](https://mistral.ai/news/mistral-large-4-oss/)** — Open-weight release aimed at agentic coding and cybersecurity use cases. Worth a local smoke test against your usual coding benchmarks. [TRY]
- **[OpenAI's updated Model Spec](https://openai.com/index/updated-model-spec)** — Five core values meant to guide model judgment and faithfulness to intent. Useful as a reference point when you're writing guardrails for your own agent deployments. [READ DEEPER]
- **[How OpenAI detects frontier model misalignment](https://openai.com/index/how-we-detect-frontier-model-misalignment)** — Layered monitoring to catch unauthorized agent behavior before it escalates. Relevant pattern for any team running autonomous agents in a regulated environment. [SHARE w/ engineering team]
- **[Smart reports, surveys, and pooled group budgets for Claude Enterprise](https://releasebot.io/updates/anthropic#Smart-reports,-surveys,-and-pooled-group-budgets-for-Claude-Enterprise)** — Anthropic adding usage/budget governance to Enterprise. Relevant if your org is scaling seat count. [SHARE w/ leadership]
- **[Claude for Financial Advisors](https://releasebot.io/updates/anthropic#Claude-for-Financial-Advisors)** and **[artifacts for legal work](https://releasebot.io/updates/anthropic#Introducing-artifacts-for-legal-work)** — Anthropic building regulated-industry-specific products. Worth knowing exists even if you're not the buyer. [SHARE w/ leadership]
- **[Managing Amazon Bedrock costs end to end](https://aws.amazon.com/blogs/machine-learning/managing-amazon-bedrock-costs-end-to-end-a-playbook-for-finops-and-platform-teams/)** — Five-stage model: attribute spend to an owner, make requests observable, enforce budgets, optimize defaults, run a review cadence. Directly usable if nobody owns Bedrock cost accountability on your platform team yet. [SHARE w/ leadership]
- **[How MoEngage turned 400 APIs into agent tools with AgentCore Gateway](https://aws.amazon.com/blogs/machine-learning/how-moengage-turned-over-400-apis-into-agent-tools-with-agentcore-gateway/)** — Permission-scoped agent tools from OpenAPI specs, no per-service MCP server, no public endpoints, no context bloat from hundreds of tool definitions. This is the tool-sprawl problem your document-ingestion stack will eventually hit. [READ DEEPER]
- **[Preview web apps live with Bedrock AgentCore runtime](https://aws.amazon.com/blogs/machine-learning/preview-web-apps-live-as-your-coding-agent-builds-them-with-amazon-bedrock-agentcore-runtime/)** — Authenticated session URLs that forward to a running dev server as a coding agent edits it. [TRY]
- **[Managed Deep Agents v0.10: Browser Use and Async Subagents](https://www.langchain.com/blog/managed-deep-agents-browser-use-and-asynchronous-subagents)** — Agents can now work sites with no API, handing control back to you to sign in, plus async subagents for background work. [TRY]
- **[Docling v2.145.0](https://github.com/docling-project/docling/releases/tag/v2.145.0)** and **[v2.144.0](https://github.com/docling-project/docling/releases/tag/v2.144.0)** — RapidOCR page-orientation detection, OCR replacing broken PDF text layers. Both land squarely on your document-ingestion work. [TRY]
- **[How Zep Context Graphs keep two timelines for every fact](https://www.getzep.com/blog/context-graphs-two-timelines-every-fact/)** — When a fact changes, the graph keeps the old value with an end date, so agents can see what was true on any date. This is the exact problem superseded clauses in underwriting documents create for RAG. [READ DEEPER]

**Also this week (brief):** [Genie 4](https://deepmind.google/blog/genie-4-a-new-generation-of-world-simulation/) (DeepMind's real-time world-simulation model) · [Timestral](https://mistral.ai/news/timestral/) (209M-param forecasting model beating larger models on CPU) · [Mistral x Mozilla](https://mistral.ai/news/mistral-x-mozilla/) (local AI in Firefox) · [Ollama v0.40.13](https://github.com/ollama/ollama/releases/tag/v0.40.13) (LFM3 models now on Linux/Windows, not just Apple silicon) · [NVIDIA Nemotron 3.5 Super VL on AWS](https://aws.amazon.com/blogs/machine-learning/accelerate-agentic-ai-with-nvidia-nemotron-models-on-amazon-eks-and-sagemaker-hyperpod-eks/) (120B MoE model with multimodal + tool use, deployable on EKS/SageMaker) · [Weaviate deprecating its GraphQL API](https://weaviate.io/blog/graphql-api-deprecation) (migration deadline if your RAG stack touches it) · [ChatGPT desktop app on Bedrock in GovCloud](https://aws.amazon.com/blogs/machine-learning/configure-the-chatgpt-desktop-app-with-amazon-bedrock-in-aws-govcloud-us/).
