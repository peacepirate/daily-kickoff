## What's New

- **[Anthropic Claude Haiku 5.5](https://releasebot.io/updates/anthropic#Claude-Haiku-5.5)** — New small model from Anthropic. Worth a quick latency/cost check against whatever you're currently routing to for cheap, high-volume calls in the document ingestion pipeline. [TRY]

- **[How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)** — Anthropic's own account of how they cap agent blast radius across claude.ai, Claude Code, and Cowork. For a regulated-industry agentic coding rollout, this is the closest thing to a reference architecture for "what stops an agent from doing too much" — useful vocabulary for internal security reviews. [READ DEEPER]

- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — New flagship model from Mistral. No benchmark detail in the release yet; flag for later if Bedrock or your eval harness picks it up. [SKIP]

- **[LegalOn halves Codex costs while maintaining development speed](https://openai.com/index/legalon-halves-codex-costs)** — They cut daily Codex spend 65% by matching task complexity to model tier (not defaulting everything to the biggest model) and managing budgets per team. Directly transferable to how you'd manage Bedrock Claude spend across 6–10 teams. [SHARE w/ engineering team]

- **[Pay-per-inference for AI agents: Bedrock AgentCore payments](https://aws.amazon.com/blogs/machine-learning/pay-per-inference-for-ai-agents-how-blockrun-and-incarna-use-amazon-bedrock-agentcore-payments/)** — New Bedrock AgentCore feature letting agents pay for third-party inference/services on a metered basis with spend limits enforced at the infra layer. Early and niche (agent-to-agent payments), but it's a Bedrock primitive you'll want to know exists. [SHARE w/ engineering team]

- **[Revamping Skills in Deep Agents](https://www.langchain.com/blog/revamping-skills-in-deep-agents)** — LangChain now lets you bind tools to named skills and pin/reload them mid-thread instead of loading every tool definition into context up front. Same problem you'll hit as your teams' internal tool libraries grow past a handful of MCP servers. [SHARE w/ engineering team]

- **[Cost Agent: find where your LLM and agent spend goes](https://arize.com/blog/arize-ax-cost-agent/)** — Arize's new tracing feature surfaces which specific traces (retry loops, oversized context, wrong model tier) are driving disproportionate cost. Relevant if you're running RAG/document pipelines where a single bad retry loop can quietly dominate the bill. [TRY]

- **[claude-mem](https://github.com/thedotmack/claude-mem)** — GitHub-trending tool that captures what an agent did during a session, compresses it, and injects relevant context back into future sessions. Works with Claude Code. Directly addresses the "agent forgets everything between sessions" complaint you'll hear from teams adopting agentic coding. [TRY]
