# AI Digest — Wednesday, May 20, 2026
*Coverage window: previous 24 hours*

## TL;DR
Google I/O dropped a dense batch: Gemini 3.5 Flash + Omni, plus a background-agent product called Spark. Anthropic quietly landed self-hosted sandboxes and MCP tunnels for Managed Agents, and AWS made SageMaker endpoints OpenAI-SDK-compatible — a near-zero-friction migration path. DeepSeek also previewed V4 with claimed top-tier reasoning.

## What's New

- **[New in Claude Managed Agents: self-hosted sandboxes and MCP tunnels](https://releasebot.io/updates/anthropic#New-in-Claude-Managed-Agents:-self-hosted-sandboxes-and-MCP-tunnels)** — Anthropic's Managed Agents platform now lets you run execution sandboxes on your own infrastructure and connect MCP servers through tunnels rather than public endpoints. For teams evaluating agentic coding in your organization's security context, self-hosted sandboxes change the conversation — code never leaves your perimeter. `[READ DEEPER]`

- **[Announcing OpenAI-compatible API support for Amazon SageMaker AI endpoints](https://aws.amazon.com/blogs/machine-learning/announcing-openai-compatible-api-support-for-amazon-sagemaker-ai-endpoints/)** — SageMaker real-time inference endpoints now speak the OpenAI API contract. If a team is using the OpenAI SDK, LangChain, or Strands Agents, the migration is one URL change. This lowers the barrier for teams already on Bedrock to also experiment with models hosted on SageMaker without a code rewrite. `[SHARE w/ engineering team]` `[TRY]`

- **[Gemini 3.5: frontier intelligence with action](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-5/)** — Google I/O's centerpiece: Gemini 3.5 Flash is the generally available release; Gemini Omni adds native multimodal output (audio/video generation). Simon Willison notes that most other I/O announcements are "coming soon" — Flash is the only thing you can touch today. Worth flagging to leadership given your organization's multi-cloud posture. `[SHARE w/ leadership]`

- **[Multimodal evaluators: MLLM-as-a-judge for image-to-text tasks in Strands Evals](https://aws.amazon.com/blogs/machine-learning/multimodal-evaluators-mllm-as-a-judge-for-image-to-text-tasks-in-strands-evals/)** — AWS Strands Evals now supports vision-model judges for evaluating image-to-text outputs — invoice extraction, document grounding, chart summaries. This is directly applicable to your OCR/document ingestion pipeline for underwriting. Using an MLLM evaluator means you can verify whether extracted values are actually grounded in the source document image, not just text-plausible. `[READ DEEPER]`

- **[DeepSeek-V4 preview release](https://mp.weixin.qq.com/s/8bxXqS2R8Fx5-1TLDBiEDg)** — DeepSeek announces V4 in preview with claims of top-tier reasoning and significantly improved agent capabilities, available on web, app, and API. No independent benchmarks yet — watch for reproducible evals before drawing conclusions. `[SHARE w/ engineering team]`

- **[Railway: The Agent-Native Cloud — Jake Cooper](https://www.latent.space/p/railway)** — Latent Space interview with Railway's CEO on what "agent-native" infrastructure actually means in practice: 3M users, $200K+ in monthly coding agent spend, own-metal data centers, and a thesis that PRs are dying as agents merge directly. Concrete data points for your teams' agentic adoption conversations. `[READ DEEPER]`

- **[multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills)** — A single CLAUDE.md distilling Andrej Karpathy's observations on LLM coding pitfalls into Claude Code behavioral improvements. 141K stars. Drop it into a repo and run a session — quick signal on whether it tightens output quality for your teams. `[TRY]`
