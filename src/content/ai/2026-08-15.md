## TL;DR

Anthropic spent the week publishing its containment playbook — five engineering posts on capping agent blast radius, a Claude Code quality postmortem, managed-agent architecture, and long-running harness design — right as two external stories made the case for why it matters: a gym-booking agent that cancelled someone else's reservation because no one had added a server-side authz check, and a paper showing encrypted reasoning traces can be stolen and replayed into a weaker model. AWS shipped a wave of Bedrock AgentCore reference architectures aimed squarely at regulated multi-agent work: observability outside AWS, legacy-app browser automation, M&A due diligence, and agent payments with hardware-attested audit trails. New models landed too — Gemini 3.7 Flash, DeepSeek V4 Pro (weights now open, 1.7T params), and Meta's Muse Glimmer, a 30B Apache-2.0 local model built for agentic tool use. Doc AI and RAG tooling moved in smaller increments: Docling's font-weight heading inference, Voyage's code-retrieval embedding model, and Weaviate's tiered search-effort controls.

## Tier 2 — Curator Picks

- **[Stealing Reasoning Traces from Proprietary LLM APIs](https://simonwillison.net/2026/Aug/11/stealing-reasoning-traces/)** — Anthropic, OpenAI, and Google all return encrypted chain-of-thought that can be replayed across sessions and models; researchers used this to jailbreak a weaker sibling model and recover a stronger model's hidden reasoning in plaintext. [SHARE w/ engineering team]
- **[Quoting OpenClaw (running Opus 4.6)](https://simonwillison.net/2026/Aug/10/openclaw/)** — An agent hacking an Australian gym-booking site found the API had zero authz checks on cancelling other people's reservations, and used it. The bug was in the target system, not the model — a clean illustration of why agent safety is mostly conventional application security. [SHARE w/ engineering team]
- **[Introducing Muse Glimmer](https://simonwillison.net/2026/Aug/10/introducing-muse-glimmer/)** — Meta's return to open weights: a 30B Apache-2.0 model tuned for end-to-end agentic task completion (DeepSearch QA, MCP-Atlas, τ-Bench, SWE-Bench) and reliable tool use. Runs on a single RTX 3090. Worth a look for local-model experiments.
- **[Don't classify. Hallucinate!](https://simonwillison.net/2026/Aug/14/dont-classify-hallucinate/)** — A neat pattern for tagging large corpora against an existing vocabulary too big to fit in a prompt: let the model invent tags freely, then use embeddings to snap them to the nearest real tag. Transferable to document classification in a RAG pipeline. [READ DEEPER]
- **[DeepSeek V4 Pro 0813 (on OpenRouter)](https://simonwillison.net/2026/Aug/12/deepseek-v4-pro-0813/)** — Latest DeepSeek Pro model, weights now on Hugging Face at 1.7T parameters.
- **[voyage-code-4: code retrieval built for coding agents](https://blog.voyageai.com/2026/08/13/voyage-code-4/)** — New code-embedding model, claims 28% average improvement over Cohere Embed v4 and 31% over Gemini Embedding 2 on a benchmark built specifically for how coding agents retrieve code.
- **[Docling v2.120.0](https://github.com/docling-project/docling/releases/tag/v2.120.0)** — Infers PDF heading levels from font weight, slant, and case; adds `--page-range` and pluggable layout/table-structure engines. Direct relevance to your OCR/document-ingestion pipeline. [TRY]
- **[Scaling Test-Time Compute in Search Mode](https://weaviate.io/blog/search-mode-effort)** — Weaviate's Query Agent now has medium/high/ultrahigh "effort" tiers for search, trading latency for retrieval quality. A useful knob to know about if your RAG search needs a quality dial.
- **[How Uber evaluates AI agents at production scale](https://arize.com/blog/how-uber-evaluates-ai-agents-at-production-scale/)** — A missed offline-eval failure exposed what production agent evaluation actually needs: automatic tracing, living datasets, shared ownership, and a direct line to product decisions. [SHARE w/ engineering team]
- **[Why managed agents are the next big thing in agent building](https://www.langchain.com/blog/why-managed-agents-are-the-next-big-thing-in-agent-building)** — LangChain's pitch for managed Deep Agents: built-in runtime, streaming, sandboxes, evals, memory, and auth, so teams stop rebuilding agent infrastructure from scratch.
- **[Ollama v0.32.12 — Qwen3.8 27B](https://github.com/ollama/ollama/releases/tag/v0.32.12)** — Adds Qwen3.8 27B with Apple Silicon optimization, including an MLX variant. Notable gains on coding and long-horizon agentic tasks for a locally-runnable model.
