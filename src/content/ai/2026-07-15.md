## What's New

- **[Introducing Mistral OCR 4](https://mistral.ai/news/ocr-4/)** — New state-of-the-art document intelligence model from Mistral. Direct competitor to what you're wiring through Azure AI Search for underwriting. Worth a bake-off before you deepen the Azure investment. [TRY]

- **[Built Technologies builds an AI-powered document intelligence solution on AWS](https://aws.amazon.com/blogs/machine-learning/built-technologies-builds-an-ai-powered-document-intelligence-solution-on-aws-to-power-agents-across-real-estate-finance/)** — Real estate finance analog to your small-business-card underwriting problem: classify, split, extract, evaluate, reason. Days-to-minutes claim; shared environment for engineering + domain experts. Closest public reference architecture you'll find for your stack. [SHARE w/ engineering team]

- **[Agentic vision: Building visual intelligence with Amazon Bedrock and MCP servers](https://aws.amazon.com/blogs/machine-learning/agentic-vision-building-visual-intelligence-with-amazon-bedrock-and-mcp-servers/)** — AWS walkthrough of a Computer Vision MCP Server on Bedrock. Pattern is transferable: standardized MCP interface in front of specialized models is how your document ingestion agents should look. [READ DEEPER]

- **[How I tricked Claude into leaking your deepest, darkest secrets](https://simonwillison.net/2026/Jul/15/claude-web-fetch-exfiltration/#atom-everything)** — Ayush Paul found a hole in Anthropic's web_fetch URL-allowlist defense against prompt injection. The lethal-trifecta pattern (private data + hostile-instruction ingest + exfil channel) is now demonstrated against Claude's production protections. Factor into any Claude Code + external-content workflow your teams enable. [SHARE w/ all teams]

- **[xai-org/grok-build, now open source](https://simonwillison.net/2026/Jul/15/grok-build/#atom-everything)** — xAI open-sourced their Grok CLI after a backlash: users reported the tool uploaded entire directories (SSH keys, password DBs) to xAI cloud buckets when run in a home directory. Live case study for the data-boundary questions you should be asking as you scale agentic coding tools across teams. [SHARE w/ leadership]

- **[Introducing computer use in Gemini 3.5 Flash](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-computer-use-gemini-3-5-flash/)** — Computer-use capability now in the Flash tier. Cheaper agentic browser/desktop control is a meaningful shift; watch for parity claims vs. Claude's computer use.

- **[Introducing Gemini Omni](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)** — Google's new omni-modal flagship. Nano Banana 2 Lite and Gemini Omni Flash follow-ups shipped same day. No Bedrock availability yet; note for when parity questions come up.

- **[Nutlope/hallmark](https://github.com/Nutlope/hallmark)** — Anti-AI-slop design skill for Claude Code, Cursor, and Codex (8.8k stars). Aimed at the exact quality-degradation complaints that surface as you scale agentic coding — installable skill your teams can adopt without procurement. [TRY]
