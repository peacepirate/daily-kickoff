# AI Digest — Thursday, August 06, 2026
*Coverage window: previous 24 hours*

## TL;DR
Heavy day for agentic infrastructure: Anthropic shipped a safer permission-skip mode for Claude Code plus inline DLP for Claude Enterprise, while AWS published three Bedrock AgentCore/MCP posts — including a multi-agent mortgage assistant that's a close analog to your underwriting pipeline. A PDF-classification library also hit GitHub Trending that slots directly into document-ingestion triage. Separately, Meta became the third lab (after OpenAI and the UK AI Safety Institute) to report an agent accidentally attacking real infrastructure during an eval meant to be isolated — worth a flag if you rely on third-party red-teaming.

## What's New
- **[How we built Claude Code auto mode: a safer way to skip permissions](https://www.anthropic.com/engineering/claude-code-auto-mode)** — Anthropic's engineering breakdown of a new auto mode that skips permission prompts more safely than blanket skip-permissions flags. Worth understanding before any team standardizes on auto-approve for speed. [TRY]
- **[Inference hooks: inline data loss prevention for Claude Enterprise](https://releasebot.io/updates/anthropic#Inference-hooks:-inline-data-loss-prevention-for-Claude-Enterprise)** — New enterprise-tier control that catches sensitive data in prompts/outputs before it crosses the inference boundary. Relevant if Capital One evaluates Claude Enterprise for regulated workloads. [SHARE w/ leadership]
- **[How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)** — Anthropic on how they cap agent blast radius across claude.ai, Claude Code, and Cowork as capability grows. A useful framework for governance conversations with the teams you lead. [READ DEEPER]
- **[How LendingTree built a multi-agent mortgage assistant on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/how-lendingtree-built-a-multi-agent-mortgage-assistant-on-amazon-bedrock/)** — Three coordinated agents (LangGraph + MCP + Amazon Nova) with built-in guardrails handling regulated financial-services workflows end to end. Close architectural cousin to the document-ingestion/underwriting work on your team. [READ DEEPER]
- **[How we built an MCP bridge to give our AgentCore-hosted AI agent access to local MCP tools](https://aws.amazon.com/blogs/machine-learning/how-we-built-an-mcp-bridge-to-give-our-agentcore-hosted-ai-agent-access-to-local-mcp-tools/)** — Pattern for letting a cloud-hosted agent reach local MCP servers via a signed WebSocket tunnel and browser extension, no VPN or open ports. Useful if your agentic tooling ever needs to touch engineers' local dev environments. [TRY]
- **[Run production AI agents in n8n with Amazon Bedrock AgentCore harness](https://aws.amazon.com/blogs/machine-learning/run-production-ai-agents-in-n8n-with-amazon-bedrock-agentcore-harness/)** — AgentCore harness is now GA, with a new open-source n8n node giving persistent memory, tool execution, and VPC isolation straight from the workflow editor. [SHARE w/ engineering team]
- **[firecrawl / pdf-inspector](https://github.com/firecrawl/pdf-inspector)** — Rust library that classifies PDFs as scanned vs. text-based before extraction. That's exactly the triage step your OCR/RAG pipeline needs to route documents correctly. [TRY]
- **[An AI model from Meta also hacked another company during testing](https://simonwillison.net/2026/Aug/6/an-ai-model-from-meta/#atom-everything)** — Third disclosed case (after OpenAI and the UK AI Safety Institute) of an agent unintentionally attacking real systems during a security eval that was supposed to be network-isolated, this time due to a misconfiguration at third-party tester Irregular. If your org uses or is considering third-party AI red-teaming, this is worth a question about isolation guarantees. [SHARE w/ leadership]
