# AI Weekly Synthesis — Week of May 11 – May 16, 2026
*Coverage window: Mon–Sat*

## TL;DR

Claude Code shipped five releases in five days (2.1.138–2.1.143), the biggest agentic-tooling sprint in months: agent-session view, a `/goal` command with live completion metrics, Fast Mode promoted to Opus 4.7, and a plugin marketplace with projected token costs. OpenAI countered with Codex Mobile on iOS/Android (HIPAA-ready for Enterprise) and Workspace Agents for Enterprise. On the AWS side, document-level ACL for Bedrock knowledge bases landed and is directly applicable to your RAG document ingestion work. DeepSeek previewed V4 with substantially upgraded agent capabilities — no precise date yet, worth watching.

## Tier 1 — Primary Sources

- **Claude Code 2.1.138–2.1.143 (May 9–15)** — Five releases in five days. The headline additions: an **agent view** (`claude agents`) showing every Claude Code session in one list — running, blocked on you, or done; a **`/goal` command** with user-defined completion conditions and a live metrics overlay; **Fast Mode defaulting to Opus 4.7** (was Opus 4.6); a **plugin marketplace** with projected token costs per plugin; `settings.autoMode.hard_deny` for unconditional action blocking without prompting; `worktree.bgIsolation: "none"` for repos where worktrees are impractical; PowerShell getting `-ExecutionPolicy Bypass` by default; and a `terminalSequence` hook field for desktop notifications and window-title updates from background jobs. If your teams are on 2.1.13x, the update is worth forcing this weekend. [SHARE w/ engineering team] [TRY]

- **AWS: Document-Level ACL for Bedrock Knowledge Bases (May 15)** — AWS published a step-by-step guide for per-document access controls on S3-backed Bedrock knowledge bases, using either a centralized ACL config file or per-document metadata files. This is the current AWS-native pattern for row-level security in RAG pipelines — directly applicable to underwriting doc ingestion where different teams should see different borrower files. [SHARE w/ engineering team] [TRY]

- **AWS: Real-Time Voice Agents with Nova 2 Sonic (May 14)** — A production architecture combining Stream's Vision Agents framework (edge media transport) with Amazon Nova 2 Sonic on Bedrock (speech-to-speech) running inside the customer's AWS account. Sub-500ms latency, barge-in detection, function calling for business logic. Relevant if your document ingestion roadmap ever expands to voice intake or call-center transcript processing. [READ DEEPER]

- **OpenAI Codex Mobile (May 14)** — Codex is now on iOS and Android across all plans. Enterprise-relevant details: HIPAA support for Enterprise workspaces in local environments, remote SSH, and access tokens are GA. Remote work review and approvals make long-running agent tasks more supervisable from mobile. Direct competitive signal — your teams will compare this with Claude Code's mobile story. [SHARE w/ leadership]

- **OpenAI Workspace Agents for Enterprise (May 11)** — ChatGPT Enterprise can now create repeatable workflow agents operating across ChatGPT, Slack, and connected apps (requires Enterprise Key Management). Closer to RPA than deep agentic coding, but shows the trajectory for enterprise workflow automation at scale. [SHARE w/ product team]

- **DeepSeek-V4 Preview** — DeepSeek announced a V4 preview on their homepage: "world-class reasoning performance" with substantially improved agent capabilities, available on web, mobile, and API. No confirmed benchmark numbers or architecture details yet. Watch for the technical report — prior DeepSeek releases have disrupted capability/cost assumptions quickly. [READ DEEPER]

- **Claude for Small Business (May 13)** — Anthropic launched a Claude tier targeting SMB workflows. Not directly relevant to your Capital One enterprise context, but signals Anthropic broadening the product line downmarket. [SKIP]

## Tier 2 — Curator Picks

- **Simon Willison: llm 0.32a2 (May 12)** — The open-source `llm` CLI now routes OpenAI models through the `/v1/responses` endpoint, enabling interleaved reasoning across tool calls for GPT-5 class models. A new `-R` flag surfaces summarized reasoning tokens inline. Useful reference if you're building evaluation pipelines that need to inspect chain-of-thought, not just final outputs.

- **Latent Space: "Everything is Conductor" (May 15)** — Makes the case that GitHub's new Copilot App, OpenAI's Codex Mobile, and VS Code's agent mode are all converging on the same agent-first form factor Conductor pioneered. Also examines monetization pressure on pioneers as form factors commoditize. Strong framing article for your internal agentic adoption pitch: the "right" interface is becoming consensus, which makes the rollout conversation easier. [READ DEEPER]

- **Import AI 456: Neural Computer (May 11)** — Jack Clark's newsletter covers Meta researchers proposing "Neural Computers" — systems that unify computation, memory, and I/O in learned runtime states, potentially replacing traditional OS abstractions for agent workloads. Very early-stage concept; treat as a 3–5 year horizon signal for how agent memory and compute may co-evolve.

- **Latent Space: Cerebras $60B IPO (May 16)** — Cerebras went public at a $60B valuation, validated by serving trillion-parameter models including internal OpenAI workloads. Signals that inference economics are large enough to sustain dedicated hardware plays. No near-term action required. [SKIP]

Claims fewer tokens and fewer tool calls vs. baseline file reads, 100% local. Worth testing on a medium-complexity repo to measure context-window efficiency before recommending to teams. [TRY]

- **obra/superpowers (GitHub Trending, 194k stars, Shell)** — "An agentic skills framework and software development methodology that works." Unusually high star count for a Shell repo suggests broad adoption appetite for standardized agent skill libraries. Skim the methodology docs — may inform how you structure shareable agentic patterns across your 6–10 teams.
