# AI Digest — Friday, July 31, 2026
*Coverage window: previous 24 hours*

## TL;DR
Anthropic dropped four engineering posts today — Claude containment design, a new Claude Code auto mode for safer permission-skipping, a managed-agents scaling pattern, and long-running-app harness design — the most substantive Claude Code content in weeks. AWS shipped Bedrock AgentCore Observability for diagnosing production agent performance, DeepSeek released a new cost-leading V4-Flash model, and Simon Willison covered both in depth plus a new small-eval tool (smevals) worth trying on your own harness changes. Opus 5, Mistral OCR 4, and the MCP 2026-07-28 spec are repeats from earlier this week.

## What's New

- **[How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)** — Anthropic's own account of containment engineering across claude.ai, Claude Code, and Cowork: sandboxing, permission boundaries, and blast-radius limits as agents get more capable. Directly relevant given Anthropic's own April sandbox-escape disclosures this week — good grounding for any governance conversation about Claude Code rollout. [SHARE w/ leadership]

- **[How we built Claude Code auto mode: a safer way to skip permissions](https://www.anthropic.com/engineering/claude-code-auto-mode)** — A new mode that skips permission prompts with guardrails instead of the current all-or-nothing choice. Worth testing directly since permission-prompt friction is a real adoption blocker across your teams. [TRY]

- **[Scaling Managed Agents: Decoupling the brain from the hands](https://www.anthropic.com/engineering/managed-agents)** — Architecture pattern separating an agent's decision-making from its execution layer to scale many concurrent Managed Agents. Relevant as agentic coding usage grows across more of your teams and you need a scaling story beyond "one agent per developer." [READ DEEPER]

- **[Harness design for long-running application development](https://www.anthropic.com/engineering/harness-design-long-running-apps)** — Patterns for structuring agents that build and maintain applications over long horizons rather than single-shot tasks. Worth checking against how your teams currently scope larger Claude Code work. [READ DEEPER]

- **[Optimizing production agents with Amazon Bedrock AgentCore Observability](https://aws.amazon.com/blogs/machine-learning/optimizing-production-agents-with-amazon-bedrock-agentcore-observability/)** — Using AgentCore Observability with CloudWatch to find performance bottlenecks and memory issues in long-running agent sessions once they're in production, not just prototyping. Directly applicable if any part of your document-ingestion pipeline runs agents on Bedrock. [TRY]

- **[deepseek-ai/DeepSeek-V4-Flash-0731](https://simonwillison.net/2026/Jul/31/deepseek-v4-flash-0731/#atom-everything)** — 304B open-weight model (167GB on Hugging Face) ranking ahead of the larger MiniMax M3 on Artificial Analysis, priced at $0.14/$0.27 per million input/output tokens — likely the best value-per-intelligence model available right now. Not on Bedrock, but a sharp benchmark for cost conversations. [SHARE w/ leadership]

- **[Stateless MCP has recaptured my interest (and inspired mcp-explorer and datasette-mcp)](https://simonwillison.net/2026/Jul/31/stateless-mcp/#atom-everything)** — A deeper technical look at why the MCP 2026-07-28 spec's move to statelessness matters, beyond the terse vendor announcements already covered this week, plus two new tools built on it. [READ DEEPER]

- **[smevals - a small eval suite for evaluating models, prompts, and harnesses](https://simonwillison.net/2026/Jul/31/smevals/#atom-everything)** — New lightweight eval framework: point your coding agent at `uvx smevals docs` and have it build an eval suite for you. A fast way to get regression coverage before changing a prompt or swapping a model in the underwriting pipeline. [TRY]
