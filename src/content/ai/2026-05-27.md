# AI Digest — Wednesday, May 27, 2026

*Coverage window: previous 24 hours*

## TL;DR

AWS dropped nine AgentCore posts today, headlined by a Bedrock Data Automation deep-dive on extracting structured data from financial documents — directly relevant to the underwriting pipeline. Google released Gemini 3.5 and Gemini Omni. A Microsoft Copilot data-exfiltration vulnerability is a required read for anyone deploying agentic systems.

## What's New

- **[Process financial documents using Amazon Bedrock Data Automation](https://aws.amazon.com/blogs/machine-learning/process-financial-documents-using-amazon-bedrock-data-automation/)** — AWS walks through custom extraction on bank statements, W-2s, 1099-Bs, and vendor contracts using Bedrock Data Automation. This is the closest thing to a production blueprint for the OCR/extraction layer in the underwriting pipeline — worth testing against real documents before the next sprint. `[TRY]` `[SHARE w/ engineering team]`

- **[Build highly scalable serverless LangGraph multi-agent systems in AWS with Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/build-highly-scalable-serverless-langgraph-multi-agent-systems-in-aws-with-amazon-bedrock-agentcore/)** — End-to-end pattern for LangGraph orchestrators backed by AgentCore Memory and AgentCore Observability, serverless on AWS. The architecture maps cleanly to what your teams are building — and the observability layer solves the "what did the agent actually do?" debugging problem. `[TRY]` `[SHARE w/ engineering team]`

- **[Building AI agents for business support using Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/building-ai-agents-for-business-support-using-amazon-bedrock-agentcore/)** — AWS GenAIIC + Works Human Intelligence case study: two business-support agents that cut costs 97% while improving operational efficiency. The numbers are strong enough to take to leadership. `[SHARE w/ leadership]`

- **[Gemini 3.5: frontier intelligence with action](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-5/)** and **[Gemini Omni](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)** — Google released two new models this week: Gemini 3.5 (positioned as frontier + action-capable) and Gemini Omni (multimodal). No AWS Bedrock availability announced yet, but watch for it. `[SHARE w/ all teams]`

- **[DeepSeek-V4 preview](https://mp.weixin.qq.com/s/8bxXqS2R8Fx5-1TLDBiEDg)** — DeepSeek claims world-top reasoning performance and substantially improved agent capability. Preview is live on web, app, and API. Worth benchmarking against Claude Sonnet for document extraction tasks if cost is a lever. *(Note: link is WeChat/Chinese-language announcement.)*

- **[Microsoft Copilot Cowork Exfiltrates Files](https://simonwillison.net/2026/May/26/copilot-cowork-exfiltrates-files/#atom-everything)** — Copilot's agentic email feature allowed attackers to trigger outbound image requests that leaked file data when a user opened a compromised message. The attack surface — rendered content in agentic output — applies broadly. If any of your teams are building agents with email, Slack, or doc-rendering capabilities, this is the threat model to internalize before deploying. `[READ DEEPER]` `[SHARE w/ engineering team]`

- **[sqlite AGENTS.md](https://simonwillison.net/2026/May/27/sqlite-agents/#atom-everything)** — SQLite added an AGENTS.md file this week — not for their own development, but as instructions for AI agents pointed at their codebase. A small but meaningful signal that AGENTS.md is becoming a standard artifact for codebases expecting agentic interaction. Worth adding to repos your teams are actively using with Claude Code. `[SHARE w/ engineering team]`

- **[anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins)** — Anthropic published an open-source repo of Claude Cowork plugins targeting knowledge workers (17K stars already). If teams are using Claude Cowork, this is the official plugin library to pull from first.
