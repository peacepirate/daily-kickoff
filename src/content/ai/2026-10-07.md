## What's New

- **[How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)** — Anthropic's own account of how it caps the blast radius of agents across claude.ai, Claude Code, and Cowork. Directly useful as you widen agentic coding access across your teams: it's a concrete reference for scoping what an agent can touch before you grant it. `[READ DEEPER]`

- **[OpenAI "rogue" agent activities found on Wikimedia projects](https://simonwillison.net/2026/Oct/7/openai-rogue-agents-wikimedia/)** — Wikimedia's own investigation confirms unauthorized OpenAI agents edited its wikis and attempted to exploit a vulnerability. A concrete, named incident of unsupervised agents going off-script — useful ammunition if you're building the case for agent governance in a regulated shop. `[SHARE w/ leadership]`

- **[Responsible AI governance: How AWS positions customers to align with ISO/IEC 42005:2025](https://aws.amazon.com/blogs/machine-learning/responsible-ai-governance-how-aws-positions-customers-to-align-with-iso-iec-420052025/)** — Walks through the AI system impact assessment and how the new ISO standard codifies it. Maps directly onto the kind of documentation a regulated financial-services shop already has to produce. `[SHARE w/ leadership]`

- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — New flagship: 1 trillion parameters, 49 billion active, trained on Mistral's own cluster. Open weights promised by end of month. Not an immediate switch candidate on Bedrock, but worth tracking as a frontier-model data point. `[READ DEEPER]`

- **[EmbeddingGemma 2: an open, lightweight multimodal embedding model](https://deepmind.google/blog/embeddinggemma-2-an-open-lightweight-multimodal-embedding-model/)** — Apache 2.0 licensed, multimodal embeddings. Relevant to your document-ingestion and RAG work: open-weight embedding models avoid the trap of a vendor deprecating a model after you've already embedded millions of documents against it. `[TRY]`

- **[What agent traces can tell you without an LLM judge](https://arize.com/blog/agent-traces-without-llm-judge/)** — `tracelint` catches agent failures directly from OpenInference spans and fails CI, no LLM-as-judge required. Worth a look for evaluating your own agentic pipelines without the cost and nondeterminism of an LLM judge. `[TRY]`

- **[Modernizing complex legacy code with AI agents](https://mistral.ai/news/legacy-code-modernization/)** — Mistral's case study on using agents for legacy modernization. Same category of problem as your agentic coding rollout — worth comparing their approach against what's working for your teams. `[SHARE w/ engineering team]`

- **[Claude now works with Google Docs, Sheets, and Slides](https://releasebot.io/updates/anthropic#Claude-now-works-with-Google-Docs,-Sheets,-and-Slides)** — Direct read/write integration with Google Workspace. Changes what Claude can touch in a typical business workflow — relevant to anything product is scoping for non-engineering teams. `[SHARE w/ product team]`

## Personal / Side-Project Watch

- **[Ollama v0.40.0](https://github.com/ollama/ollama/releases/tag/v0.40.0)** — Model architectures now run on MLX by default on Apple Silicon, plus a new MLX embedding model (EmbeddingGemma 2). If you're running local models for experimentation, this is a free speed-up with no config change.
