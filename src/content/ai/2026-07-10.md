# AI Digest — Thursday, July 10, 2026

## TL;DR
Google dropped Gemini Omni and computer-use in Gemini 3.5 Flash, making this a significant model day. Mistral launched OCR 4 — directly relevant to your document AI pipeline. OpenAI shipped GPT-5.6 and merged Codex into ChatGPT desktop, while AWS published multiple AgentCore production patterns worth studying.

## What's New

- **[Introducing Gemini Omni](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)** — Google's new flagship multimodal model. No detailed specs in source, but positioned as a major release alongside Nano Banana 2 Lite and Gemini Omni Flash variants. Signals Google is shipping a tiered model family similar to Claude's Haiku/Sonnet/Opus structure. `[SHARE w/ leadership]`

- **[Introducing computer use in Gemini 3.5 Flash](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-computer-use-gemini-3-5-flash/)** — Gemini 3.5 Flash now supports computer use, putting it alongside Claude's computer use capability. Flash is Google's speed/cost-optimized tier, so this matters for agentic workflows where latency and cost are constraints. Your teams evaluating agentic coding tools should know this option exists on Bedrock if Google makes it available there. `[SHARE w/ engineering team]`

- **[Introducing Mistral OCR 4](https://mistral.ai/news/ocr-4/)** — "State of the art document intelligence model" from Mistral. This is directly in your lane — OCR for document ingestion in underwriting. Worth a direct benchmark against Azure AI Document Intelligence on your actual document types before drawing conclusions. `[TRY]` `[READ DEEPER]`

- **[OpenAI GPT-5.6 System Card](https://releasebot.io/updates/openai#GPT-5.6-System-Card)** — OpenAI shipped GPT-5.6 with variants named Sol/Terra/Luna (per Latent Space coverage). A tiered release; system card is the primary technical artifact to evaluate capability claims. Less directly relevant while you're on Bedrock/Claude, but worth tracking as competitive context. `[SKIP]`

- **[Codex joins the ChatGPT desktop app](https://releasebot.io/updates/openai#Codex-joins-the-ChatGPT-desktop-app)** — OpenAI's agentic coding tool is now embedded in ChatGPT desktop, positioning it directly against Claude Code. Worth knowing as your teams compare tools, but no new capability here — distribution play. `[SHARE w/ engineering team]`

- **[Build a semantic layer for agentic AI on AWS with Stardog and Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/build-a-semantic-layer-for-agentic-ai-on-aws-with-stardog-and-amazon-bedrock-agentcore/)** — Production pattern: Strands Agents SDK + AgentCore querying Aurora and Redshift through a unified semantic layer, no ETL required. The bundled inbound auth and tool credentials in AgentCore is a pattern your teams can reuse for any multi-source agentic workflow. `[READ DEEPER]`

- **[How KTern.AI built agentic AI for SAP on Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/how-ktern-ai-built-agentic-ai-for-sap-on-amazon-bedrock-agentcore/)** — A concrete example of multi-agent orchestration with persistent context on AgentCore using Strands Agents SDK. The architecture — specialized agents, long-running enterprise programs, production-grade reliability — is a useful reference for how to structure your teams' agentic workflows beyond single-shot coding tasks. `[SHARE w/ engineering team]`

- **[obra/superpowers](https://github.com/obra/superpowers)** — GitHub trending at 251K stars: "an agentic skills framework & software development methodology that works." Alongside [mattpocock/skills](https://github.com/mattpocock/skills) (164K stars) and [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) (76K stars), there's clearly a wave of Claude Code skill/methodology repos going viral. Worth a quick scan to see if any patterns are worth standardizing across your 6–10 teams. `[TRY]`
