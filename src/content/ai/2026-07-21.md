## What's New

- **[Exploring self-distilled reasoning for supervised fine-tuning with Amazon Nova](https://aws.amazon.com/blogs/machine-learning/exploring-self-distilled-reasoning-for-supervised-fine-tuning-with-amazon-nova/)** — AWS's Self-Distilled Reasoning (SDR) technique generates reasoning traces for SFT datasets that don't have them, validated across three benchmarks. Relevant if you ever fine-tune a Nova/Bedrock model for the underwriting pipeline and your training data lacks reasoning annotations. [READ DEEPER]

- **[Introducing Gemini 3.6 Flash, 3.5 Flash-Lite, and 3.5 Flash Cyber](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-6-flash-3-5-flash-lite-3-5-flash-cyber/)** — Google adds three new Flash-tier models, including a "Cyber" variant (no detail on what that specializes in from the source). Extends the cheap/fast-tier competition Bedrock's Nova and Claude Haiku already compete in. [SHARE w/ engineering team]

- **[Start building with Nano Banana 2 Lite and Gemini Omni Flash](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni-flash-nano-banana-2-lite/)** — Lighter-weight image/omni-modal tiers ship alongside the Flash refresh. No spec detail in the source; noting for the record.

- **[A Fireside Chat with Cat and Thariq from the Claude Code team](https://simonwillison.net/2026/Jul/21/cat-and-thariq/#atom-everything)** — Transcript of Willison's AI Engineer World's Fair session with Anthropic's Claude Code team, covering Claude Code, Claude Tag (new Slack integration), Fable, coding agent security, evals, and tool design — plus how Anthropic uses these tools internally. A direct look at how the team building your daily tool thinks about agent security and eval design. [READ DEEPER]

- **[Kimi K3 Is Competitive with Fable; Kimi K3 and Fable Is SoTA](https://fireworks.ai/blog/kimik3-fable)** — Fireworks AI benchmarks Moonshot's Kimi K3 against "Fable," the same term appearing in Willison's Claude Code team interview above (unexplained in these sources, likely an Anthropic product). #2 on Hacker News (335 points, 188 comments) — worth 5 minutes to find out what Fable is before it shows up in your toolchain. [READ DEEPER]

- **[tirth8205/code-review-graph](https://github.com/tirth8205/code-review-graph)** — Local-first code intelligence graph for MCP and CLI: builds a persistent map of your codebase so AI coding tools read only what's relevant, with benchmarked context reductions on code review and large-repo workflows. 24.7k stars. Worth a look for shrinking Claude Code's context footprint on your larger repos. [TRY]

## Personal / Side-Project Watch

- **[Nativ: Run AI models locally on your Mac](https://simonwillison.net/2026/Jul/21/nativ/#atom-everything)** — Prince Canuma's new macOS app wraps MLX in a full desktop client: chat interface plus a localhost API server, and it auto-detects MLX models already sitting in your Hugging Face cache. Similar shape to LM Studio. Worth a look for local-LLM experiments alongside Gods of the Future Past. [TRY]

- **[AlexsJones/llmfit](https://github.com/AlexsJones/llmfit)** — One command to check which of hundreds of local models/providers actually run on your hardware. 30.2k stars. Pairs well with Nativ above if you're testing local models on your Mac.
