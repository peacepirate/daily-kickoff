## TL;DR

Claude Code's Code Review feature hit general availability. Mistral shipped Large 4 and a write-up on using AI agents for legacy code migration. Anthropic published a case study on rebuilding their internal version control after merge volume grew 10x — relevant if you're sizing what agentic adoption does to your own pipeline. Two reproducible agentic-coding write-ups (tmux sessions, a lighter skill framework) are worth a quick look.

## What's New

- **[Code Review is now generally available](https://releasebot.io/updates/anthropic#Code-Review-is-now-generally-available)** — Claude Code's review feature exited beta. It runs inside the CLI/IDE workflow rather than as a separate tool, so there's no new adoption friction for teams already on Claude Code. [TRY]

- **[Redesigning source control at Anthropic](https://www.anthropic.com/engineering/redesigning-source-control)** — Anthropic moved off their prior VCS to an in-house system after merges per day grew more than 10x and existing tooling became the bottleneck. A useful signal for what breaks first when agentic coding pushes merge volume up across your own teams. [READ DEEPER]

- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — New flagship release from Mistral. No benchmark detail in today's feed and no mention of Bedrock availability, so there's nothing actionable yet. [SKIP]

- **[Modernizing complex legacy code with AI agents](https://mistral.ai/news/legacy-code-modernization/)** — Mistral's write-up on using agents for legacy code migration, the kind of multi-decade codebase regulated-industry shops run. Directly relevant to agentic-coding adoption decisions even if your teams stay on Claude Code. [SHARE w/ engineering team]

- **[Tmux and Claude Code: Sessions, Send-Keys, and the Ceiling](https://crystl.dev/guides/tmux-for-ai-agents/)** — Reproducible pattern for running persistent Claude Code sessions inside tmux via send-keys, including where it hits a ceiling. Worth testing if any team runs long agentic sessions that need to survive a disconnect. [TRY]

- **[Superlite: A Faster Alternative to Superpowers](https://contextfirst.blog/superlite-hand-an-agent-a-spec/)** — A lighter-weight alternative to the "Superpowers" agent-skill framework, trading structure for speed. Worth a look if you're evaluating skill/plugin frameworks for standardizing how agents approach tasks. [READ DEEPER]

- **[DeepSeek V4.1 Flash (Max)](https://artificialanalysis.ai/models/deepseek-v4-1-flash-1017)** — New DeepSeek release drew heavy HN discussion (144 points, 46 comments). One to watch for cheaper open-weight alternatives on non-sensitive workloads, but no Bedrock availability yet. [SKIP]
