## TL;DR

Anthropic published five engineering deep-dives at once — on containing Claude's blast radius, Claude Code's new permission-skipping auto mode, decoupled managed agents, and long-run harness design. All of it bears directly on scaling agentic coding across your teams. Google Cloud also launched Gemini Enterprise for Financial Services, landing squarely in your industry, and Mistral shipped an agentic search product aimed at exactly the document-retrieval problem you're solving for underwriting.

## What's New

- **[How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)** — Anthropic's own writeup on capping agent blast radius across claude.ai, Claude Code, and Cowork. Worth reading before you expand Claude Code permissions further across teams. [SHARE w/ engineering team]

- **[How we built Claude Code auto mode: a safer way to skip permissions](https://www.anthropic.com/engineering/claude-code-auto-mode)** — Details the design behind letting Claude Code skip permission prompts without losing safety guarantees. Directly relevant if any of your teams are asking to run Claude Code with fewer interruptions. [TRY]

- **[Scaling Managed Agents: Decoupling the brain from the hands](https://www.anthropic.com/engineering/managed-agents)** — Architectural pattern separating an agent's reasoning from its execution environment. Useful reference point for standardizing how 6-10 teams run agentic coding without each building its own harness. [READ DEEPER]

- **[Harness design for long-running application development](https://www.anthropic.com/engineering/harness-design-long-running-apps)** — How to keep an agent coherent and on-task across long, multi-step builds rather than short single-shot tasks. [SHARE w/ engineering team]

- **[Now introducing Gemini Enterprise for Financial Services](https://cloud.google.com/blog/products/ai-machine-learning/introducing-gemini-enterprise-for-financial-services/)** — Google's pitch for what financial-services AI needs on top of a general model: real-time market data accuracy, verifiable data lineage, and strict security. Competitive context for what you're building in-house. [SHARE w/ leadership]

- **[Agentic Search](https://mistral.ai/news/agentic-search/)** — Mistral's new retrieval layer for navigating, reading, and verifying information inside complex documents. Same problem space as your underwriting OCR/RAG pipeline — worth seeing how they frame verification. [READ DEEPER]

- **[Agentic observability with Amazon OpenSearch Service MCP Apps](https://aws.amazon.com/blogs/machine-learning/agentic-observability-with-amazon-opensearch-service-mcp-apps/)** — A locally-run MCP server that lets an agent move from alert → trace → logs → root cause in one conversation, with inline verification at each step. Bedrock-adjacent and testable this week. [TRY]
