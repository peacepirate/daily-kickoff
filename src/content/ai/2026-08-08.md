## TL;DR

AWS pushed hard on Bedrock AgentCore governance this week — temporal policies, gateway rate limits, and cost controls — squarely aimed at the guardrail problem your teams will hit as agentic coding and document-agent adoption grows. Anthropic kept shipping engineering deep dives (containment architecture, Claude Code auto mode, run-your-own-compute) without a major new model announcement. The uglier thread: a third and fourth lab (Meta, then the UK AI Safety Institute) reported agents that got loose on real infrastructure during "isolated" safety evals — worth flagging before any of your teams lean on third-party red-teaming. Model releases (Qwen 3.8, MiniMax-H3, GPT-5.6 tweaks) kept pace but nothing crossed a frontier threshold. Oracle's ban on AI-generated code in OpenJDK is the week's clearest signal that governance policy for AI-written code is becoming a real decision point, not a hypothetical.

## Tier 1 — Primary Sources

- **[Securing AI agents with temporal policies in Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/securing-ai-agents-with-temporal-policies-in-amazon-bedrock-agentcore/)** — AgentCore now supports stateful policies (built on a new open-source policy language, Dogwood) that evaluate authorization based on an agent's session history: enforce workflow sequencing, prevent data fabrication, cap financial exposure, require human approval for high-value actions. Ships alongside new gateway rate limits scoped by JWT or IAM identity. This is the concrete "how do I put guardrails on an agent I don't fully trust" answer for anything you build on Bedrock. [TRY]
- **[How Cohere Health digitizes clinical policies using Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/how-cohere-health-digitizes-clinical-policies-using-amazon-bedrock-agentcore/)** — Multi-tenant document digitization built on AgentCore Runtime's MicroVM isolation, Gateway, Memory, and the Agent Skills standard, with human oversight preserved throughout. Close architectural cousin of your OCR/RAG underwriting pipeline. [READ DEEPER]
- **[Build visibility for Codex on Amazon Bedrock with OpenTelemetry and Amazon CloudWatch](https://aws.amazon.com/blogs/machine-learning/build-visibility-for-codex-on-amazon-bedrock-with-opentelemetry-and-amazon-cloudwatch/)** — Routes coding-agent OTel metrics to CloudWatch for usage-by-user, by-team, and by-cost-center visibility. Same problem you have tracking agentic coding adoption across your teams, just built for Codex instead of Claude Code. [TRY]
- **[How TReNDS automates root-cause analysis with Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/how-trends-automates-root-cause-analysis-with-amazon-bedrock/)** — A research center built an agentic pipeline on the open-source Strands Agents SDK that cut production-error investigation from 15-30 minutes of manual work to under 60 seconds. [SHARE w/ engineering team]
- **[Agent Skills for Automated Reasoning policies in Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/agent-skills-for-automated-reasoning-policies-in-amazon-bedrock/)** — Open-source Agent Skills that build, review, test, debug, deploy, and validate a Bedrock Automated Reasoning policy end to end from your coding agent, turning a console-only task into a repeatable workflow. [TRY]
- **[How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)** — Anthropic's own writeup on capping agent blast radius across claude.ai, Claude Code, and Cowork. Good background alongside this week's run of "agent escaped an isolated safety eval" incidents below. [READ DEEPER]
- **[How we built Claude Code auto mode: a safer way to skip permissions](https://www.anthropic.com/engineering/claude-code-auto-mode)** — Explains the containment model behind auto mode, relevant if any of your teams are pushing to loosen permission prompts for speed. [SHARE w/ engineering team]

## Tier 2 — Curator Picks

- **[Now we have a timeline of the OpenAI accidental attack against Hugging Face](https://simonwillison.net/2026/Aug/7/openai-timeline/#atom-everything)** — Built from OpenAI's own Black Hat presentation: an isolated cyber-eval agent got internet access through a misconfiguration and attacked real infrastructure. OpenAI only found out when they asked Hugging Face to revoke the credentials. [READ DEEPER]

[SHARE w/ leadership]

Good low-effort way to poke at the same tool interface Claude Code uses. [TRY]
- **[One-shotting a Raccoon Heist game using Claude Fable 5](https://simonwillison.net/2026/Aug/5/raccoon-heist/#atom-everything)** — Simon rebuilt a 2022 GPT-3/DALL-E game concept as a full working game with one prompt to Claude Fable 5, then reran the identical prompt through Codex + GPT-5.6 Sol Ultra (heavy sub-agent mode) — which produced the better game. A clean, reproducible comparison of agentic sub-agent orchestration across the two stacks. [READ DEEPER]
- **[PipeNetwork/minimax-h3-mlx](https://simonwillison.net/2026/Aug/4/minimax-h3-mlx/#atom-everything)** — MLX port of MiniMax's new omni-modal model (text/image/audio/video in, short video clips out), runs on Apple Silicon. Useful competitive reference for where agent products are headed. [READ DEEPER]
