## What's New

- **[Expanding Claude availability and deployment choice on Google Cloud](https://cloud.google.com/blog/products/ai-machine-learning/expanding-claude-availability-on-google-cloud/)** — An Anthropic-managed Claude deployment option is now GA on Google Cloud, alongside the existing Google-managed option. Same frontier models, same pricing, day zero. So what: if your org ever revisits single-cloud dependence on Bedrock, this is a real alternative, not a rumor. [SHARE w/ leadership]

- **[Donating Agent Skills to the Agentic AI Foundation](https://simonwillison.net/2026/Oct/22/donating-agent-skills/)** — Anthropic is handing the Agent Skills standard to the AAIF under the Linux Foundation — the same home MCP moved to. So what: the skills format your teams build Claude Code workflows on is now vendor-neutral, which lowers lock-in risk for anything you standardize on internally. [SHARE w/ engineering team]

- **[How Rescale built an AI triage agent with Strands Agents and AI-DLC](https://aws.amazon.com/blogs/machine-learning/how-rescale-built-an-ai-triage-agent-with-strands-agents-and-ai-dlc/)** — Rescale used AWS's AI-Driven Development Lifecycle framework with Strands Agents and Bedrock to build a test-triage agent in weeks, and is scaling the practice org-wide. So what: this is close to the exact adoption curve you're driving across your 6–10 teams — a documented reference, not theory. [READ DEEPER]

- **[How IskayPet unified corporate knowledge with Amazon Bedrock Managed Knowledge Bases](https://aws.amazon.com/blogs/machine-learning/how-iskaypet-unified-corporate-knowledge-with-amazon-bedrock-managed-knowledge-bases/)** — A multilingual corporate knowledge assistant built entirely on Bedrock Managed Knowledge Bases, with no RAG infrastructure to maintain. So what: a concrete trade-off case for your underwriting doc-search stack — managed KB vs. the custom RAG pipeline you run today. [READ DEEPER]

- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — New flagship release from Mistral. Today's feed didn't carry benchmark or capability detail — worth a glance at the source post directly. [SHARE w/ engineering team]

- **[LangSmith LLM Gateway: Runtime Controls for Agents](https://www.langchain.com/blog/langsmith-llm-gateway-runtime-controls-for-production-agents)** — Public beta: spend caps, rate limits, model fallbacks, and PII redaction for production agents, provider-neutral. So what: a concrete governance pattern to compare against whatever guardrails (or lack of them) your teams have on agent usage today. [TRY]

- **[LLMs are making formal software verification feasible at a much larger scale](https://www.anthropic.com/research/formal-verification)** — Anthropic research, trending on HN (348 points). So what: directly relevant to how much agentic-coding output you can trust before it ships in a regulated financial-services environment. [READ DEEPER]

- **[Docling v2.142.1](https://github.com/docling-project/docling/releases/tag/v2.142.1)** — A batch of hardening fixes: clamped page-range bounds, limited decompressed size on DOCX/XLSX/EPUB members, bounded image decode pixels, bounded regex spans. So what: if Docling sits anywhere in your document-ingestion pipeline, these are resource-exhaustion/DoS fixes on untrusted document input — worth a dependency bump, not just a changelog skim. [SHARE w/ engineering team]
