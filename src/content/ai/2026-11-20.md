## TL;DR

Agent governance and agentic coding tooling dominated the last 24 hours — BMW's enterprise governance framework, a Bedrock AgentCore harness update, and a new Claude Code security-skill bundle are the throughline. Document AI got a Docling point release. Mistral dropped open weights for Mistral Large 4.

## What's New

- **[How the BMW Group governs hundreds of agents across thousands of developers](https://aws.amazon.com/blogs/machine-learning/how-the-bmw-group-governs-hundreds-of-agents-across-thousands-of-developers/)** — BMW's R&D org shares how it builds, governs, and operates agents at scale without sacrificing speed or compliance. Directly applicable to running agentic coding adoption across multiple teams in a regulated shop. `[SHARE w/ leadership]`

- **[Amazon Bedrock AgentCore harness adds Strands harness defaults, built-in tools, and lifecycle hooks](https://aws.amazon.com/blogs/machine-learning/amazon-bedrock-agentcore-harness-adds-strands-harness-defaults-built-in-tools-and-lifecycle-hooks/)** — AgentCore now runs on the open-source Strands harness: task-oriented defaults, automatic prompt caching, proactive context management, plus lifecycle hooks for deterministic allow/deny checks in the agent loop. The lifecycle hooks are the piece worth a look for guardrails on agent actions in underwriting workflows. `[TRY]`

- **[Use Kimi Code CLI with models on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/use-kimi-code-cli-with-models-on-amazon-bedrock/)** — Kimi Code CLI v2.7.0 adds a native Bedrock provider, authenticating via your standard AWS credential chain (named profiles or SSO) instead of a separate API key. Same pattern you'd want for any coding agent you bring into the Bedrock environment. `[TRY]`

- **[LangSmith Tool Gateway: Secure, governed tool use for agents](https://www.langchain.com/blog/langsmith-tool-gateway)** — Now in public beta: a gateway that handles credentials, identity, and access for every agent tool call, with policies, approvals, and traces. Relevant if any of your teams are wiring agents to internal tools/APIs and need an audit trail. `[SHARE w/ engineering team]`

- **[Docling v2.151.1](https://github.com/docling-project/docling/releases/tag/v2.151.1)** — Point release: preserves VLM page-range provenance across document assembly, fixes OpenCV FIPS aborts (relevant if you're in a FIPS-constrained environment), and keeps escaped citation brackets out of display math. Small release, but directly in the OCR/RAG lane. `[READ DEEPER]` — worth checking if you use Docling anywhere in the ingestion pipeline.

- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4-oss/)** — Mistral released open weights for its new flagship, pitched at agentic coding and cybersecurity use cases. Another open-weight option to have on the radar for anything that can't go through Bedrock/Claude. `[SHARE w/ engineering team]`

- **[Claude-BugHunter](https://github.com/elementalsouls/Claude-BugHunter)** — A Claude Code skill bundle for bug hunting and red-team work: 82 skills, 15 slash commands, 681 disclosed-report patterns across 24 vulnerability classes, plus enterprise identity/infra attack matrices. Worth a look for security review passes on agent-generated code. `[SHARE w/ engineering team]`

- **[Claude solves two open problems in the physics of black holes](https://www.anthropic.com/research/claude-black-hole-physics)** — Anthropic research result, not a product launch, but a real signal on reasoning depth: Claude working through genuinely unsolved problems, not benchmark questions. `[READ DEEPER]` — useful context for how much to trust Claude Code on hard, open-ended engineering problems.

## Personal / Side-Project Watch

- **[Ollama v0.40.17](https://github.com/ollama/ollama/releases/tag/v0.40.17-rc2)** — Local-model runtime update: Vulkan integrated-GPU memory mapping, concurrent generation support in MLX, llama.cpp bumped to b12257. Routine maintenance release, no action needed unless you're actively running local models for Gods of the Future Past.
