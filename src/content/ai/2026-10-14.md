## What's New

- **[Redesigning source control at Anthropic](https://www.anthropic.com/engineering/redesigning-source-control)** — Anthropic's merge rate went from ~2,500/day to 30,000+/day in five months as AI-assisted coding scaled, forcing them to build an in-house VCS. If your teams are seeing commit-velocity growth from agentic coding adoption, this is a data point for the "our tooling needs to catch up" conversation. [SHARE w/ leadership]

- **[Gemini 4 Argon](https://deepmind.google/blog/introducing-gemini-4-argon/)** — Google's new frontier model went GA today, also available on Google Cloud and with a dedicated robotics variant. Another data point in the model race you're tracking for Bedrock parity. [SHARE w/ leadership]

- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — Mistral's new flagship, released the same day as Argon. No Bedrock availability yet; worth a glance if you evaluate open-weight-adjacent options. [SHARE w/ leadership]

- **[Build long-horizon agents with Grok 4.7 on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/build-long-horizon-agents-with-grok-4-7-on-amazon-bedrock/)** — Grok 4.7 is now on Bedrock. AWS's post builds a tool-calling agent and measures correctness vs. token cost across four reasoning-effort levels, then shows how to tune that trade-off per request in production. [TRY]

- **[Natural language security queries at Orca Security using Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/natural-language-security-queries-at-orca-security-using-amazon-bedrock/)** — A multi-stage Bedrock architecture that converts plain-English questions into structured queries, cutting query cost 90%, input tokens 93%, and latency 75% vs. their initial baseline. [READ DEEPER]

- **[How ShipStation Global built an AI IT help desk on Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/how-shipstation-global-built-an-ai-it-help-desk-on-amazon-bedrock-agentcore/)** — A Slack-based AgentCore agent that answers from a knowledge base, reads error screenshots, and files Jira tickets. 97.5% of channel queries resolved in its first three months. [SHARE w/ engineering team]

- **[EU AI Act compliance for AI agents: a practical engineering guide](https://arize.com/blog/eu-ai-act-compliance-ai-agents/)** — Walks through agent traces, human oversight, production evals, and log retention for compliance, using a credit-assistant (regulated lending) example. Close to your own underwriting-agent surface area. [SHARE w/ leadership]

- **[MCP in LangChain: Stateless Protocol, Elicitation, and More!](https://www.langchain.com/blog/mcp-in-langchain-stateless-protocol-elicitation-and-more)** — LangChain's MCP support now lives in `langchain.mcp`, built on FastMCP for the 2026-07-28 spec, with elicitation handled as a LangGraph interrupt. [TRY]

## Personal / Side-Project Watch

**[Ollama v0.40.4](https://github.com/ollama/ollama/releases/tag/v0.40.4)** adds "decision models" runnable straight from the CLI — yes/no classification, labeling, and rubric scoring on local input without a full chat round-trip. Useful if you want a cheap local-LLM step in the content pipeline for Gods of the Future Past instead of calling out to Bedrock.
