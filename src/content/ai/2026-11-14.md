## TL;DR

Big week for model releases: Anthropic shipped Claude Fable 5.2 and Mythos 5.2, Google made Gemini 4 Carbon generally available and launched the cheaper Gemini 4 Hydrogen, and Mistral released Mistral Large 4. On the Bedrock side, AWS published four posts directly useful for your work: model routing by cost-per-task, AgentCore session-startup patterns, per-user cost attribution, and a lever-by-lever breakdown of what drives your Bedrock bill. Document AI got real movement too — Google Cloud's AlloyDB gained native classify/extract functions and Docling shipped a PII-exposure fix. Outside the big labs, the agentic-coding ecosystem kept building: DSPy graduated its RLM/GEPA modules out of experimental, and an open-source code-review agent from Alibaba crossed 50k stars. Quiet week for drama — skip the NVIDIA CEO story and the LangChain funding round, neither changes anything about how you build.

## Tier 1 — Primary Sources

- **[Claude Code 2.1.312 → 2.1.325](https://releasebot.io/updates/anthropic/claude-code#2.1.325)** — Ten point releases this week with no published changelog detail, so treat as "shipping fast" signal rather than a specific feature to act on. [SKIP]
- **[Operate Claude Managed Agents inside your security perimeter](https://releasebot.io/updates/anthropic#Operate-Claude-Managed-Agents-inside-your-security-perimeter)** — New Anthropic offering for running managed agents inside your own network boundary, relevant if your compliance team has ever blocked an agent deployment on data-residency grounds. [SHARE w/ leadership]
- **[Building strong safety evaluations](https://www.anthropic.com/research/building-strong-safety-evaluations)** — Anthropic's own methodology for building rigorous evals; the same discipline applies to grading RAG/OCR output quality, not just model safety. [READ DEEPER]
- **[Route coding agent requests to the right model on Amazon Bedrock with NVIDIA NeMo Switchyard](https://aws.amazon.com/blogs/machine-learning/route-coding-agent-requests-to-the-right-model-on-amazon-bedrock-with-nvidia-nemo-switchyard/)** — Deploys LiteLLM + NeMo Switchyard on Bedrock to route coding-agent requests by cost per *solved task*, not price per token — the metric that actually matters when you're running Claude Code across 6–10 teams. [SHARE w/ engineering team]
- **[Architecture patterns for fast session startup on Amazon Bedrock AgentCore runtime](https://aws.amazon.com/blogs/machine-learning/architecture-patterns-for-fast-session-startup-on-amazon-bedrock-agentcore-runtime/)** — AgentCore runtime V2 snapshots your initialized environment so session start no longer scales with image size; four patterns for keeping setup off the first request. [READ DEEPER]
- **[Cost attribution and controls for AI developer and productivity tools on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/cost-attribution-and-controls-for-ai-developer-and-productivity-tools-on-amazon-bedrock/)** — Zero-instrumentation per-user cost tracing via IAM Identity Center, session tags, and CUR 2.0, plus per-user usage caps. This is the Bedrock cost-governance answer leadership will eventually ask you for. [SHARE w/ leadership]
- **[Four Amazon Bedrock inference choices that affect cost](https://aws.amazon.com/blogs/machine-learning/four-amazon-bedrock-inference-choices-that-affect-cost/)** — Cache duration, service tier, reasoning effort, and maxTokens each change token volume and rate independently of prompt tuning. Concrete, testable. [TRY]
- **[How Natera designed an agentic AI system for lab ops with Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/how-natera-designed-an-agentic-ai-system-for-lab-ops-with-amazon-bedrock-agentcore/)** — Full build of SWARM, a knowledge-capture agentic system: 130x faster first response, 96.2% automated ticket coverage. Closest published blueprint to a regulated-industry agentic ops system. [READ DEEPER]
- **[Introducing Gemini 4 Hydrogen](https://deepmind.google/blog/introducing-gemini-4-hydrogen/)** — Google's lowest-cost Gemini 4 tier, priced close to its bigger siblings ($1.50/$7.50 per million tokens). - **[Introducing new AI functions for AlloyDB: ai.classify and ai.extract](https://cloud.google.com/blog/products/databases/ai-classify-and-ai-extract-functions-in-alloydb-ai/)** — Native in-database functions to classify and extract structured fields from unstructured text (notes, invoices, descriptions) without an app-side model-call loop. - **[New AI agent observability and governance across BigQuery and Looker](https://cloud.google.com/blog/products/data-analytics/enterprise-ai-agent-observability-with-bigquery-and-looker/)** — Unified visibility into what data an agent touches, how it reasons, and what it costs — the same questions you'll get asked about any underwriting agent you ship.
