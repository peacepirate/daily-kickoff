## What's New

- **[Milvus client/v3.0.1](https://github.com/milvus-io/milvus/releases/tag/client%2Fv3.0.1)** — First patch release of the Milvus Go SDK v3, targeting Milvus 3.0.1. Adds a full row-level-security SDK surface (row policies, principal tags, count-only principal listing), nested struct/array fields, and path-level replacement for partial upserts. If any of your teams run Milvus for RAG, the RLS surface is the piece worth a look — it's a client-side access-control primitive for exactly the kind of multi-tenant retrieval a regulated underwriting pipeline needs. [SHARE w/ engineering team]

- **[google-labs-code/stitch-skills](https://github.com/google-labs-code/stitch-skills)** — A library of Agent Skills built for Google's Stitch MCP server, following the open Agent Skills standard for compatibility with Claude Code, Gemini CLI, Cursor, and Antigravity. Worth a quick test: open Agent Skills portability across coding agents is a real question as your teams standardize tooling, and this is a concrete example to try it against. [TRY] — load one skill into Claude Code and see if it runs without modification.

- **[HKUDS/CLI-Anything](https://github.com/HKUDS/CLI-Anything)** — Pitched as making "ALL software agent-native" via CLI. Description is thin and the star count looks inflated relative to everything else in today's GitHub Trending pull (one other repo in the same batch claimed 324k stars, which isn't plausible for a trending repo) — flagging the data quality issue rather than the project itself.
