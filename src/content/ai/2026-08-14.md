## TL;DR

Anthropic published a cluster of engineering posts on containing and scaling agents — auto mode's permission-skip safety model, a Claude Code quality postmortem, and a managed-agents architecture piece that LangChain independently echoed the same day. AWS extended Bedrock AgentCore with multi-cloud observability. DeepMind shipped Gemini 3.7 Flash, and document-AI tooling (Docling, Voyage) moved forward on the OCR/RAG side.

## What's New

- **[How we built Claude Code auto mode: a safer way to skip permissions](https://www.anthropic.com/engineering/claude-code-auto-mode)** — Anthropic's design for letting Claude Code run with fewer permission prompts without giving up guardrails. Worth reviewing before recommending broader use across your teams. [TRY]

- **[How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)** — Anthropic's writeup on capping agent blast radius across claude.ai, Claude Code, and Cowork. Useful framing for governance conversations as you scale agentic coding adoption across 6-10 teams. [SHARE w/ leadership]

- **[An update on recent Claude Code quality reports](https://www.anthropic.com/engineering/april-23-postmortem)** — Postmortem on a Claude Code quality regression. Read before it comes up in a team retro. [SHARE w/ engineering team]

- **[Scaling Managed Agents: Decoupling the brain from the hands](https://www.anthropic.com/engineering/managed-agents)** — Anthropic's architecture for separating agent reasoning from execution infrastructure. LangChain published a [parallel piece](https://www.langchain.com/blog/why-managed-agents-are-the-next-big-thing-in-agent-building) the same day — two major players converging on the same pattern is a signal worth tracking. [READ DEEPER]

- **[Monitor on-premises and multi-cloud AI agents with AgentCore Observability](https://aws.amazon.com/blogs/machine-learning/monitor-on-premises-and-multi-cloud-ai-agents-with-agentcore-observability/)** — Bedrock AgentCore Observability now traces agents running outside AWS via OpenTelemetry. Relevant if any of your document-ingestion agents run off-cloud. [SHARE w/ engineering team]

- **[Docling v2.120.0](https://github.com/docling-project/docling/releases/tag/v2.120.0)** — New `--layout-engine` and `--table-structure-engine` CLI flags, plus font-based heading-level inference for PDFs. Directly applicable to underwriting document OCR. [TRY]

- **[voyage-code-4: code retrieval built for coding agents](https://blog.voyageai.com/2026/08/13/voyage-code-4/)** — New code embedding model claiming a 28% average lead over Cohere Embed v4 on a coding-agent retrieval benchmark. [READ DEEPER]

- **[Introducing Gemini 3.7 Flash](https://deepmind.google/blog/introducing-gemini-3-7-flash/)** — DeepMind's latest fast-tier model. Not Bedrock-relevant today, but worth knowing it exists for competitive context. [SKIP]
