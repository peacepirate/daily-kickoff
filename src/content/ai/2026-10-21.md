## TL;DR

Security dominates today: a compromised CA affects trust stores everywhere, and AWS posted two pieces on cryptographically identifying AI agents — relevant as your agentic coding rollout grows past a handful of teams. AWS also published a close analog to your own underwriting RAG problem: a regulated, multi-tenant document search system on Bedrock. Mistral shipped a new flagship model and Docling added a VLM-based form parser.

## What's New

- **[eMudhra Intermediate CA Compromise](https://simonwillison.net/2026/Oct/20/emudhra-certificates/)** — Private keys for eight eMudhra intermediate CA certs were stolen. They chain to roots trusted by Mozilla, Microsoft, Apple, and Chrome, so any bundled trust store (Linux `ca-certificates`, Python's `certifi`) needs an update. Check whether anything your teams run pins or bundles certs from this chain. [SHARE w/ engineering team]

- **[Securing AI agent identity with X.509 PKI on AWS](https://aws.amazon.com/blogs/machine-learning/securing-ai-agent-identity-with-x-509-pki-on-aws/)** — Reference architecture for proving which agent made a request: signed envelopes, user-signed delegation, audience-scoped tokens, real-time revocation. This is the governance layer that's missing once agent-to-agent and MCP tool calls move past a prototype. [SHARE w/ engineering team]

- **[How Octave built a secure multi-tenant AI foundation on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/how-octave-built-a-secure-multi-tenant-ai-foundation-on-amazon-bedrock/)** — Complaint-triage search over 2 billion regulated documents, isolated per tenant, using Cohere Embed v4 and Bedrock AgentCore. This is the shape of problem your underwriting document search sits in. [READ DEEPER]

- **[Discover tools at runtime with AWS Agent Registry](https://aws.amazon.com/blogs/machine-learning/discover-tools-at-runtime-with-aws-agent-registry/)** — A discover/instantiate/execute pattern for agents picking MCP servers and tools via semantic search at runtime, instead of hardcoding every tool at build time. Worth knowing before your MCP tool count becomes a maintenance problem. [READ DEEPER]

- **[Using Claude to reduce the attack surface of code](https://www.anthropic.com/research/attack-surface-reduction)** — Anthropic research on using Claude to shrink a codebase's exposed surface. Directly testable against a real repo. [TRY]

- **[Docling v2.141.0](https://github.com/docling-project/docling/releases/tag/v2.141.0)** — Adds Nemotron-3.5-Parse as a supported VLM model and a geometric solver for mapping AcroForm fields. Incremental, but relevant if Docling is anywhere in your OCR/ingestion stack. [SKIP]

- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — New flagship model from Mistral. No benchmark detail in today's feed to act on yet. [SKIP]
