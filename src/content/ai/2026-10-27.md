## TL;DR

A quiet lab-release day with one real security story: Arize caught their support agent leaking a stranger's data to a prompt-injection attack on 28 of 100 runs, and traced exactly how. AWS shipped two Bedrock patterns — prompt caching and agentic retrieval — that map directly onto your document-ingestion work. Mistral and OpenAI both dropped new models, and Cloudflare disclosed a cross-tenant KV-cache leak in a Workers AI model worth a security skim.

## What's New

- **[A web page talked our agent into leaking a stranger's data. Here's how we caught it.](https://arize.com/blog/indirect-prompt-injection-ai-agents/)** — A page told a support agent to look up a different customer's data, and it complied 28% of the time. Arize found the leak in a trace, closed it with a scope guardrail, and now monitors the injection rate in production. Directly applicable to any agent on your ingestion/RAG pipelines that touches customer or applicant data. [READ DEEPER]
- **[Build agentic retrieval on a Managed Amazon Bedrock Knowledge Base with CDK](https://aws.amazon.com/blogs/machine-learning/build-agentic-retrieval-on-a-managed-amazon-bedrock-knowledge-base-with-cdk/)** — An agent that routes across two knowledge bases through the AgentCore Gateway, returns grounded/cited answers, and ships with seven layers of observability plus continuous eval, all as one CDK app. This is the architecture shape for underwriting RAG done right. [READ DEEPER]
- **[Groundhog Day for AI agents: Prompt caching patterns for using OpenAI models on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/groundhog-day-for-ai-agents-prompt-caching-patterns-for-using-openai-models-on-amazon-bedrock/)** — Agents re-read their whole context on every step. This post shows the caching pattern that stops Bedrock from resending the same tools, instructions, and history each turn. Cheap to test, real cost/latency payoff on any multi-step agent. [TRY]
- **[Cross-request KV cache exposure in the GLM-5.3 Workers AI model](https://blog.cloudflare.com/kv-cache-exposure-remediation/)** (HN, 137 pts) — A cross-tenant data leak in a Cloudflare-hosted inference model's KV cache. Not your stack, but it's the kind of shared-infra failure mode worth a quick read before trusting any multi-tenant inference endpoint. [SHARE w/ engineering team]
- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — New flagship model from Mistral. Worth a bench run against whatever you're currently using for document classification/extraction. [SHARE w/ engineering team]
- **[GPT-6.1 Terra](https://simonwillison.net/2026/Oct/26/gpt-61-terra/)** — OpenAI's new fast model, pitched on visual reasoning and computer use (reading forms, technical drawings). Not Bedrock-available, low relevance to your stack right now. [SKIP]
- **[Docling v2.143.0](https://github.com/docling-project/docling/releases/tag/v2.143.0)** — Mixed-format ZIP input support, deferred local-provider imports for VLM pipelines, and a new way for a VLM to declare a valid end-of-output. Incremental but relevant if Docling is anywhere in your OCR/ingestion toolchain. [TRY]
