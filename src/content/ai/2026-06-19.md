# AI Digest — Friday, June 19, 2026
*Coverage window: previous 24 hours*

## TL;DR
DeepSeek-V4 preview is live, claiming top-tier reasoning and a major leap in agent capability — the one to watch for Bedrock availability. AWS Bedrock AgentCore gets GA web search, making live-data retrieval trivial in agent pipelines. Google announces Gemini Omni and DiffusionGemma on the same day.

## What's New

- **[Introducing Web Search on Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/introducing-web-search-on-amazon-bedrock-agentcore/)** — Web search is now GA inside AgentCore, letting your agents pull live data without custom tool builds. The post walks through wiring it in with a few lines of code. Direct unlock for teams building RAG-adjacent or research agents on Bedrock. `[TRY]`

- **[DeepSeek-V4 Preview](https://mp.weixin.qq.com/s/8bxXqS2R8Fx5-1TLDBiEDg)** — DeepSeek-V4 is live on web, app, and API — announcing world-class reasoning performance and a significant jump in agent capabilities. No English write-up yet but this is the model to track once it hits Bedrock. `[SHARE w/ leadership]`

- **[Introducing Gemini Omni](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)** — Google's new multimodal model launch. No detailed spec available from the fetch, but worth noting alongside DiffusionGemma below.

- **[DiffusionGemma: 4x faster text generation](https://blog.google/innovation-and-ai/technology/developers-tools/diffusion-gemma-faster-text-generation/?utm_source=deepmind.google&utm_medium=referral&utm_campaign=gdm&utm_content=)** — Google claims 4x throughput improvement using a diffusion-based text generation approach on Gemma. Relevant if latency is a constraint in your doc ingestion pipeline.

- **[Securing the future of AI agents](https://deepmind.google/blog/securing-the-future-of-ai-agents/)** — DeepMind signals investment in multi-agent AI safety research. As you scale agentic coding adoption across teams, the threat models here (prompt injection, tool misuse, inter-agent trust) are ones you'll encounter. `[READ DEEPER]`

- **[codebase-memory-mcp](https://github.com/DeusData/codebase-memory-mcp)** — MCP server that indexes a codebase into a persistent knowledge graph: 158 languages, sub-ms queries, single static binary, claims 99% token reduction. If that holds up, it's a practical tool for code-heavy agents. `[TRY]`

- **[MCP auth framing — Sean Lynch via Simon Willison](https://simonwillison.net/2026/Jun/19/sean-lynch/#atom-everything)** — Sharp observation: MCP's real value may be isolating auth flows outside the agent's context window, not the protocol itself. Useful mental model when evaluating MCP server designs for your teams.
