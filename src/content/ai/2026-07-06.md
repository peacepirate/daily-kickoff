## TL;DR

AWS drops a multi-component PII redaction pipeline (Nova + Textract + SAM 3) that maps directly to your underwriting doc ingestion work. MiniMax joins Bedrock's model catalog. Anthropic adds admin spend controls for teams running Claude. Tencent's Hy3 — 295B MoE, Apache 2.0 — is the new open-weight frontier model to watch.

## What's New

- **[Automatically redact PII in images with Amazon Nova](https://aws.amazon.com/blogs/machine-learning/automatically-redact-pii-in-images-with-amazon-nova/)** — AWS walkthrough of a pipeline where Nova handles contextual vision reasoning while delegating OCR to Textract and pixel-level segmentation to Meta's SAM 3 — covering edge cases like rotated IDs, fingerprints, and license plates. The Nova-as-orchestrator pattern is the architecturally interesting piece: Nova doesn't do OCR, it directs tools that do. That separation of concerns is worth borrowing for your own doc ingestion pipeline. `[READ DEEPER]`

- **[Run MiniMax models on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/run-minimax-models-on-amazon-bedrock/)** — MiniMax is now live on Bedrock with on-demand inference, targeting agentic apps, long-context document analysis, and software engineering workflows. Adds a credible alternative to your current Bedrock model lineup — check the context window and pricing tiers against what you're running today. `[TRY]`

- **[Giving admins more visibility and control over Claude spend](https://releasebot.io/updates/anthropic#Giving-admins-more-visibility-and-control-over-Claude-spend)** — Anthropic is adding spend visibility and per-team controls at the admin level. This is currently API-tier; verify whether it surfaces on the Bedrock side (likely via AWS Cost Explorer tagging instead). Either way, cost attribution per team is the missing piece as you scale Claude Code adoption — good to flag upward. `[SHARE w/ leadership]`

- **[Securing the future of AI agents](https://deepmind.google/blog/securing-the-future-of-ai-agents/)** — DeepMind post covering prompt injection, tool misuse, trust boundary failures, and agent containment. No new tooling released, but the threat taxonomy is useful framing for your teams as they build more autonomous coding workflows. `[SHARE w/ engineering team]`

- **[tencent/Hy3](https://simonwillison.net/2026/Jul/6/hy3/#atom-everything)** — Tencent drops Hy3 under Apache 2.0: 295B total parameters, 21B active (MoE architecture), outperforming same-size models and reportedly rivaling flagships with 2–5x the active parameter count. Full model is 598GB — datacenter-only for now — but distilled variants will follow. This is where the open-weight frontier sits heading into mid-2026. `[READ DEEPER]`

- **[addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)** — Addy Osmani's production-grade engineering skills collection for AI coding agents, sitting at 70k+ stars. If your teams are building or customizing Claude Code workflows, this is a high-signal curated reference for what production patterns look like at scale. `[SHARE w/ engineering team]`

- **[Teaching models to forget: Selective unlearning with Amazon Nova](https://aws.amazon.com/blogs/machine-learning/teaching-models-to-forget-selective-unlearning-with-amazon-nova/)** — AWS introduces Reverse DPO (rDPO) as the technique behind Nova's Customizable Content Moderation Settings — lets you reduce over-deflection in fine-tuned models without retraining from scratch. The compliance angle is real: if you ever need a fine-tuned underwriting model to stop producing certain outputs without a full retraining cycle, rDPO is the mechanism to understand. `[READ DEEPER]`
