## TL;DR
AWS shipped Grok 4.6 on Bedrock plus two case studies close to your work: a medical-claims IDP pipeline shaped like your underwriting document flow, and a multi-tenant agent security pattern built on AgentCore. Anthropic's engineering blog resurfaced the same five posts you've already read this week — skipped today. TypeSafe AI's "Jev," a new model class that outputs probabilities instead of text, got broad curator coverage and is worth 5 minutes to understand.

## What's New

- **[xAI's Grok 4.6 is now available in Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/xais-grok-4-6-is-now-available-in-amazon-bedrock/)** — Frontier model for long-running agents and coding: 500K token context, four reasoning-effort levels, Converse API and cross-Region inference support. One more model option on the Bedrock stack you already run Claude Code through. [SHARE w/ engineering team]

- **[Reducing medical claims review time with AI on AWS: The EXL Medical IDP solution](https://aws.amazon.com/blogs/machine-learning/reducing-medical-claims-review-time-with-ai-on-aws-the-exl-medical-idp-solution/)** — IDP combined with domain-specific LLMs on SageMaker and Bedrock cut claims review from 100+ minutes per case. Same document-extraction shape as your underwriting pipeline — worth comparing their model and architecture choices to yours. [READ DEEPER]

- **[How Benchling secured multi-tenant AI agents with Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/how-benchling-secured-multi-tenant-ai-agents-with-amazon-bedrock-agentcore/)** — Defense-in-depth for untrusted agent-generated code: VPC-mode Code Interpreter, Route 53 Resolver DNS Firewall, and VPC endpoint policies blocking exfiltration including through DNS. A concrete isolation pattern if your teams' agent use keeps growing across tenants or business lines. [SHARE w/ engineering team]

- **[Jev introduces a new shape of LLM - System One, aka Decision Models](https://simonwillison.net/2026/Sep/21/jev/)** — TypeSafe AI's Jev takes text in but returns floating-point decisions — category, yes/no, rating, confidence — instead of generated text. Pitched as a fast, cheap judge or router rather than a general model, and it's already showing up as a LangSmith-eval and agent-harness component elsewhere in today's fetch. [READ DEEPER]

- **[MiMo-V2.6-Pro: Intelligence, Performance and Price Analysis](https://artificialanalysis.ai/models/mimo-v2-6-pro)** — Xiaomi's new open-weights model, reportedly trained for $3M, now leading open-weight benchmarks. Notable as a training-cost data point, nothing to act on. [SKIP]
