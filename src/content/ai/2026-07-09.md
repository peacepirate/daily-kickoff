# AI Digest — Wednesday, July 9, 2026

*Coverage window: previous 24 hours*

## TL;DR

Big day across all three frontier labs. OpenAI pushed GPT-5.6 (Luna/Terra/Sol) to GA, Google launched Gemini Omni and added computer use to Gemini 3.5 Flash, and Meta shipped Muse Spark 1.1 with its first public API. The AWS blog dropped a practical MCP tool design guide directly relevant to your teams. Mistral OCR 4 is also out and worth evaluating against your document ingestion pipeline.

## What's New

- **[GPT-5.6 — Luna, Terra, Sol](https://openai.com/index/gpt-5-6/)** — OpenAI's new flagship hits GA in three sizes: Luna ($1/$6 per 1M tokens), Terra ($2.50/$15), Sol ($5/$30). 1M-token context, 128K output limit, February 2026 knowledge cutoff. Sol is priced below Claude Fable 5 ($10/$50) and comparable to Opus — the competitive pricing on reasoning-heavy tasks is the story here. [SHARE w/ leadership]

- **[AWS: MCP Tool Design — Practical Approaches and Tradeoffs](https://aws.amazon.com/blogs/machine-learning/mcp-tool-design-practical-approaches-and-tradeoffs/)** — AWS ML Blog post on where MCP tool design goes wrong and how to fix it with context engineering. If your teams are building MCP servers for Claude Code, this is the most directly applicable thing published today. Run this through a team design review. [TRY] [SHARE w/ engineering team]

- **[Mistral OCR 4](https://mistral.ai/news/ocr-4/)** — Mistral's new "state of the art document intelligence model." No technical details in the source snippet, but given your Azure AI Search + OCR pipeline for underwriting, this is worth a direct benchmark against your real docs before dismissing it. [READ DEEPER]

- **[Introducing Gemini Omni](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)** — Google's new flagship multimodal model. No pricing or context window details in the source, but positions as the Gemini answer to GPT-5.6 Sol / Claude Opus tier. Worth tracking for AWS Bedrock availability. [SHARE w/ leadership]

- **[Computer use in Gemini 3.5 Flash](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-computer-use-gemini-3-5-flash/)** — Google brings computer use (GUI automation) to Gemini 3.5 Flash. Anthropic launched this pattern first; now it's table stakes across labs. If any of your teams are evaluating agentic automation beyond coding, the competitive field just widened. [SHARE w/ engineering team]

- **[Meta Muse Spark 1.1](https://ai.meta.com/blog/introducing-muse-spark-meta-model-api/)** — Meta's Spark model now has a public API for the first time. Claims significant improvements in agentic tool calling and computer use. The `llm-meta-ai` plugin (Simon Willison) lets you test it via the `llm` CLI immediately. Open-weight lineage makes this relevant if you're watching local LLM options. [TRY]

- **[Securing the Future of AI Agents](https://deepmind.google/blog/securing-the-future-of-ai-agents/)** — DeepMind's framing on agent security risks. As you expand Claude Code across 6–10 teams, the attack surface grows. Worth reading before your next adoption review to have the vocabulary for a leadership conversation about guardrails. [READ DEEPER]

- **[agent-skills (addyosmani)](https://github.com/addyosmani/agent-skills)** — 76k stars. Production-grade engineering skills for AI coding agents. Addy Osmani (Google Chrome) curating patterns that work at scale — strong signal for what's battle-tested. Good reference to share with tech leads building out Claude Code workflows. [SHARE w/ engineering team]
