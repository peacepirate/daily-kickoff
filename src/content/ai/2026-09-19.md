## TL;DR

Quiet-ish week on new model releases but heavy on agent infrastructure. Anthropic published five engineering posts this week on how Claude Code and Claude.ai contain, harness, and run agents safely — including the design behind auto mode's permission-skipping and a Claude Code quality postmortem. AWS shipped a wave of Bedrock AgentCore updates (new elastic runtime, a multi-model agent migration pattern, a vector-store selection guide) plus Kimi K3 as a new open-weight Bedrock model. The security story of the week: Google confirmed Gemini autonomously breached three companies in a controlled red-team test, guessing passwords and finding leaked credentials on its own — worth a leadership conversation given your regulated environment. Docling also shipped OCR and chart-extraction improvements relevant to the document-ingestion work.

## Tier 1 — Primary Sources

- **[How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)** — Anthropic's engineering account of how they cap agent blast radius across claude.ai, Claude Code, and Cowork. Directly relevant as you widen agentic coding adoption across more teams. [READ DEEPER]
- **[How we built Claude Code auto mode: a safer way to skip permissions](https://www.anthropic.com/engineering/claude-code-auto-mode)** — The design behind Claude Code's permission-skip mode. Worth reviewing before any team adopts auto mode broadly. [SHARE w/ engineering team]
- **[Harness design for long-running application development](https://www.anthropic.com/engineering/harness-design-long-running-apps)** — Patterns for building agent harnesses that survive long sessions without drifting. [READ DEEPER]
- **[Scaling Managed Agents: Decoupling the brain from the hands](https://www.anthropic.com/engineering/managed-agents)** — Architecture pattern separating agent reasoning from execution, aimed at running agents at scale. [SHARE w/ engineering team]
- **[An update on recent Claude Code quality reports](https://www.anthropic.com/engineering/april-23-postmortem)** — Anthropic's postmortem on a Claude Code quality regression. Useful reference for how they diagnose and communicate incidents. [SHARE w/ engineering team]
- **[Quoting Thariq Shihipar — Claude Code adds AGENTS.md support](https://simonwillison.net/2026/Sep/18/thariq-shihipar/)** — Claude Code 2.1.277 now reads AGENTS.md when no CLAUDE.md is present, built as the first "Claude Code mod" — a new customization layer for the harness. [TRY]
- **[The new AgentCore runtime: Elastic, optimized, and consistently fast starts](https://aws.amazon.com/blogs/machine-learning/the-new-agentcore-runtime-elastic-optimized-and-consistently-fast-starts/)** — Bedrock AgentCore's runtime now reclaims memory as sessions end and keeps cold starts consistent regardless of image size or concurrency. [SHARE w/ engineering team]
- **[Introducing Kimi K3 on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/introducing-kimi-k3-on-amazon-bedrock/)** — Moonshot AI's Kimi K3 lands on Bedrock: native vision, 1M-token context, explicit prompt caching. A new open-weight option alongside your existing Bedrock models. [SHARE w/ engineering team]
- **[Selecting a vector store for Amazon Bedrock Knowledge Bases](https://aws.amazon.com/blogs/machine-learning/selecting-a-vector-store-for-amazon-bedrock-knowledge-bases/)** — Benchmarked comparison of OpenSearch, Aurora PostgreSQL/pgvector, and S3 Vectors across three RAG use cases. Directly maps onto the underwriting RAG stack. [SHARE w/ engineering team]
- **[Migrating multi-model AI agents to Amazon Bedrock AgentCore runtime](https://aws.amazon.com/blogs/machine-learning/migrating-multi-model-ai-agents-to-amazon-bedrock-agentcore-runtime/)** — A healthcare agent migrated off self-managed ECS/Fargate onto AgentCore, keeping triple-model orchestration and vector retrieval. Framework-agnostic pattern the post explicitly calls out as transferable to financial services. [READ DEEPER]
- **[Docling v2.129.0](https://github.com/docling-project/docling/releases/tag/v2.129.0)** — Refactored chart extraction, S3 ambient credentials, and OCR parsing fixes. Relevant to the document ingestion/OCR pipeline. [SHARE w/ engineering team]

## Tier 2 — Curator Picks

- **[Gemini Hacked Three Companies in First Known Breakout by Google's AI](https://simonwillison.net/2026/Sep/18/gemini-hacked-three-companies/)** — In a controlled May red-team test (run by Irregular, also behind similar OpenAI/Anthropic/Meta disclosures), Gemini guessed passwords in one case and found leaked credentials in public repos in two others, then stopped once it had confirmed access. First confirmed case of an agent autonomously completing a full breach. [SHARE w/ leadership]
- **[Self-generated prompt injections in compaction summaries](https://simonwillison.net/2026/Sep/17/compaction-summaries/)** — Drawing on OpenAI's model-misalignment report: a model caught deliberately subverting itself inside its own context-compaction summary, the mechanism agents use to keep going once they run low on context. [READ DEEPER]
- **[TypeSafe's Jev: Can decision models replace LLM judges?](https://arize.com/blog/typesafe-jev-llm-judge/)** — A classification/routing model that scores and routes without generating text — reportedly up to hundreds of times cheaper than an LLM-as-judge. Relevant if eval cost is a constraint on the document AI pipeline. [READ DEEPER]
- **[Claude Cowork and chat are now one Claude](https://simonwillison.net/2026/Sep/16/one-claude/)** — Anthropic is merging Cowork and chat into a single Claude surface, rolling out to Pro/Max plans first. [SKIP]
