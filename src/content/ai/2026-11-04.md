## What's New

- **[Le Chonk: Built for Coders, Trusted by Defenders](https://mistral.ai/news/mistral-large-4-oss/)** — Mistral open-sourced the weights behind Mistral Large 4, pitched at agentic coding and cybersecurity use. Worth knowing as an open alternative when a Bedrock-hosted model isn't the right fit for a given workload. [SHARE w/ engineering team]

- **[ServiceNow on-behalf-of token exchange with Bedrock AgentCore Gateway](https://aws.amazon.com/blogs/machine-learning/servicenow-on-behalf-of-token-exchange-with-bedrock-agentcore-gateway/)** — AgentCore Gateway now exchanges tokens with Entra ID so an agent calls a backend API as the calling user, not as a generic service identity. This is the identity-passthrough problem that usually eats a sprint; AWS closed it with config instead of code. [READ DEEPER]

- **[Build a semantic layer for agentic AI with EDB Postgres AI and Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/build-a-semantic-layer-for-agentic-ai-with-edb-postgres-ai-and-amazon-bedrock-agentcore/)** — Business meaning, join paths, and row-level security all live in Postgres; a Strands Agents agent on Bedrock AgentCore queries through that layer and only sees what GRANT and RLS allow. A clean template for governed RAG over sensitive data. [READ DEEPER]

- **[Bring structured and unstructured data together with Amazon Quick](https://aws.amazon.com/blogs/machine-learning/bring-structured-and-unstructured-data-together-with-amazon-quick/)** — Walkthrough of connecting S3 as a knowledge base and building a chat agent that answers questions spanning structured and unstructured data in one interface. Adjacent to the document-ingestion problem your team already works. [SHARE w/ engineering team]

- **[How We Optimized Browser Use for Deep Agents](https://www.langchain.com/blog/how-we-optimized-browser-use-for-deep-agents)** — LangChain tested seven browser toolsets for agents, landed on Stagehand (Browserbase), and tuned it using LangSmith traces and evals. A reproducible write-up if any team is extending agents past pure code tasks into web interaction. [READ DEEPER]

- **[thedotmack/claude-mem](https://github.com/thedotmack/claude-mem)** — Trending tool that captures what a Claude Code session did, compresses it, and injects it back into future sessions. Directly relevant to the context-loss problem in long-running agentic coding work. [TRY]

## Personal / Side-Project Watch

- **[Qwen 3.8 27B on my laptop can interpret model weights, too](https://simonwillison.net/2026/Nov/3/qwen-can-interpret-model-weights/)** — Simon Willison reproduces a paper finding that frontier models can read and modify raw neural network weights as text, and gets a smaller local model (Qwen 3.8 27B) to do a version of it on a laptop. Interesting if you're still poking at local LLM limits outside of work.
