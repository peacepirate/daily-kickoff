## TL;DR

AWS had an unusually heavy Bedrock day — six new posts on agent guardrails, agent evaluation, silent-failure detection, and agentic RAG retrieval, several with direct application to your underwriting pipeline and agentic coding rollout. Poolside detailed how a 118B MoE model (Laguna S) is beating a roughly 1T-parameter open-weights model, and a small Claude Code session-keeper tool is worth a quick try. Gemini's new Flash lineup and Mistral OCR 4 are repeats from earlier this week — no new ground there today.

## What's New

- **[Agentic retrieval for Amazon Bedrock Managed Knowledge Base](https://aws.amazon.com/blogs/machine-learning/agentic-retrieval-for-amazon-bedrock-managed-knowledge-base/)** — New AgenticRetrieveStream API breaks multi-part questions into sub-queries before retrieving, instead of the single-shot search classic RAG does. AWS walks through request construction and trace parsing. This targets exactly the failure mode you'd hit on compound underwriting questions — worth a side-by-side test against your Azure AI Search retrieval step. [TRY]

- **[Best practices for applying Amazon Bedrock Guardrails to code generation workflows](https://aws.amazon.com/blogs/machine-learning/best-practices-for-applying-amazon-bedrock-guardrails-to-code-generation-workflows/)** — Guardrail configuration patterns built specifically for coding-assistant workflows, covering capacity planning alongside safety coverage. Useful as a governance reference while you scale agentic coding across your teams. [SHARE w/ engineering team]

- **[Evaluating AI Agents: A production blueprint with Strands and AgentCore](https://aws.amazon.com/blogs/machine-learning/evaluating-ai-agents-a-production-blueprint-with-strands-and-agentcore/)** — Motorway and AWS built an eval pipeline on Strands Agents SDK + Bedrock AgentCore that cut incorrect agent results from 1-in-8 queries to 1-in-50, and dropped issue-detection time from hours to minutes. A concrete template if you're formalizing agent evals rather than relying on spot checks. [READ DEEPER]

- **[Detecting silent agent failures with Amazon Bedrock AgentCore optimization](https://aws.amazon.com/blogs/machine-learning/detecting-silent-agent-failures-with-amazon-bedrock-agentcore-optimization/)** — Surfaces agents that pass every health check but still produce wrong outcomes, then ranks failure patterns by impact so you fix the costliest ones first. Directly applicable once any of your teams' agents move past pilot into production. [SHARE w/ engineering team]

- **[Building trade assistant: How Jefferies optimized front office trading operations with AI](https://aws.amazon.com/blogs/machine-learning/building-trade-assistant-how-jefferies-optimized-front-office-trading-operations-with-ai/)** — Production case study wiring Strands Agents to Bedrock Knowledge Bases via MCP for real-time trading workflows. A concrete example of MCP connecting agents to external data sources in a regulated financial environment, close to your own constraints. [SHARE w/ engineering team]

- **[[AINews] Laguna S 2.1 Released: Cheaper than Deepseek v4 Flash, Better than V4 Pro](https://www.latent.space/p/ainews-laguna-s-21-released-cheaper)** — Poolside's Laguna S, a 118B MoE model, reportedly beats a roughly 1T-parameter open-weights model (Thinky) on quality while costing less to run. Latent Space's companion interview with co-CEO Eiso Kant ([Inside the Model Factory](https://www.latent.space/p/poolside)) explains the training approach behind it. Efficient-model economics worth tracking as an alternative to always reaching for the biggest model. [READ DEEPER]

- **[Show HN: Claude-thermos keeps your Claude session warm for you](https://github.com/izeigerman/claude-thermos)** — Small utility that pings a Claude session to prevent it going cold during long-running agentic work. Trending on HN (76 points). Cheap to try if you or your teams run multi-hour Claude Code sessions. [TRY]

- **[alibaba / open-code-review](https://github.com/alibaba/open-code-review)** — Open-source code review tool combining deterministic pipelines with an LLM agent for line-level comments, with a built-in fine-tuned ruleset for NPE, thread-safety, XSS, and SQL injection issues. Works with both OpenAI and Anthropic models. Worth a look as a reference architecture if any of your teams want automated review gates beyond ad hoc Claude Code review prompts. [SHARE w/ engineering team]
