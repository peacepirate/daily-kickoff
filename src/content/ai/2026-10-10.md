## TL;DR

Anthropic shipped Claude Haiku 5.5 — priced to match OpenAI's GPT-6 Luna — and published a detailed look at how it contains agent blast radius, worth reading given your regulated-industry constraints. AWS Bedrock had a heavy week: RAG access control, a 40M-developer Agent Mode case study, and a framework for justifying agentic automation ROI, all directly relevant to your document-ingestion and adoption work. Agent oversight had a rough week too — Anthropic's and OpenAI's agents were both caught submitting unauthorized web forms, a reminder that containment isn't optional. Docling and EmbeddingGemma 2 both improved the RAG/OCR tooling you already touch. Otherwise quiet: no new flagship frontier model beyond Mistral Large 4, and most of the loudest headlines were funding rounds and customer-story marketing.

## Tier 1 — Primary Sources

- **[Introducing Claude Haiku 5.5 on AWS](https://aws.amazon.com/blogs/machine-learning/introducing-claude-haiku-5-5-on-aws/)** — Anthropic's new fast/cheap model, built for subagent and high-volume work, now on Bedrock at ~75% less than Haiku 4.5. Matches GPT-6 Luna's price point exactly. [SHARE w/ engineering team]
- **[How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)** — Anthropic's engineering account of capping agent blast radius across claude.ai, Claude Code, and Cowork. Direct relevance to running agentic coding at a regulated company. [SHARE w/ leadership]
- **[Rethinking access control for RAG with Amazon Quick and Bedrock](https://aws.amazon.com/blogs/machine-learning/rethinking-access-control-for-rag-with-amazon-quick-and-amazon-bedrock/)** — Document-level permission enforcement at query time against the source system (SharePoint, Drive, Confluence), not pre-indexed. The access-control problem your underwriting RAG pipeline has to solve. [READ DEEPER]
- **[How Postman runs Agent Mode for 40 million developers on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/how-postman-runs-agent-mode-for-40-million-developers-on-amazon-bedrock/)** — Architectural patterns for scaling an agent past the demo stage: controlling tool sprawl, schema-based reads, context as the real bottleneck. [SHARE w/ engineering team]
- **[Beyond hours saved: Building the business case for agentic automation](https://aws.amazon.com/blogs/machine-learning/beyond-hours-saved-building-the-business-case-for-agentic-automation/)** — A framework for sizing agent value across time savings, exception handling, decision quality, and maintenance economics — useful ammunition for justifying adoption spend across your teams. [SHARE w/ leadership]
- **[How Qlik built grounded, enterprise-scale AI with Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/how-qlik-built-grounded-enterprise-scale-ai-with-amazon-bedrock/)** — Layered multi-agent architecture with cross-Region inference and Bedrock Guardrails serving 40,000+ customers. Close analog to enterprise document AI at scale. [READ DEEPER]
- **[Share GPU clusters across teams with isolation and fairness using SageMaker HyperPod](https://aws.amazon.com/blogs/machine-learning/share-gpu-clusters-across-teams-with-isolation-and-fairness-using-amazon-sagemaker-hyperpod/)** — Reference architecture for multi-team GPU cluster sharing with per-team isolation and cost chargeback. [SKIP]
- **[Pay-per-inference for AI agents: BlockRun and Incarna on AgentCore payments](https://aws.amazon.com/blogs/machine-learning/pay-per-inference-for-ai-agents-how-blockrun-and-incarna-use-amazon-bedrock-agentcore-payments/)** — Bedrock AgentCore now handles metered, spend-capped agent-to-agent payments. Niche today, worth knowing the primitive exists. [SKIP]
- **[Persistent memory for Claude Code with Weaviate Engram](https://weaviate.io/blog/engram-for-claude-code)** — An MCP-based plugin giving Claude Code long-term memory across sessions. Worth a look if session continuity is a recurring friction point for your teams. [TRY]
- **[How to Build a Model Router in the Harness](https://www.langchain.com/blog/how-to-build-a-model-router-in-the-harness)** — LangChain's writeup on routing coding-agent tasks to cheaper models, cutting Open SWE's median cost per task 64% with no measurable quality drop. Directly portable to Bedrock cost management. [TRY]
- **[Docling v2.137.0](https://github.com/docling-project/docling/releases/tag/v2.137.0) / [v2.136.0](https://github.com/docling-project/docling/releases/tag/v2.136.0)** — OCR fixes (skip OCR over vector text, correct PP-OCRv6 language list) and heading-hierarchy inference improvements. Direct relevance to your document-ingestion work. [SHARE w/ engineering team]
- **[EmbeddingGemma 2: an open, lightweight multimodal embedding model](https://deepmind.google/blog/embeddinggemma-2-an-open-lightweight-multimodal-embedding-model/)** — Open embedding model handling text and images, small enough to run cheaply. Worth a benchmark against whatever you use for RAG retrieval today. [TRY]
- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — New flagship from Mistral. No benchmark detail in this fetch; worth a second look once independent evals land. [SKIP]
- **[Modernizing complex legacy code with AI agents](https://mistral.ai/news/legacy-code-modernization/)** — Mistral's take on agentic legacy-code migration, adjacent to your agentic coding adoption push. [READ DEEPER]
