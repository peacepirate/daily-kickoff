# AI Digest — Monday, July 7, 2026

*Coverage window: previous 24 hours*

## TL;DR

Google launched Gemini Omni and expanded Managed Agents in the Gemini API with background tasks and remote MCP support. AWS published two Bedrock AgentCore walkthroughs — one using MCP for an AWS support bot, one for serverless image editing — both directly relevant to your agentic work. Mistral dropped OCR 4, worth a look given your document ingestion pipeline.

## What's New

- **[Expanding Managed Agents in Gemini API: background tasks, remote MCP and more](https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api/)** — Google's Managed Agents feature bundle now includes background task execution, remote MCP server connections, and additional orchestration hooks. This is Gemini's direct answer to the Claude agentic harness — and remote MCP alignment means protocol tooling you build for one stack increasingly transfers to the other. `[READ DEEPER]` `[SHARE w/ engineering team]`

- **[Introducing Gemini Omni](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)** — Google's new multimodal flagship model. No technical depth in the source data yet, but a named model release from a primary lab warrants watching. `[READ DEEPER]`

- **[Build an AI-powered AWS support companion with Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/build-an-ai-powered-aws-support-companion-with-amazon-bedrock-agentcore/)** — Full walkthrough: Strands Agents as the orchestration layer, MCP for connecting to AWS services (CloudWatch, re:Post, support case creation), deployed via CloudFormation + Amplify in one script. Concrete production reference for the MCP + AgentCore stack you're likely evaluating. `[TRY]` `[SHARE w/ engineering team]`

- **[Build a serverless image editing agent with Amazon Bedrock AgentCore harness](https://aws.amazon.com/blogs/machine-learning/build-a-serverless-image-editing-agent-with-amazon-bedrock-agentcore-harness/)** — AgentCore harness without custom orchestration code, deployed with CDK. Three tools, auth, encrypted storage, React frontend — all in a single deployment command. The "no custom orchestration" framing is the key signal: AgentCore is maturing toward zero-boilerplate agent hosting. `[SHARE w/ engineering team]`

- **[Introducing Mistral OCR 4](https://mistral.ai/news/ocr-4/)** — Mistral calls it "state of the art document intelligence." No benchmark details in the source data, but given your Azure AI Search + OCR ingestion pipeline for underwriting, this is worth a direct accuracy comparison on your document types. `[TRY]`

- **[Securing the future of AI agents](https://deepmind.google/blog/securing-the-future-of-ai-agents/)** — DeepMind post on agent security. No summary in the source data, but agent security is directly in scope as you scale agentic coding across 6–10 teams. Worth a skim. `[READ DEEPER]`

- **[Show HN: Rowboat – Open-source, local-first alternative to Claude Desktop](https://github.com/rowboatlabs/rowboat)** — Positions itself as a "full-fledged work app" rather than a chat interface, with the ability to build custom work surfaces inside it. Local-first, open source. Interesting if your teams want a self-hosted Claude Code alternative with more UI flexibility. `[SHARE w/ engineering team]`

- **[Anthropic: Bringing Claude Code and Claude Cowork to government](https://releasebot.io/updates/anthropic#Bringing-Claude-Code-and-Claude-Cowork-to-government)** — Claude Code is expanding into government. Relevant context if Capital One's regulatory/compliance posture ever factors into your AI tool evaluations. `[SHARE w/ leadership]`
