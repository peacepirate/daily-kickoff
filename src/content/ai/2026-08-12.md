## TL;DR

Two governance stories lead today: Anthropic extended Compliance API coverage to Claude Cowork and Code, and AWS published a reference deployment for a self-hosted governance gateway sitting in front of Bedrock-hosted Claude. A LangChain benchmark found only 7% of agent turns actually need a frontier model — worth testing against your own agent cost profile. Also worth a read: a paper on extracting hidden reasoning traces from proprietary LLM APIs, relevant if you're thinking about what Bedrock's Claude endpoints expose.

## What's New

- **[Compliance API coverage extends to Claude Cowork and Claude Code](https://releasebot.io/updates/anthropic#Compliance-API-coverage-extends-to-Claude-Cowork-and-Claude-Code)** — Anthropic's audit/export API, previously scoped to claude.ai, now covers Cowork and Code. Directly relevant for a regulated environment where every agent action needs a paper trail. [SHARE w/ leadership]
- **[Deploying Anthropic Claude apps gateway for AWS for enterprise workloads](https://aws.amazon.com/blogs/machine-learning/deploying-anthropic-claude-apps-gateway-for-aws-for-enterprise-workloads/)** — A self-hosted governance layer that sits between Claude Code/Desktop and Bedrock or Claude Platform. AWS's post is a full production reference deployment: architecture, cost, and enterprise patterns. [TRY]
- **[How many of your agent's calls actually need a frontier model?](https://www.langchain.com/blog/switchyard-agent-routing-benchmark)** — LangChain benchmarked NVIDIA NeMo Switchyard on 145 agent tasks. Only 7% of turns needed a frontier model; routing the rest cut cost 74% for a 6-point accuracy hit. A concrete number for any cost conversation about agent spend. [TRY]
- **[Looker's semantic layer governs Gemini Enterprise data for user trust](https://cloud.google.com/blog/products/business-intelligence/integrating-looker-and-gemini-enterprise/)** — A semantic-layer pattern for grounding NL2SQL against structured databases, addressing the same hallucination-from-schema-guessing problem you'd hit mixing structured and unstructured sources in a RAG pipeline. [SHARE w/ engineering team]
- **[Daybreak Red & Daybreak Blue now available on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/accelerate-cyber-defense-with-openai-and-aws-daybreak-red-daybreak-blue-now-available-to-eligible-customers-on-amazon-bedrock/)** — OpenAI's specialized cyber defense models, now on Bedrock for eligible customers, with zero-operator access enforced at the chip level. [SHARE w/ leadership]
- **[A $70-a-month production app replaced a $5,000-a-month platform](https://www.zyte.com/blog/a-70-a-month-production-app-replaced-a-5-000-a-month-platform-what-production-grade-ai-coding-looks-like/)** — Case study in spec-driven development: one engineer, 3,600 tests, agentic coding used to replace a commercial platform outright rather than just accelerate feature work. [SHARE w/ engineering team]
- **[How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)** — Anthropic's engineering team on capping agent blast radius across claude.ai, Claude Code, and Cowork as capability grows. [READ DEEPER]
- **[Stealing Reasoning Traces from Proprietary LLM APIs](https://simonwillison.net/2026/Aug/11/stealing-reasoning-traces/#atom-everything)** — Anthropic, OpenAI, and Google return encrypted chain-of-thought blocks that can be replayed across sessions. Researchers replayed a frontier model's trace into a weaker sibling and recovered the stronger model's reasoning in plaintext. [READ DEEPER]
