## TL;DR
Claude Opus 5.5 and GPT-6 Sol/Luna both landed on Bedrock the same day, with OpenAI cutting prices roughly in half again. Anthropic's engineering blog published two posts on agent containment and Claude Code's new auto-permissions mode, both relevant to how far you push autonomous execution on a regulated stack. AWS also shipped a Bedrock Data Automation + MCP pattern for turning unstructured documents into structured data — the same shape as your underwriting pipeline — and Anthropic quietly opened a GitHub repo aimed at financial services.

- **[Claude Opus 5.5 is now available on AWS Bedrock](https://aws.amazon.com/blogs/machine-learning/claude-opus-5-5-is-now-available-on-aws/)** — Anthropic's most capable Opus model, tuned for agentic coding and long-running tasks, is live on Bedrock alongside Claude Platform. Worth a spot-check against your current Bedrock model on one of the harder underwriting OCR/RAG steps. [TRY]

- **[Bring more intelligence to everyday work with GPT-6 Sol and GPT-6 Luna on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/bring-more-intelligence-to-everyday-work-with-gpt-6-sol-and-gpt-6-luna-on-amazon-bedrock/)** — Landed on Bedrock the same day as Opus 5.5. Per Simon Willison's [side-by-side writeup](https://simonwillison.net/2026/Sep/22/opus-and-sol-and-luna/), GPT-6 Luna is roughly half the price of its GPT-5.6 predecessor. Two labs shipping and price-cutting on the same day — expect this to keep compressing per-call costs regardless of which model you standardize on. [SHARE w/ leadership]

- **[How we built Claude Code auto mode: a safer way to skip permissions](https://www.anthropic.com/engineering/claude-code-auto-mode)** — Anthropic's design for letting Claude Code run without per-action approval while keeping a containment boundary. Directly relevant to how far you can push autonomous execution for your teams inside a regulated environment. [SHARE w/ engineering team]

- **[How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)** — Anthropic's writeup on capping agent blast radius across claude.ai, Claude Code, and Cowork. Useful reference architecture and vocabulary if you need to explain agent risk controls to compliance or security stakeholders. [READ DEEPER]

- **[Extending public sector intelligence with Agentforce and AWS](https://aws.amazon.com/blogs/machine-learning/extending-public-sector-intelligence-with-agentforce-and-aws/)** — Combines Amazon Bedrock Data Automation with MCP to turn unstructured evidence (scanned documents, footage) into structured, queryable data. Same shape as your underwriting document pipeline — worth reading for the Bedrock Data Automation + MCP wiring pattern. [READ DEEPER]

- **[anthropics/financial-services](https://github.com/anthropics/financial-services)** — New Anthropic GitHub repo, already at 36k+ stars, targeted at financial services use cases. No description beyond the star count came through in today's fetch — worth a direct look given your industry. [READ DEEPER]
