## TL;DR

AWS published a cluster of Bedrock AgentCore write-ups today — multi-tenant RAG over 2 billion regulated documents, agent identity via X.509 certificates, and MCP-based tool/credential discovery — all patterns that map onto your document-ingestion work and your agentic-coding rollout across teams. Docling added a VLM parser and a forms solver worth testing against your OCR pipeline. Separately, eight compromised CA certificates (eMudhra) chain to major root trust stores, and Mistral shipped Large 4.

## What's New

- **[How Octave built a secure multi-tenant AI foundation on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/how-octave-built-a-secure-multi-tenant-ai-foundation-on-amazon-bedrock/)** — Octave built a Complaint Triage Assistant on Bedrock AgentCore with Cohere Embed v4, searching 2 billion regulated documents while keeping tenants isolated. Close to your own underwriting-document RAG problem, just at larger scale. [SHARE w/ engineering team]

- **[Securing AI agent identity with X.509 PKI on AWS](https://aws.amazon.com/blogs/machine-learning/securing-ai-agent-identity-with-x-509-pki-on-aws/)** — Signed request envelopes, delegation assertions, and real-time certificate revocation to prove which agent is making a call across agent-to-agent and MCP tool traffic. Worth a look as more of your teams' agents start calling each other, not just a human.  [SHARE w/ engineering team]

- **[Discover tools at runtime with AWS Agent Registry](https://aws.amazon.com/blogs/machine-learning/discover-tools-at-runtime-with-aws-agent-registry/)** — A discover/instantiate/execute pattern where an orchestrator finds MCP servers and A2A agents via semantic search at runtime, instead of every tool being hardcoded at build time. [READ DEEPER]

- **[How Eon built multi-cloud investigation with an MCP Gateway on Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/machine-learning/how-eon-built-multi-cloud-investigation-with-an-mcp-gateway-on-amazon-bedrock-agentcore/)** — Eon replaced per-tool credentials and local MCP processes across AWS, GCP, and Azure with one authenticated gateway, cutting new-engineer onboarding from two days to two minutes. [READ DEEPER]

- **[Docling v2.141.0](https://github.com/docling-project/docling/releases/tag/v2.141.0)** — Added Nemotron-3.5-Parse as a supported VLM model and a geometric solver for mapping form fields when AcroForm widgets are present. Both land directly on document-ingestion/OCR work. [TRY]

- **[Introducing Mistral Large 4](https://mistral.ai/news/mistral-large-4/)** — New flagship from Mistral. No benchmark detail or Bedrock-availability note in today's feed, so nothing actionable yet beyond awareness. [SHARE w/ all teams]

- **[eMudhra Intermediate CA Compromise](https://simonwillison.net/2026/Oct/20/emudhra-certificates/)** — Private keys for eight eMudhra intermediate CA certificates were compromised; they chain to roots trusted by Mozilla, Microsoft, Apple, and Chrome. Any software bundling a trusted-cert list needs an update — `certifi`, `uv`, and `pip` already shipped fixes. [SHARE w/ engineering team]
