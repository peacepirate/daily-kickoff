## What's New

- **[Introducing Gemini 4 Neon](https://deepmind.google/blog/introducing-gemini-4-neon/)** — Google DeepMind's new mid-tier model, positioned against Claude Opus and GPT's reasoning-tier models. Pricing sits oddly against the existing Gemini 4 lineup (Hydrogen/Argon/Carbon) — worth a glance only if you're actively comparing model costs for Bedrock vs. direct API use. [SKIP]
- **[How Airbnb uses cost per task to operate coding agents on Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/how-airbnb-uses-cost-per-task-to-operate-coding-agents-on-amazon-bedrock/)** — Airbnb picks models for its coding agents using cost-per-task from production, not eval benchmarks, because the two diverge once agents hit real codebases. Directly applicable to running Claude Code via Bedrock across your teams. [TRY]
- **[Sashiko: Lessons from building an agentic code review system for Linux](https://cloud.google.com/blog/products/application-development/lessons-from-building-sashiko-an-agentic-code-review-system/)** — Google's internal tool for triaging AI-generated kernel patches before they hit human maintainers. The core problem it names — code generation outpacing review capacity — is the one you'll face as agentic adoption scales past a few teams. [READ DEEPER]
- **[Docling v2.151.0](https://github.com/docling-project/docling/releases/tag/v2.151.0)** — Document parsing release: better PPTX chart extraction (waterfall, treemap), calendar invite parsing, hardened malformed-file handling. Minor but relevant if Docling is anywhere in your OCR/ingestion stack. [SHARE w/ engineering team]
- **[Le Chonk: Built for Coders, Trusted by Defenders](https://mistral.ai/news/mistral-large-4-oss/)** — Mistral open-sourced Large 4's weights, aimed at agentic coding and cybersecurity use cases. Notable mainly as a local/open-weights option if you ever need to run coding-agent inference off a hosted API. [SKIP]
- **[Quoting Daniel Stenberg](https://simonwillison.net/2026/Nov/18/daniel-stenberg/)** — The curl maintainer on parallel AI efforts to rewrite curl's 185k lines of C in Rust: during the same three weeks, the actual human-led project merged 300+ commits and fixed 200+ bugs, none of which the Rust rewrites have matched. A concrete, citable counterpoint to "agents will just rewrite our codebase." [SHARE w/ leadership]
- **[Your coding agent bill doubled. Here's how to fix it.](https://www.langchain.com/blog/fix-your-coding-agent-bill)** — Practical piece on tracing and governing spend across Claude Code, Cursor, and Copilot from one place. Useful if cost visibility across your 6-10 teams is still ad hoc. [SHARE w/ engineering team]
